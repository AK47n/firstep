# 数字钥匙端（信标端）固件需求说明

## 硬件平台

- **主控芯片**：TI MSPM0G3507（LaunchPad 开发板）
- **无线模块**：DL-20 ZigBee 透传模块
- **ID 输入**：4 位 DIP 拨码开关
- **指示灯**：板载 LED（用作心跳指示）

## 引脚连接

| 外设 | MSPM0 引脚 | 说明 |
|------|-----------|------|
| DL-20 RXD | **PB6** (UART TX) | MSPM0 发给 DL-20 |
| DL-20 TXD | **PB7** (UART RX) | DL-20 发给 MSPM0（本程序只发不收，PB7 可只初始化不读） |
| DL-20 VCC | 3.3V | 跟 MSPM0 同一路供电 |
| DL-20 GND | GND | 共地 |
| DIP 第1位 (最左) | **PA12** | 上拉输入，ON=闭合到GND=读到0=该位为1 |
| DIP 第2位 | **PA13** | 上拉输入 |
| DIP 第3位 | **PA14** | 上拉输入 |
| DIP 第4位 (最右) | **PA15** | 上拉输入 |
| LED | 板载 LED | 推挽输出，心跳闪烁 |

## 程序功能

1. 上电即运行，**无限循环**
2. 每 **100ms** 执行一次：
   - 读取 4 位 DIP 拨码开关，得到钥匙 ID（0x00 ~ 0x0F）
   - 通过 UART（PB6/PB7）发送一帧数据给 DL-20 模块
   - 翻转一次 LED 状态（心跳闪烁，周期 200ms）

## 串口参数

- **波特率**：**115200**
- **数据位**：8
- **校验位**：无
- **停止位**：1
- **流控**：无

## 数据帧格式（4 字节，固定，不可修改）

门锁端按照以下格式解析，改任意一个字节都会导致门锁端收不到。

| 字节 | 内容 | 说明 |
|------|------|------|
| **[0]** | **0xAA** | 同步头1，固定值 |
| **[1]** | **0x55** | 同步头2，固定值 |
| **[2]** | **ID** | 钥匙 ID = DIP 拨码值，只取低4位（0x00~0x0F） |
| **[3]** | **SUM** | 校验和 = `(0xAA + 0x55 + ID) & 0xFF` |

**每 100ms 发送一帧，持续发送，永不停止。**

### 帧示例

| DIP 拨码 | ID | 发送帧 (16进制) | 校验和计算 |
|----------|-----|-----------------|-----------|
| 0000 (全OFF) | 0x00 | `AA 55 00 FF` | 0xAA+0x55+0x00 = 0xFF |
| 0001 (仅第1位ON) | 0x01 | `AA 55 01 00` | 0xAA+0x55+0x01 = 0x100 → 0x00 |
| 0110 (第2、3位ON) | 0x06 | `AA 55 06 05` | 0xAA+0x55+0x06 = 0x105 → 0x05 |
| 1000 (仅第4位ON) | 0x08 | `AA 55 08 07` | 0xAA+0x55+0x08 = 0x107 → 0x07 |
| 1111 (全ON) | 0x0F | `AA 55 0F 0E` | 0xAA+0x55+0x0F = 0x10E → 0x0E |

## DIP 拨码读取规则

**警告：最容易出错的地方，务必按以下规则实现。**

- DIP 拨码开关一端接 GPIO，另一端接 GND
- GPIO 配置为**输入 + 内部上拉**
- 拨码 **ON（闭合）= GPIO 读到 0 = 该位为 1**
- 拨码 **OFF（断开）= GPIO 读到 1 = 该位为 0**

**位序定义（跟门锁端约定一致）：**

```
DIP 位置 (左→右):  第1位   第2位   第3位   第4位
MSPM0 引脚:        PA12    PA13    PA14    PA15
对应的 ID 位:      bit0    bit1    bit2    bit3
                  (LSB)                   (MSB)
值:               0x01    0x02    0x04    0x08
```

**读数示例（拨码 0110，即第2、3位 ON）：**

```
引脚:         PA12   PA13   PA14   PA15
拨码:         OFF    ON     ON     OFF
电平:          1      0      0      1
取反(ON=1):    0      1      1      0
ID 各bit:     bit0   bit1   bit2   bit3
            =  0   +  2   +  4   +  0  = 0x06
```

## 伪代码参考

```
main():
    初始化系统时钟
    初始化 PA12/PA13/PA14/PA15 为上拉输入
    初始化 PB6/PB7 为 UART 功能: 115200, 8N1
    初始化 LED 为推挽输出，默认灭
    配置 1ms 定时器（SysTick）
    
    while (1):
        id = 0
        if (PA12 读到 0) id |= 0x01   // bit0
        if (PA13 读到 0) id |= 0x02   // bit1
        if (PA14 读到 0) id |= 0x04   // bit2
        if (PA15 读到 0) id |= 0x08   // bit3
        
        sum = (0xAA + 0x55 + id) & 0xFF
        
        串口发送(0xAA)
        串口发送(0x55)
        串口发送(id)
        串口发送(sum)
        
        LED 翻转()
        
        延时 100ms
```

## 注意事项

1. **字节顺序**：帧的 4 个字节顺序严格固定 AA→55→ID→SUM，不能颠倒
2. **校验和**：每次发送前都要重新计算（ID 可能刚被拨动）
3. **ID 取值**：确保 `id = id & 0x0F`，高4位始终为0
4. **发送间隔**：精确 100ms。用硬件定时器中断或 SysTick，不要用软件空循环延时
5. **DIP 每帧重读**：每次发帧前重新读取 DIP，拨码改动最迟 100ms 生效
6. **LED 闪烁**：每 100ms 翻转一次 = 200ms 完整周期，肉眼可见
7. **UART 只发不收**：DL-20 是透明传输，MSPM0 发什么门锁端就收什么。PB7(RX) 可以不接 DL-20 的 TXD，但串口初始化时 RX 功能要开着（方便调试）
8. **DL-20 前提**：DL-20 模块需要提前配置为 115200 波特率 + 点对点模式。程序里不需要发 AT 命令

## 验证方法

写完程序后，建议用 USB 转串口模块接到 DL-20 的 TXD 脚，串口助手上位机用 HEX 显示模式：

1. 全拨 OFF → 应看到 `AA 55 00 FF` 每 100ms 重复
2. 只拨第1位 ON → 应看到 `AA 55 01 00`
3. 只拨第4位 ON → 应看到 `AA 55 08 07`
4. 拨 0110（第2、3位 ON） → 应看到 `AA 55 06 05`

如果收到的帧跟上面不一致，检查 DIP 位序和 ON/OFF 映射。
