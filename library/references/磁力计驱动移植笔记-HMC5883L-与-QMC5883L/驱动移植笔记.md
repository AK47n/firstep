# 磁力计驱动移植笔记（HMC5883L / QMC5883L）

## 这两份驱动从哪来

**不是从移植页抄的**——库内没有磁力计移植手册（lckfb 地猛星 41 篇 / 地阔星 43 篇 sensor 页均无该器件），寄存器表依据**器件官方数据手册**：

| 器件 | 手册 | 关键取值 |
|---|---|---|
| HMC5883L | Honeywell HMC5883L Datasheet 900405 Rev E | 7 位地址 0x1E（写 0x3C / 读 0x3D）；数据区顺序 **X-Z-Y**（0x03/04 = X、0x05/06 = Z、0x07/08 = Y），大端有符号；ID 寄存器 0x0A..0x0C 读回 `'H','4','3'`（0x48/0x34/0x33）；CRA 合法组合 0x70/0x78/0x68 等 |
| QMC5883L | QST QMC5883L Datasheet Rev. B（QST-PD-B002-22） | 7 位地址 0x0D（写 0x0D / 读 0x0E）；数据 0x00..0x05 = X/Y/Z 各 16 位**小端**补码；状态 0x06（bit0 DRDY / bit1 OVL / bit2 DOR）；控制 1（0x09）= 0x1D（OSR 512 / ±8G / 10Hz / 连续）；控制 2（0x0A）= 0x40；SET/RESET 周期（0x0B）= 0x01（手册原话「recommended that the register 0BH is written by 0x01」）；Chip ID（0x0D）读回 **0xFF** |

**两件不可混用寄存器**：0x09 在 HMC 是状态寄存器、在 QMC 是控制 1；0x0B 在 HMC 是 ID 尾字节、在 QMC 是 SET/RESET 周期。把 HMC 的初始化序列发给 QMC 会写坏它的控制字——这是市售「HMC5883L 模块」（GY-271 类，实物多为 QMC5883L）最常见的坑。库内两件各自 `init()` **先验 ID**：读不到 = 总线问题（返回 1），读得到但 ID 不符 = 型号不符（返回 2）。

## 库内模块名与调用

| 器件 | 模块 slug | API（两平台同名同语义） |
|---|---|---|
| HMC5883L | `hmc5883l` | `hmc5883l_init()` → 0/1/2；`hmc5883l_read(&x,&y,&z)`；`hmc5883l_read_heading(&deg, x_off, y_off)` |
| QMC5883L | `qmc5883l` | `qmc5883l_init()` → 0/1/2；`qmc5883l_read(...)`；`qmc5883l_read_heading(...)` |

- 通信：**软 I2C**（占 2 个 GPIO，不占硬件 I2C 外设）。mspm0 侧默认脚 HMC = PB6/PB7、QMC = PA23/PA24；stm32 侧两件都挂库内软 I2C 总线（默认 PA6/PA7，与 aht10/bh1750/sht20/sht30/at24c02/ags10/ads1115/vl53l0x/mlx90614 共挂——器件地址全异合法）。
- 航向角：`heading = atan2(Y, X)`，0–360° 顺时针（X 轴为 0°）。换算用内联四象限 arctan 有理逼近，**不引 `math.h`**（双工具链免链 libm；精度 ±0.01° 级）。
- 校准：只吃**硬铁偏移入参**（`x_off`/`y_off`），现场磁干扰下不改代码即可重定标；8 字走位 / 椭球软铁拟合**不入库**（属你的决策骨架，ADR 0009）。
- 两件均**未上板**：软 I2C 时序、ID 读回、航向角真机方向语义待实机复核（编译矩阵已 0 error / 0 module warning 通过）。QMC 另有已知项：Chip ID 读 0xFF 在总线浮空上拉时也会出现，判别力有限（Betaflight 同记录）。

## 与库内其它姿态件怎么分工

| 想要 | 选 |
|---|---|
| 水平面**绝对航向**（找北 / 航向保持 / 定向跟随 / 与 UWB-AOA 配合的朝向） | `hmc5883l` 或 `qmc5883l`（按手里芯片选；两件互替，别同时选） |
| 三轴姿态角（roll/pitch/yaw） | `jy61p`（器件内卡尔曼融合直接出角度） |
| 原始加速度 / 角速度，自己做融合 | `ml_mpu6050`（硬 I2C）或 `imu_uart`（UART 601 帧） |

组合建议：`jy61p`/`ml_mpu6050` 给姿态、磁力计给航向——**别同时选两个航向源**（HMC + QMC 互替件同选无意义，且默认脚在 mspm0 侧已刻意错开、stm32 侧共总线）。

## 原实现的六处缺陷（库内旧副本，勿照抄）

库内 `sources/contest/*/ml_libs/ml_hmc5883l.c` 与桌面工作目录副本**逐字节相同**，存在六处确定性缺陷：

1. 读地址当寄存器用（`HMC5883L_ADDR | 0x01` 被当寄存器地址发出）——正确写法是读用 0x3D、写用 0x3C，两个宏分列；
2. 寄存器宏名按 X-Y-Z 命名，实际器件顺序是 **X-Z-Y**，照宏名用必然错轴；
3. 无符号扩展（`data_l | (data_h << 8)`）——负磁场读成 32768+ 的大正数；
4. `float yaw_hmc;` 声明后从未赋值——航向角名义存在、实际不可用；
5. CRA 写的值落在数据手册保留区间（合法组合 0x70/0x78/0x68 等）——本库取 0x70；
6. 从不验 ID、I2C 原语全部忽略 ACK——器件拔了 / 接错型号也「初始化成功」，随后静默读出垃圾数（最难查的一类故障）。

库内新模块（`hmc5883l` / `qmc5883l`）逐条修正，并在测试里钉住防回潮。
