## 系统框图

依赖树（缩进 = 依赖层级，依赖先于使用者）：
  - motor：TB6612 双路直流电机驱动（双平台统一 API）：motor_set_duty 调速 + motor_set_direction 方向 + motor_encoder_read 编码器读数（读后清零）。
    - xunji：灰度循迹驱动（mspm0）：8 路灰度读取（位图）+ 加权质心巡线核心 + 编码器采样读（读后清零）+ 电机速度输出绑定；适用于巡线/循迹类赛题功能，路口/模式等决策逻辑归生成骨架。（依赖：motor）
  - led：LED 指示灯驱动（双平台）：led_init/led_on/led_off/led_toggle + 通道宏 LED_RED/LED_YELLOW/LED_GREEN；拉电流 1=亮 细节已封装在模块内。
  - beep：蜂鸣器驱动（双平台）：beep_init/beep_on/beep_off/beep_toggle + beep_beep 响 N 声（阻塞式）。
  - delay：MSPM0 毫秒延时：delay_ms 基于 CPUCLK_FREQ 换算调用 delay_cycles，任何时钟频率自动适配。
    - led_beep：声光组合模块（双平台）：LED + 蜂鸣器同时开关 + led_beep_alarm 声光报警；只控制一方请选 led 或 beep。（依赖：led、beep、delay）
  - ml_mpu6050：MPU6050 六轴传感器的 I2C 通用驱动：提供初始化、寄存器读写以及加速度计和陀螺仪原始数据读取功能，供外部算法进一步解算姿态角；适用于航向保持（车头朝向）、直线行驶纠偏、倾角检测等需要陀螺仪/姿态数据的功能。

## 系统方案论证

本系统针对自动行驶小车需求，选用TI MSPM0系列MCU作为主控，结合8路灰度循迹模块（xunji）与MPU6050姿态传感器（ml_mpu6050）实现路径识别与航向保持。题目明确禁止使用摄像头且场地仅提供黑色弧线，灰度传感器通过检测地面反射光差异能够可靠识别黑线，加权质心算法可输出连续偏差值，适用于直线与圆弧的精确循迹。针对长直道行驶，MPU6050可提供实时角速度与加速度信息，通过积分获得航向角，与编码器测速结合纠正方向偏移，避免累计误差导致脱离轨迹。电机驱动选用TB6612，支持PWM调速与正反转控制，配合霍尔编码器构成速度闭环，保证小车在不同负载下平稳运行。声光提示由LED和蜂鸣器模组实现，满足经过关键点时的声光反馈要求。

系统采用分层控制架构：底层为电机速度环，使用编码器反馈进行PID调节；中层为循迹环，根据灰度传感器偏差控制转向；上层为路径状态机，负责按A-B-C-D-A顺序切换行驶模式。该设计在不增加复杂视觉处理的前提下，利用低成本传感器实现高可靠性轨迹跟踪，符合小车尺寸限制与禁用摄像头的规定。所有模块均通过MSPM0的丰富外设接口连接，引脚分配合理，便于统一调度。方案充分考虑了赛题对停车精度、行驶时间及声光提示的要求，具有结构清晰、实时性强、易调试的特点。

## 软件流程设计

系统上电后先初始化各模块：配置GPIO、PWM、I2C，校准灰度传感器阈值，初始化MPU6050，读取编码器清零。初始化完成后进入主循环，等待启动指令。主循环内按状态机执行：状态S0等待，S1直线A-B，S2圆弧B-C，S3直线C-D，S4圆弧D-A，S5停车。每个状态通过读取灰度传感器和MPU6050数据，结合编码器速度进行PID控制。直线段利用MPU6050航向角与目标航向偏差调节左右轮PWM，弧线段利用加权质心得到的偏差调整转向。到达关键点时（A/B/C/D），触发LED与蜂鸣器声光提示，并切换状态。完成4圈后进入停车状态，关闭电机。主循环中持续监测异常超时，若超过规定时间1倍则强制停车。
