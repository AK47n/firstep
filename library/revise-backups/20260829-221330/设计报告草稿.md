## 系统框图

依赖树（缩进 = 依赖层级，依赖先于使用者）：
  - motor：TB6612 双路直流电机驱动（双平台统一 API）：motor_set_duty 调速 + motor_set_direction 方向 + motor_encoder_read 编码器读数（读后清零）。
    - pid：PID 闭环控制 + 灰度循迹驱动（双平台）：通用 PID 控制器（位置式/增量式，pid_init/pid_cal/pidout_limit）+ 左右轮目标速度输出（含轮速校准，motor_target_set）+ 灰度 8 路读取与边缘中点巡线偏差计算（line_error_calc）+ PD 巡线速度输出（line_pid_track）；适用于巡线/循迹/速度闭环类赛题功能，路口/停车等决策逻辑归生成骨架。（依赖：motor）
  - led：LED 指示灯驱动（双平台）：led_init/led_on/led_off/led_toggle + 通道宏 LED_RED/LED_YELLOW/LED_GREEN；拉电流 1=亮 细节已封装在模块内。
  - beep：蜂鸣器驱动（双平台）：beep_init/beep_on/beep_off/beep_toggle + beep_beep 响 N 声（阻塞式）。
  - delay：MSPM0 毫秒延时：delay_ms 基于 CPUCLK_FREQ 换算调用 delay_cycles，任何时钟频率自动适配。
    - led_beep：声光组合模块（双平台）：LED + 蜂鸣器同时开关 + led_beep_alarm 声光报警；只控制一方请选 led 或 beep。（依赖：led、beep、delay）
    - imu_uart：UART 串口陀螺仪（新 IMU 器件）MSPM0 驱动：115200 9 字节帧 + CRC16(Modbus) 校验 + 帧间隙噪声过滤，中断解析出 yaw 角度与角速度（raw×0.1），供车头朝向闭环使用。（依赖：delay）
  - config：集中外设配置头文件：硬件引脚映射（UART/GPIO/LED/蜂鸣器/DIP 拨码）与通用显示、滤波参数统一集中定义，供各模块与主程序统一调用；适用于 UWB 定位、OLED 显示、LED/蜂鸣器指示等多外设联调场景。

## 系统方案论证

本系统采用TI MSPM0系列MCU作为核心控制器，搭配TB6612双路直流电机驱动和编码器实现闭环运动控制。由于场地仅允许存在黑色弧线标记，不允许使用摄像头，故选用8路灰度传感器阵列进行循迹，通过检测弧线位置偏差实现路径跟踪。为满足声光提示要求，采用LED指示灯与蜂鸣器组合，在到达各点及停车时发出声光信号。小车行驶过程中不能后退，因此通过编码器反馈与PID控制确保每次前进行程可控。系统还集成UART串口陀螺仪（IMU），在直线段辅助航向校正，提高行驶稳定性。

在选型方面，MSPM0系列MCU符合题目要求，具有足够的外设资源（PWM、UART、GPIO等），便于实现多路信号采集和控制。TB6612驱动芯片体积小、效率高，支持双向PWM调速，配合编码器可精确控制轮速。8路灰度传感器提供足够密集的采样点，能可靠识别弧线并计算偏差，满足“投影必须在弧线上”的严格约束。LED和蜂鸣器组合方案简单有效，实现多状态提示。陀螺仪选用UART串口模块，集成CRC校验，提供稳定航向角度，用于长直线段补偿漂移，避免累积误差导致脱离弧线。软件架构中，使用PID控制及PD循迹算法，结合状态机管理不同路径段（直线与圆弧），确保完成各规定动作。

综上，本方案在满足功能要求的前提下，结构简洁、成本低、可靠性高，能够应对比赛对时间、精度和声光提示的需求。

## 软件流程设计

系统初始化包括配置时钟、GPIO、PWM、UART和定时器，初始化LED、蜂鸣器、灰度传感器和IMU，然后启动编码器计数。主循环首先读取8路灰度值，计算线路偏差值，判断当前是否在弧线或直线上。若检测到转弯点或停车点，则调用led_beep_alarm触发声光提示并更新状态机。根据当前路径段，调用line_pid_track计算目标速度，若处于直线段还需结合IMU的yaw角度进行航向修正，然后通过motor_set_duty和motor_set_direction控制电机。同时定时读取编码器值，通过pid_cal计算速度闭环，实现前进方向不后退。状态机按题目要求依次切换：A->B->C->D->A（第2项）或A->C->B->D->A（第3项），并记录圈数，完成4圈后停车。整个过程循环运行，确保小车始终沿弧线行驶，满足时间与精度要求。
