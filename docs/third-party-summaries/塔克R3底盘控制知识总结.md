## 1. 直流电机开环调速（PWM）

- **原理**：电机两端电压决定转速（占空比 → 平均电压 → 转速）。STM32 用定时器
  PWM 输出，占空比 0~100% 连续调速；反转通过 H 桥（TB6612 / AT8236）换向。
- **要点**：PWM 频率要避开电机/驱动谐振（常见 10k~20kHz）；死区与续流二极管
  防 H 桥共穿（驱动芯片内置则不必处理）；初始速度从 0 缓升（软启动），
  直接给大占空比会因启动电流大而抖动/烧驱动。

## 2. 正交编码器测速

- **原理**：电机尾部 AB 两相互交脉冲，转一圈发出 N 组脉冲；测「单位时间的脉冲增量」
  = 即时转速，测「总脉冲数」= 累计转角（配合减速比换算圈数）。正交计数 =
  边沿×方向的四倍频（4 倍分辨率），是增量式编码器的标准计数法。
- **要点**：转速采样周期要固定（如 10ms~50ms），太短噪声放大、太长响应迟；
  方向由相序判；`增量/时间` 的速度量要滤波（滑动平均/低通）再进 PID，
  否则调速环比例项会抖。

## 3. PID 闭环（速度环 / 位置环）

- **速度环**：反馈 = 编码器周期增量折合的转速，输出 = PWM 占空比。
  偏差 `e(t) = 目标 - 实测`；`输出 = Kp*e + Ki*∫e + Kd*de/dt`。
  速度环 Kd 常小（增量差分噪声大），扰动靠 Kp/Ki。
- **位置环**：反馈 = 编码器累计计数值（相对/绝对），输出 = 速度目标或 PWM。
  位置环一般**内嵌速度环**（串级：外环位置 → 内环速度 → PWM），
  单环位置控制需要微分阻尼（Kd 防超调）。
- **调参口诀**：先 Kp 从小到大会震荡→回退；加 Ki 消稳态误差（注意积分饱和 → 
  限幅/抗积分饱和）；Kd 先不加，位置环需要防超调时再加。
- **注意**：PID 参数与「采样周期」强耦合——改了采样周期必须重新调参；
  量纲要统一（速度用 脉冲/周期 或 r/min，目标量与反馈量同量纲）。

## 4. 底盘运动学（车体坐标 → 轮速分配）

- **两轮差速**：`v_L = v_center - ω*L/2`，`v_R = v_center + ω*L/2`
  （L = 轮距，ω 逆时针为正）。正逆解一对：
  正解（两轮 → 车体）：`v_center = (v_L+v_R)/2`，`ω = (v_R - v_L)/L`。
- **四轮差速**：同侧轮速相加平均（四轮同速 = 两侧差速，同两轮差速模型，
  只是左右各两个轮取平均）。
- **麦克纳姆轮全向**：45° 辊子，四个轮速 = 车体 (vx, vy, ω) 的线性组合，
  系数矩阵由安装方向（X 型 / O 型辊子排布）决定；逆解 = 矩阵求逆。
  实现要点：辊子方向符号写错会出「前后左右全错位」的经典 bug。
- **阿克曼转向**：前轮差速转向（内轮转角大、外轮转角小），后桥驱动。
  低速精度模型 `ω = v * tan(δ) / L`（δ = 前轮转角，L = 轴距）——跟踪曲率用。
- **三段式**：车体速度 → 各轮速度（运动学）→ 各轮速度环（PID）→ PWM。

## 5. 周期任务调度（软实时）

- 主循环固定周期（如 20ms / 50Hz）：读传感器 → 解算运动学 → 各轮速度环 →
  上传位姿 / 响应手柄。中断只做「计数/置标志」，重活放主循环。
- 与「硬实时」的区别：软实时用轮询周期，丢一帧只影响瞬时精度不崩溃，
  对比赛小车足够；关键在**周期恒定**（不要用 `while` 忙等+随机 delay
  串起来的时间基准）。
