# 模块库简介规范：三要素判据 + 功能库归属母版

真机录入后暴露简介无法支撑"能否嵌入母版"的判断：缺套件/版本身份信息、逻辑绑定赛题的模块（lock_control / zone / pid）没有专用性标注、逐飞库被误录为模块并与母版同路径内容冲突、三个模块因误声明对功能库的依赖而无法被选中。决定：简介判据 = ① 与代码一致（AI 校验，保留）② 硬件身份可确认（平台条目新增 `kit` 套件型号 + `source_url` 购买链接，新录入必填、URL 格式校验、由人补填）③ 逻辑绑定具体赛题的模块必须标注"XX 题专用"。功能库（逐飞 ml_*）归属母版基础设施，不属于模块库，模块不得声明对其依赖；模块库删除重复的 ml_i2c / ml_oled，清除三个误声明依赖。

**可选配套方向**：filter 之于 uwb_uart 认可为可选组件，但代码层现状是必需依赖（uwb_uart.c 写死滤波调用），可选化需要条件编译改造 + 生成器按选中定义宏，已立项未实现；普适 filter、普适巡线逻辑为将来方向。
