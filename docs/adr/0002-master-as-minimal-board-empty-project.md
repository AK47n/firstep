# 现阶段母版 = 空的最小系统板工程

Status: accepted

现阶段提炼产物是一个**空的最小系统板工程**：平台基础设施文件齐全（启动文件 / system / CMSIS / 工程配置文件）+ 确定性模板 main.c（时钟初始化 + while(1) 空循环 + TODO 区），能直接编译烧录。旧工程里的业务 .c/.h（赛题逻辑）一律剔除；整合的实际对象以工程配置文件为主。

这是用户路线的当前第一步（上传题目 → AI 理解 → 模块库推荐 → 用户选定 → 生成带模块的 .c/.h → 框架代码）。驱动文件的通用提炼与整合、AI 基于保留头文件生成骨架 main.c（机制已存在于 skeleton.py，暂不用于母版）都是后续拓展；骨架生成机制仍服务于生成流程（按赛题生成 main.c），与本决策不冲突。
