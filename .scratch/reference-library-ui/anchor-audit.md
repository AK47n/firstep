## 锚定机制（判定依据）

- 赛题方向：锚定值 `topic` 必须命中赛题库 key（8 个：2018C/2019A/2020C/2021F/
  2022C/2022H/2024H/2026C），生成时按「key ∈ 锚定值子串」自动关联；
- 套件方向：锚定值 `kit` 必须在模块库套件词表（`module_kit_vocabulary`，
  只有两个值：`MPU6050`、`最新ALX-AOA-FIT跟随套件开发资料`）；
- 悬空 = 两边都不命中 → 生成时永不自动关联 → 行内 ⚠ + 统计红段（工单 04）。
