# 04 — LLM 赛题→模块选择 + 依赖解析 + 配置

**What to build:** 用户粘贴赛题后，系统调用可配置的 AI（默认 DeepSeek），基于模块库清单选出推荐模块并附理由，递归带上依赖模块；用户可在生成前增删选择。API 配置存本机。

**Blocked by:** 01 — 生成器核心骨架 + fixture 测试基座

**Status:** ready-for-agent

- [ ] LLM 客户端抽象为协议：生产实现调用 DeepSeek（base_url / key / 模型可配置，存本机配置文件，不入版本库）；测试注入固定返回的假实现
- [ ] 赛题 + 模块库 manifest 摘要 → 结构化输出：推荐模块列表 + 每条理由
- [ ] 依赖解析：按 manifest 递归带入依赖模块，无环
- [ ] 平台警告：推荐模块缺少目标平台版本时输出两类提示——"未验证"与"硬件绑定"
- [ ] 选择结果可在生成前由用户增删
