# 08 — 现象回填 + AI 排障

**要做什么：** 用户上板跑完，把「我实际看到的现象」填回检测页，AI 给出排查方向（先判断是接线问题、器件问题还是代码问题，再说下一步查什么），并把这次检测的现象与清单勾选一起留档。

**被谁阻塞：** 04（要有专精检测结果可供讨论）。

**状态：** ready-for-agent

- [ ] 检测页有现象输入区；提交后返回中文排查建议（结构化：可能原因 + 下一步查什么）
- [ ] 送进模型的上下文含：接触线表与引脚绑定、检测项清单、勾选状态、用户填写现象；**不编造库内没有的接口或引脚**
- [ ] LLM 失败**不阻断**（中文兜底文案 + 可重试），检测记录照常保留
- [ ] telemetry 与"最近工作流"接入既有机制（事件常量登记在事件词表单源）
- [ ] 协议方法列入既有协议清单用例（假 LLM 桩同步），保证漏实现即红
- [ ] 事实约束：建议里出现的引脚名与模块名必须来自本次检测上下文（假 LLM 桩注入非法值 → 拒收或降级，有单测）
- [ ] 检测记录（现象 + 勾选 + 建议）随该次检测落盘，刷新可回显

## 边界与决策引用

- 这是本功能里 **LLM 的唯一入口**（其余全程确定性渲染）；失败降级照既有"步骤报告"先例。
- 检测没过 = 正常结果：建议里要给"必要时把问题反馈成一张修复单"的出口，不含糊其辞。
