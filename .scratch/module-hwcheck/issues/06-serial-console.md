# 06 — 交互式串口控制台（自动一遍 + 命令复测）

**要做什么：** 上电自动跑完一遍之后，程序进入串口命令交互：敲一个字符就能重测对应器件、看回显，**不用重烧**就能边动线边看现象。库内既有的点灯 / 蜂鸣命令语义保持不变，新命令由配方声明。

**被谁阻塞：** 05（配方与探头已就位）。

**状态：** ready-for-agent

- [ ] 自动一遍照旧（逐件自报 + LED 心跳常驻）；之后进入命令循环
- [ ] 命令表由配方生成（每件声明的命令字符 + 固定的帮助命令）；字符冲突在**构建期**报错（不是运行时静默覆盖）
- [ ] 既有 `r` / `y` / `g` / `o` / `b<N>` 五条命令**语义一个字节不动**（已上过板的既有行为），新命令只追加
- [ ] 回显格式固定（含"这是哪件、测的是什么、结论/数值"三段），并有单测锁定格式
- [ ] 无 debug_uart 的构建：只跑自动那遍，检测页**明说**"没有串口 = 不能交互式复测"（不静默降级）
- [ ] 命令解析是纯函数（字符串进 / 结果出），单测覆盖：合法命令 / 未知命令 / 多字符参数 / 空输入
- [ ] 真机口径：至少一个平台编译绿；交互行为未上板则如实标注

## 边界与决策引用

- 不做串口实时波形、不做上位机（spec 范围外）。
- 控制台形态的既有先例是库内已有的接线检测台，本单是"把它扩成配方驱动"。
