# 02 — 存量赛题条目取题面自动补图注

**要做什么：** 取历史赛题（如 2026C）题面时，若条目题面引用图（含「图N」字样）但无 `[示意图` 标注、原 PDF 仍在条目目录内、且配置了视觉 key——自动对原 PDF 生成图注段并**写回条目题面**（幂等，补过一次不再补），返回带图注的全文。用户下次取 2026C 题面就能看到图内容描述，生成随之用上；未配置视觉 key = 返回与现状逐字节一致。

**被谁阻塞：** 无——可立即开始（与 01 独立，均复用既有图注抽取）

**状态：** resolved

- [x] 赛题库模块新增补图注服务（enrich_topic_image_notes）：判定（图引用 && 无图注 && 原 PDF 存在）→ 图注生成 → 图注段追加题面文末（空行分隔）→ 写回 + 自动提交 → 返回更新后全文
- [x] 幂等：题面已含 `[示意图` 前缀行 = 跳过不跑视觉；重复取题面不重复消耗额度（测试断言调用计数）
- [x] 取题面路由接线：仅视觉 key 已配置时调用；任何异常降级返回原题面（视觉是增强不是阻塞）
