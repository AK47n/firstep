# Spec — 历史赛题视觉图注（topic-vision-notes）

## 问题陈述

用户取历史赛题（如 2026C）题面时只看到文字：题面里的 `图1` 只剩标题（`> **图1** 数字钥匙实验系统功能示意图`），图内容（电路图 / 布局图 / 功能示意图）丢失。根因：拆条入库用纯文本抽取（PDF 嵌入图被丢弃），视觉模型只在「上传 PDF / 图片」路径生效，从未接入拆条与取题面路径。

## 方案

两处接线，让视觉模型覆盖历史题全链路：

- **A. 拆条时识别图**：上传长 PDF 拆条时，若配置了视觉 API key，先对 PDF 做「文本 + 嵌入图视觉图注」抽取（`[示意图N：…]` 段，与上传抽取同款），再送 LLM / 分块拆条——新拆的题面自带图注。未配置视觉 key = 纯文本抽取，与现状逐字节一致。
- **B. 存量条目补图注**：取题面时检测条目是否需要补图注——题面引用图（含「图N」字样）但无 `[示意图` 标注、原 PDF 仍在条目目录内、且配置了视觉 key → 对原 PDF 生成图注段 → **写回条目题面**（幂等，补过一次不再补）。取题面返回带图注的全文，生成随之用上。

## 用户故事

1. 作为用户，我拆条新题 PDF 时希望嵌入示意图被视觉识别进题面，以便推荐 / 生成能「看到」图。
2. 作为用户，我取存量历史题（如 2026C）题面时希望自动带上图注，以便 AI 理解图内容。
3. 作为用户，我没配置视觉 key 时希望一切行为与现状完全一致（纯文本）。
4. 作为用户，我多次取同一题题面时希望不会重复消耗视觉额度（幂等）。
5. 作为用户，我希望视觉识别失败（限流 / 网络 / 未配置 / PDF 异常）时不拖垮拆条或取题面（降级为原行为）。

## 实现决策

- 复用上传抽取同款图注能力（单文件 ≤ 8 张、单张 ≤ 4MB、单张失败跳过、异常返回空串降级），拆条与补图注都不新造图注逻辑。
- A 接线点：拆条路由的上传 PDF 分支，按「视觉 key 已配置」分流到图注抽取；观测口径照上传抽取（collector → LLM 观测 / 最近工作流）。
- B 落点在赛题库模块（新公开函数）：读条目 → 判定（图引用 && 无图注 && 原 PDF 存在）→ 图注生成 → 图注段**追加到题面文末**（空行分隔，不破坏原文结构、diff 干净）→ 事务写回（照确认入库先例，含自动提交）。幂等判定 = 题面已含 `[示意图` 前缀行。
- B 接线点：取题面路由调补图注（仅视觉 key 已配置时）；任何异常降级返回原题面，绝不让视觉拖垮取题面。
- 图注判定「含图N引用」用宽匹配（题面文本含 `图` 且含数字上下文即可，宁多跑一次视觉也不漏图；幂等写回保证重复无害）。
- 契约：取题面返回的 `problem_text` 带图注；未配置视觉 key 时返回与现状逐字节一致。

## 测试决策

- 先例：上传抽取图注用例（monkeypatch 假视觉描述）、赛题库 CRUD 用例、webapp topics 路由用例（fake LLM / fake 视觉）。
- A：拆条用例——假视觉描述下断言拆条收到的题面含 `[示意图1：…]`；未配置 key 断言纯文本（与现状一致）。
- B：赛题库用例——构造「有图引用、无图注、原 PDF 在」的条目 + 假视觉 → 断言写回图注；幂等（二次调用不再调视觉）；无图引用 / 无原 PDF / 未配置 → 原样不写。
- 结构测试防回退：补图注函数为赛题库模块公开属性；取题面路由存在接线（图注调用点）。

## 范围外

- PDF 矢量图提取限制（pypdf 只取栅格图对象）不解决——识别不到的就是拿不到。
- 前端零改动（取题面返回文本自动带图注；无新按钮）。
- 不提供手动「重新拆条」动作；已入库条目不自动重拆。
- 生成装配（历史题编号直通生成）不在装配点做图注逻辑——取题面已写回库，装配自然读到。

## 补充说明（03a 决策：矢量图标注文字布局，零额度通吃）

实测 2026C：矢量图的**标注文字留在 PDF 文本层**（"60cm/100cm/15°/30°/45°"等），但 `extract_text()` 丢坐标导致格式乱、标注与线段对应关系丢失；**visitor_text 回调 + cm×tm 复合矩阵可还原页面坐标**，按 y 聚类成行、行内按 x 排序可重建图内标注布局（实测 2026C 图1：左侧 -45°/-30°/-15°、右侧 15°/30°/45°、尺寸链 60cm→100cm×3、α 全部还原）。

**补图注改为两级：文字标注优先，视觉兜底**：
1. 文字层（新，零额度）：对原 PDF 逐页提取「图N」标题行 → 标题上下窗口内的短文本行（正文长行滤除）→ 按坐标重建布局 → `[图N 标注]` 段（多行，行 = 同 y 聚类，行内按 x 排序）；
2. 视觉层（既有）：文字层为空（扫描件 / 无文本层）→ GLM-4.6V 图注（现状不变）；
3. 幂等判定更新：题面已含 `[示意图` 或 `[图N 标注` 均跳过。
