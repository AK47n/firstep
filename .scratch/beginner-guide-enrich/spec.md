## 问题陈述

新手帮助面（新手指引四章、README、欢迎卡、新手词表）整体完整，但存在 **1 处事实错误** 与 **4 处内容缺口**，会让新手走弯路甚至卡住：

1. **事实错误**：三处文案声称「一键补齐」能**下载**参考文件与模块库（新手指引准备章 note、欢迎卡第 2 步、README 三步装好第 3 步）。实际「一键补齐」只按计划依次滚动/聚焦缺失步骤，**不下载任何东西**。
2. **首次使用关键缺口**：模块库 / 母版库（含赛题库、参考文件库的派生）都随包存放在仓库 `library/` 目录，但默认配置指向 `~/.contest_generator/`。新手不手动把「设置 → 库目录」指过去，会卡在：模块库空、母版「未导入」、生成报「母版工程目录不存在」。教程/README 完全没讲这一环。
3. **评分点体系没讲**：结果区有「评分点核对」可勾选验收清单（可复制核对表），任务推进里有「评分点覆盖总览」（某评分点无任务覆盖标红 = 丢分风险）。教程只字未提，而这是新手最关心的「这题怎么给分」。
4. **「参数速调」只有名字**：实际 = AI 扫描 main.c 可调数值（阈值/速度/频率…）给出列表、建议范围与改值应用，页签内还有「问 AI：我该调哪个参数」。教程没解释用途。
5. **IDE/驱动下载无入口**：MDK-ARM、CCS、ST-Link 驱动、MSPM0 SDK 无下载指引；MDK 评估版 32KB 代码限制对工程大小是真实约束，也未提。另有浏览器要求未提（任意现代浏览器，推荐 Edge/Chrome）。

## 方案

- **修正文案**：一键补齐的表述全面改为事实口径（只带路、不下载）；库目录指向讲解清楚（install.bat 已自动指向随包 library；手动场景告知设置路径与填法）。
- **首次使用自动化**：install.bat 首次运行（配置文件不存在时）自动写入最小引导配置，把模块库/母版库指向随包 `library/` 子目录；已存在配置一律不动（幂等、尊重用户）。
- **后端一致性**：设置读取接口在「配置文件存在但未配置 key」时，模块库/母版目录返回磁盘文件里已保存的值（现状返回默认值会把 install.bat 的自动指向在首次保存设置时覆盖掉）——新增原始字段解析 helper，非法值回退默认。
- **教程补全**：
  - 准备章：库目录指向（自动/手动两种口径）+ IDE/驱动官方下载表（含链接与 MDK 32KB 限制提示）+ 浏览器一行；
  - 做题主线章：任务推进小节补「评分点核对 / 覆盖总览」与「参数速调」解释；
  - 编译与上板章：新增「常见报错速查」小节（编译/烧录典型报错 → 对策表）；
  - 交付与收尾章：交付前补「评分点核对清单」动作说明。
- **词表增补**：新增「评分点」「参数速调」两个词的人话解释。
- **README/欢迎卡**：同步修正与补充（库目录说明、FAQ）。

## 实现决策

- 教程正文继续以 fx/guide.js 的 GUIDE_CHAPTERS 为单一数据源；新增小节沿用现有块类型（p/note/ul/ol/table/jump），不引入新块类型。
- 下载入口只放官方产品页链接：MDK-ARM（keil.com 下载页）+ 评估版限制（keil.com 限制页）、CCS（ti.com CCSTUDIO）、ST-Link 驱动（st.com STSW-LINK009）、MSPM0 SDK（ti.com MSPM0-SDK）；文案留「以官网为准」兜底。
- 报错速查表行目按现有代码事实核对（烧录超时 180s、找不到 DSLite/OpenOCD/st-flash、未检测到工具链、母版未导入等），与编译/烧录章既有 note 不重复而是汇总成表。
- install.bat：在第 3 步装依赖后、自检前，若配置文件不存在 → 调用可测试的写入函数生成最小引导配置（api_key 空串 + 库目录两个字段）；文件已存在则跳过；保持幂等与 GBK 中文提示风格。
- 最小引导配置写入函数放入配置层（纯函数、可直测）：只写「文件不存在」情形；api_key 为空串，使应用保持「未配置」状态（各端点现有提示不变），同时库目录被设置读取接口识别。
- 设置读取接口：新增原始字段解析 helper——配置文件存在且 JSON 可解析时，模块库/母版目录取文件值（非空字符串），否则回退默认；仅在「未配置 key（config=None）」路径参与，已配置路径行为不变。
- 欢迎卡 full 态第 2 步文案改为事实口径（一键体检 + 体检指引）；不新增按钮。
- 词表增至 12 词；summary 计数由现有模板自动显示。
