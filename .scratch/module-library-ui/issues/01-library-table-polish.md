# 01 — 模块库表格视觉令牌化

**要做什么：** 模块库页表格从「裸表格」升级为与生成页同一质感的管理面板：行 hover、
斑马纹、圆角、焦点态、统一样式的操作按钮与平台徽章；空态 / 错误态打磨。纯视觉纵切，
不改任何交互逻辑与数据流。

**被谁阻塞：** 无——可立即开始。

**状态：** resolved

- [x] 表格行 hover 与生成页 / 参考库表格一致（沿用全局 `tbody tr:hover`，不新增底纹与新令牌值；参考库表无斑马纹则本表亦无）
- [x] 平台徽章四种状态（已验证 / 未验证 / 硬件绑定 / 内嵌母版）配色与模块选择卡一致（复用 moduleBadges 同源样式）
- [x] 操作列按钮样式统一：普通按钮与 `.danger` 危险按钮对齐全局样式；删除按钮保留红色警示
- [x] slug 首列等宽字体（限 `.lib-table` 作用域，不波及参考库 / 母版表），简介列超长截断（tooltip 全文，title 由行渲染同步给出）
- [x] 空态（📦 当前文案）、加载中占位、`#lib-msg` 错误态（复用全局 `.error`）视觉打磨

**实现备注（评审修订后）：** 斑马纹方案撤销——生成页 / 参考库表均无斑马纹，为与全站一致并遵守 spec「不新造令牌」，行高亮沿用全局 `tbody tr:hover`；`td.slug` 限定 `.lib-table`（避免波及参考库中文标题列与母版表）；`.lib-table td:last-child` 与全局 `table td:last-child` 重复故删除。圆角 / 焦点态 / 错误态经查证由既有全局样式覆盖（`.card` 圆角、`button:focus-visible`、`.error`），不新增规则。
