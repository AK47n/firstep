# 01 — 模块库表格视觉令牌化

**要做什么：** 模块库页表格从「裸表格」升级为与生成页同一质感的管理面板：行 hover、
斑马纹、圆角、焦点态、统一样式的操作按钮与平台徽章；空态 / 错误态打磨。纯视觉纵切，
不改任何交互逻辑与数据流。

**被谁阻塞：** 无——可立即开始。

**状态：** ready-for-agent

- [ ] 表格行 hover、斑马纹（隔行底纹）与生成页 / 参考库表格一致（复用既有令牌，不新造）
- [ ] 平台徽章四种状态（已验证 / 未验证 / 硬件绑定 / 内嵌母版）配色与模块选择卡一致

- [ ] slug 首列等宽字体，简介列超长截断（tooltip 显示全文），与参考库表格排版一致
- [ ] 空态（📦 当前文案 + 折叠后的视觉）、加载中、`#lib-msg` 错误态视觉打磨
- [ ] 浏览器截图人工目视验收（与生成页同屏对比不割裂）
