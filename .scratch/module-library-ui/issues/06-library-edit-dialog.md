# 06 — 「编辑」弹窗（套件 / 购买链接 + 平台版本文件增删）

**要做什么：** 每行新增「编辑」按钮，弹窗承载平台级编辑：① 硬件身份——套件型号 /
购买链接（`PUT /api/modules/{slug}/platform-identity`，空值 = 保留原值的补填语义）；
② 平台版本文件——列出该平台文件清单并可删除（`DELETE /api/modules/{slug}/platform-files`）、
新增文件（选磁盘文件或粘贴内容，`POST /api/modules/{slug}/platform-files`，复用添加
表单的文件行模式）。所有操作即时生效：成功返回新 manifest → 刷新表格；失败展示原因。

**被谁阻塞：** 05——模态骨架（开合 / 保存中 / 失败反馈）先由 05 落地，本工单复用
同一套模态模式。

**状态：** ready-for-agent

- [ ] 每行「编辑」入口 → 模态；平台下拉列出该模块的平台版本，切换展示对应条目
- [ ] 套件输入框带已有 kit 词表提示（datalist，词表 = 库内所有平台条目 kit 去重，
      有先例），购买链接保存前做 URL 格式校验（空 = 保留原值）
- [ ] 平台文件清单展示（含「内嵌母版」态），可多选删除 → `platform-files` DELETE；
      删除前置确认
- [ ] 新增文件：文件行（文件名 + 内容 / 磁盘选取），提交 → `platform-files` POST
- [ ] 保存成功 → 表格与统计条即时刷新；失败展示后端错误消息，表单保留
- [ ] 只读字段（验证状态 / 备注 / 简介）可展示在本弹窗但不提供编辑（提示走对应入口）
- [ ] 现有 tests/js 全绿、pytest 全量全绿、冒烟清单不回归
