# 06 接线图两列布线：板居中 + 左右端子列 + 端子按引脚位置动态生成

Status: claimed

## 要做什么

用户实测反馈（01-05 交付后）：接线图端子全在右侧一列，多根线（尤其左列焊盘的线）横穿板图相互缠绕，看不清哪根接哪个模块。要求：

1. **板居中**，左右两侧各放一列模块端子盒；
2. 端子盒纵向位置**按引脚位置动态生成**（对齐焊盘行），线尽量水平、避免交叉缠绕。

数据纪律不变：几何/端子名仍全部由 board + rows 确定性推导，客户端无新数据源。

## 被谁阻塞

无（05 已提交；本工单在其之上，只动渲染布局）。

## 验收标准

- 接线图：板居中，左列焊盘线接左端子列、右列接右端子列（跨侧线被板隔离）；
- 常规（每焊盘 ≤1 线）：所有线水平、端子盒 y 与焊盘 y 对齐；
- 同焊盘多线（同 pin 多行）：该侧端子等距排布、同侧无交叉；
- 焊盘圆点与丝印标签画在线上层（线不压字/不压焊盘，文字衬底可读）；
- 既有功能回归：高亮/淡显/电源配色/图例/折叠开关/空态/转义/「显示全部接线」全部不变；
- tests/js 全绿；评审两轴通过后提交（中文提交信息）+ CHANGELOG + 本工单 resolved。
