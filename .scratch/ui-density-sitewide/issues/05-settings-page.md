# 05 — 设置页（含环境中心 / 更新 / 交付卡 / 资料库更新）复用同一套令牌与描边

**要做什么：** 设置页是**卡片最多**的一页（14 张卡 + 28 行）——框套框在这里最吵。
改成与检测页同一套：一屏一层完整描边、卡片之间靠大间距分组、更新与环境信息读得清。

**被谁阻塞：** 02（地基两单；页面单彼此独立）。

**状态：** ready-for-agent

## 验收标准

- [ ] 本页作用域裸 px 字号 = 0；裸令牌间距值 = 0。
- [ ] **一屏一层描边**：14 张卡之间不再互相套框——分组靠"大间距 + 分组标题"表达，
      卡内分区靠留白 / 单条分隔线 / 淡底；给出改前 / 改后逐层清单与保留的例外。
- [ ] **更新面板可读**：版本号、体量、进度三处信息的主次分明（数值优先于标签）；
      更新失败的提示是"语义告警块"那一类（保留它那一条描边）。
- [ ] **环境中心**：检查项成组呈现（通过 / 缺失 / 警告三种重量分明），不再每行一个框。
- [ ] **开关与危险操作**：设置项的开关、重置按钮与主操作不撞色；不可逆动作有明确重量。
- [ ] 契约：id 集合 / 既有元素顺序 / 既有类名计数不变；中文文案零删除。
- [ ] `SITEWIDE_BACKLOG` 摘掉 `settings` 那一条；守卫四条腿全绿。
- [ ] 读数与截图落盘：`probe-00` / `probe-01` / `probe-03` 重跑；
      **本页暗色整页图**入库。
- [ ] 门禁：前端门禁零回归（基线 1836 / 0）；浏览器门禁零回归；**不与全量 pytest 并跑**。
