## 结论（形状、读数、逐层清单、账）

**形状。** 五件事，四件在 `src/contest_generator/static/index.html`（`<style>` 块 + `#tab-settings`
的 DOM），一件在守卫；**`static/js/**` 一个字节没动**：

1. **字号按角色就地上令牌**（`apply-05a-fonts.py`，10 处）：体检行 / 批次勾选行 → `--fs-body`(14)；
   徽章与跳转小胶囊 → `--fs-tag`(12)；mono 数据块 / 元信息 / 提示行 → `--fs-note`(13)；
   **卡内小节标题 `.settings-section` → `--fs-block`(16) + 正文色**（12px muted 在那个位置弱到
   看不出分组，而本单验收就是"分组标题"）。
2. **间距令牌化**（`apply-05b-spaces.py`，9 条声明 / 10 处取值）：保值变换；本作用域**没有**
   `calc()` 声明（脚本出现就停手，不留恒空的点名表）。
3. **内层整圈框换语言**（`apply-05c-borders.py`，2 条）：`.recent-wf-summary`（卡里的 mono 数据块）
   与 `.materials-pick-list`（弹层里的批次清单）**去框留淡底**——弹层外壳 / 卡片那一层才是"一屏一层"；
   保留 2 条并写清理由（`.env-jump` 小胶囊按钮、`.settings-stickybar` 悬浮保存胶囊）。
4. **新增规则与口径**（`apply-05d-new-rules.py` + `apply-05e-review-fixups.py`）：体检失败行的重量
   （`:has()` + inset 左条）、更新 / 进度结果块（含"数值优先于标签"）、失败告警块
   （`:not(.ok):not(:empty)`）、小节标题与可点折叠头转正文色、**死类 `.warning` 补实**、
   **5 条 `.settings-band` 分组标题元素**、**不可逆按钮补 `class="danger"`**。
   合计 **8 条新规则**（规则数 40 → 48）+ 5 条 DOM 标题元素 + 1 处类名。
5. **守卫**（`tests/js/css-tokens.test.mjs`）：摘掉页面尺的 `settings`（注释里记下 4→3 与
   "新加的那 1 条是例外①"）；合成红证的注入清单加一行 `settings`。

   读数也算在本页头上，一并改完 ✅。
2. **`.llm-*` 不在本页**（票面家族清单里写了它）：分区表按第一命名页把 `.llm-telemetry` 归
   `generate`（03 账第 4 条）——本单**没碰**它，`probe-01` 的 `generate` 行仍是 0/0。
3. **票面那句"框套框主要在 DOM 组合层"是暗示、不是实测**：14 张卡全是同级（无卡中卡），
   真正要处置的内层框只有 2 处。本单按实测做，并按票面 27 行的另一句（"分组标题"）补了 5 条
   分组带。**下一单若遇到"票面说要大改 DOM"的句子，先量一遍再动手。**
4. **新加的那一处整圈框是"故意的"，而且带两个 `:not(…)`**：`#tab-settings .error:not(.ok):not(:empty)`
   是票面点名要的（"更新失败的提示是语义告警块那一类（保留它那一条描边）"）——
   · `:not(.ok)`：`ui/settings.js` 保存成功时只 `classList.add("ok")`、**不摘 `error`**；
   · `:not(:empty)`：`#settings-msg` **默认就是空 div + `error`**，不加就是一条常驻空红框
     （评审实测 1358×18；本单第一版正是这么写的，**门禁全绿、只有人眼/评审看得见**）。
   → 所以本页整圈完整框从 4 只降到 **3**，不是"4 → 2"；**逐层清单里如实点名它**。
5. **"应用之后再纠正"的两支脚本是刻意的**：`apply-05d` 保持它当初写下的原形态、
   `apply-05e` 负责纠正（同 04 单 04a 写出 `;m;` / 04d 修回）。否则同一段字节会有两个出处，
   今后只改一处就静默失配（这正是第一版的问题，评审点名）。
6. **契约对账的口径本单补了一条**（`probe-03-contract.py` 的 `strip_class_attrs`）：给
   「清空本地记录」那个按钮补 `class="danger"`（文案一个字没动）会被报成"删了一行中文"。
   与 03 账第 8 条（内联 `style=`）同类：**判据要比文字，不比属性**。第一版只把取值抹空
   （`class=""`）**不够**——新增属性时行仍然不等，得把整条属性去掉。01–04 的读数是用旧口径
   跑的（它们的结论不受影响：都通过了）。
7. **"三种重量"有两种读法**（Spec 轴提的）：本单的三档是 **安静（无标记）/ 单点（徽章）/
   整行（淡底 + 左条）**；如果要求"三档都要有底色"，得给警告行也上色——代价是整页到处色块。
   **本单选前者**，并把两种读法都记在这里。
8. **四张表以行号为键**（Primitive Obsession，评审提的）：行号是**探针口径**的定位手段
   （`probe-01 --show` 给的就是它），选择器片段是**认人**手段——纯按选择器会撞上"同一选择器
   出现多处"的场景（`.row`、`.muted` 这类）。这个组合是本轮四张表的既定形状，**如实记下这条判断**。
9. **同一块面板里的死类**：`.warning`（渲染方一直在输出、全站无规则）本单补实；
   `.full-confirm` 是弹窗**内容壳**（`.ref-files-modal` 已给形状）**不算死类**——
   下次扫死类时按"有没有渲染方 + 有没有外壳给形状"两条一起判。
10. **`git checkout <commit> -- <path>` 会把旧版写进暂存区**：本单做重放验证时踩到——还原工作树
    之后忘了 `git reset -- <path>`，`git diff` 当场把 **04 整单**的改动重新算成本单的
    （39 行变 313 行）。**重放/换版本之后补一句 `git reset`，看 diff 之前先确认比的是哪一版。**
11. **票面日期按 git 提交时间写**（`git log -1 --format=%ci`）。
