# 02 — 地基 B：全局组件与外壳（按钮 / 徽章 / chip / 提示条 / 空态 / 弹层）

**要做什么：** 把**每个页面都会长出来的那几个零件**统一到检测页那一套：按钮与徽章的字号与重量、
chip 的选中态、提示条（toast）与空态、弹层外壳的形状与层级。做完之后：任何页面上放一个按钮、
一个徽章、一张空态，观感就是新版；而且**一屏一层描边**在弹层里也成立。

**被谁阻塞：** 01（角色表与分区表不在，这一单没有可对照的尺子，也没法把 `shell` 摘干净）。

**状态：** resolved（2026-09-28；读数、逐层清单、双轴评审的账见文末「结论」）

## 范围

- `.btn` 一族（基类 + `--pill` / `--icon` / `.danger` / `.ghost` / `.primary` 等形态）
- `.badge` 一族（含 `.badge.missing` / `.badge.ok` 这类状态变体）
- `.chip` 一族（含推荐 chip 的选中 / 移除三态——**只改呈现，不改交互**）
- `.item` / `.reason` / `.add-*` 这类列表行零件
- `.toast` 一族（顶部提示条，含成功 / 失败 / 进行中）
- `.empty-state` 一族（图标 + 标题 + 说明；空态是"安静"的，不是一张满描边的卡）
- `.spinner` / `.wait-*`（长任务秒表与取消钮）
- `.service-stopped-*`（服务已停止的可见态）
- **弹层外壳**：`.overlay` 一族 / 确认弹窗 / 各类 dialog box（弹层自己算一屏，它那一条描边要留）

## 结论（形状、读数、逐层清单、账）

**形状。**

1. **就地替换**：`components` 作用域 27 处裸字号 → `--fs-*`；17 处等于令牌的间距值 → `--space-*`；
   `.item` 去整圈描边（留 `--panel-2` 淡底）。
2. **动作三级升到全局**（口径来自检测页样板 02，此前只写在 `#tab-hwcheck` 里）：
   `button.danger` 由"只有红字"升为**红描边 + 淡红底、悬停实心红**；删掉检测页那两条重复
   （值逐字相同，留一句指路：口径单源在全局那三条）；补实标记里两处**死类** `class="ghost"`
   （次要 = 描边幽灵，此前渲染成默认实心按钮，在琥珀提示条里很重）。
3. **空态安静**（照检测页那一版）：图标小一档、透明度减半、标题与说明各降一级且颜色退到 muted。
4. **去重**：`.toast-copy` / `.toast-action` / `.wait-cancel` 三段近乎逐字重复的"行内小胶囊"
   收成**形状单源 + 各自只留位置与颜色**。
5. **守卫**：新增「动作三级口径单源」用例（纯函数 `actionWeightProblems` + 合成红证）；
   `--fs-icon` 的口径修正为"**大号**装饰图标——行内小图标随正文"（spec.md 同步回写）。

**账（留给后面的人）。**

1. **施工脚本的"替换侧"也要按文件实际换行走。** 本轮 `apply-02c` 只在**匹配**侧写了 `\r?\n`，
   替换串用 `\n` → 8 行裸 LF 混进 CRLF 的 `index.html`（评审当场量出来）。已用
   `fix-crlf.py` 归一；**下一单直接用 `apply-02e` 的写法**（替换串内联 `\r?\n`，或改完必跑 fix-crlf）。
2. **`.btn` 一族没做完**：选择器里带 `.param` / `.sugg-` / `.task-` / `.draft-` 字样的按钮
   （`.btn-params-*` / `.btn-task-dialog-*` / `.btn-task-edit-*` / `.btn-task-more` / `.btn-draft-*`
   / `.btn-global-chat-*`）按分区表归 `generate`（部分含注释造成的早先误判，已修）。
   **03 单要把它们和生成页一起收干净**——别以为"按钮在 02 做完了"。
3. **对话框的内层盒子**（`.ref-files-*` / `.lib-edit-*` / `.task-dialog-box` / `.code-*`）
   分别归 06 / 03 / 04：本单只处理了 `components` 里的弹层外壳（toast / 服务停止提示），
   它们**保留一条描边是对的**（自己算一屏）。
4. **检测页那两条 `#tab-hwcheck button.danger` 覆盖已删**（值逐字相同）：口径单源现在在全局；
   spec 说"检测页本轮只跑读数复核"，删重复不属于改行为——**但这是动了检测页的样式块，如实记一笔**。
5. **`.ghost` 曾经是死类**：标记里写着 `class="ghost"`、CSS 里没有对应规则，**没有任何守卫会报**，
   只有人眼看得见"这个按钮怎么这么重"。同类风险：任何"标记里有、样式里没有"的类名。
6. **`--fs-icon` 只管大号装饰图标**；行内小图标（toast 的 ico / ✕）随正文 —— 口径已回写 spec.md
   与守卫 `FONT_ROLES`（两处一致由守卫文件头那句约束）。
