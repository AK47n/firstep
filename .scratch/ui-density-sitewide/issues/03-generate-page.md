# 03 — 生成页（做题主页面）复用同一套令牌与描边

**要做什么：** 用户每天待得最久的那一页——8 个步骤卡、推荐区、引脚配置、结果面板、任务卡、
准备度与交付——与检测页长成同一套：四级字号分得清、一屏只有一层完整描边、
"该点哪里 / 下一步看哪里"一眼可见。

**被谁阻塞：** 02（地基两单；页面单彼此独立，可与 04–07 任意顺序做）。

**状态：** ready-for-agent

## 验收标准

- [ ] 本页作用域裸 px 字号 = 0（全走 `--fs-*` 六档，按角色判而不是按数值换算）。
- [ ] 本页作用域"等于令牌却裸写"的 padding / margin / gap = 0。
- [ ] **四级可辨**：卡片标题 20 / 小节标题 16 / 正文 14 / 说明 13 在本页每一段都成立；
      步骤标题（`1. 目标平台` 这一类）不再是灰字小字。
- [ ] **一屏一层描边**：给出改前 / 改后逐层清单（本页嵌套最深的是
      卡片 → 步骤区 → 行 → 表单），如实列出保留的例外。
      **点名一处硬骨头（01 单结账时移交）**：`.card-group`（第 11 步修复中心那张卡里的分组框，
      8+ 处）**至今仍是完整内层框**——分区表修正后它归本单，别当成"地基已经做完了"。
- [ ] **重点会跳**：当前选中 / 正在编辑的那一件（推荐 chip、已选清单行、引脚角色行）
      与"未选中"的差别不依赖读文字；危险操作与主操作不撞色。
- [ ] **空态安静**：未生成时那批结果卡明显弱于有内容时，每张仍说清"生成后会出现什么"。
- [ ] 契约：id 集合 / 既有元素顺序 / 既有类名计数不变；中文文案零删除。
- [ ] `SITEWIDE_BACKLOG` 摘掉 `generate` 那一条；守卫四条腿全绿。
- [ ] 读数与截图落盘：`probe-00` / `probe-01` / `probe-03` 重跑（按页分段）；
      **本页暗色整页图**入库（真浏览器 + 真后端夹具），含"已生成 / 未生成"两态。
- [ ] 门禁：前端门禁零回归（基线 1836 / 0）；浏览器门禁零回归
      （`ui-contract.spec.mjs` 覆盖向导与折叠态）；**不与全量 pytest 并跑**。

## 备注

- 这一页的选择态与展开收口有并发纪律（令牌 / 请求体快照 / 在途排队），**一行 JS 都不许动**。
- 分组与分段靠**新增类名 + 间距**表达，不搬 DOM（`tests/js/` 里按源码文本钉了 id 与顺序）。
- 若某条"重点会跳"只能靠改标记拿到，**停下来记账**（写清哪一条、为什么、代价），
  不要顺手把回归面从"样式"扩到"行为"。
