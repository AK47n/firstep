# 01 — 地基 A：字号角色表 + 守卫分区骨架 + 全局文本基类

**要做什么：** 让「其余页面还没做、哪一页退化了」变成**机器能判**的一件事，并把**每一页都吃到的那层字**
（正文 / 标题 / 说明 / 表单 / 表格）先落到检测页那套台阶上。做完之后：守卫能逐页判红，
进度清单能逐单下降；任何一个页面的正文、标题、说明不再各写各的 px。

**被谁阻塞：** 无——可立即开始。

**状态：** ready-for-agent

## 这一单为什么是第一单

上一轮的账写得很清楚：02 在 `#tab-hwcheck` 里写了个 `font-size: 22px`，
**当场把 01 已勾选的验收打假**，而本该判红的守卫当时还不存在。全站推广面比检测页大一个量级，
**先有尺子再动手**——否则这一轮结束时会得到一堆无法复核的"我觉得改好了"。

## 范围

**算这一单的**（"全局文本基类"，不带任何页面作用域的文本层）：

- `:root` 令牌表（沿用检测页六档；必要时只改注释，不新增档位）
- 标签选择器：`body` / `h1` / `h2` / `h3` / `button` / `input` / `select` / `textarea` / `table` / `th` / `td` / `code` / `pre` / `label`
- 全局文本类：`.card`（`h2` / `h3` / `.card-details` 等子规则）/ `.muted` / `.error` / `.hint` / `.reason` / `.desc` / `.slug` / `.role` / `.decision` / `.brand` / `.welcome-card`
- 全局状态类里**只影响文本**的那些（`.hidden` / `.ok` / `.active` / `.done` 等若含字号声明）

**不算这一单的**（02 或页面单）：`.btn` / `.badge` / `.chip` / `.item` / `.toast` / 弹层外壳 /
整块 `.empty-state`（含图标）/ 任何带页面前缀的规则。

- [ ] **角色表落地为单源**：六档（页 20 / 小节 16 / 正文 14 / 说明 13 / 标签 12 / 图标 22）的
      「哪个角色用哪档」写在守卫文件头（一处），代码注释只指向它，不另抄一份。
- [ ] **分区表**：守卫里新增一张「页面 → 作用域谓词」表（页面 `#tab-*` + 该页组件类前缀 +
      该页 JS 渲染的类名），覆盖全部 12 个页签 + 全局外壳；谓词表是"哪一页归哪一单"的单源。
- [ ] **`SITEWIDE_BACKLOG`**：未完成页清单（照 `IDENTITY_BACKLOG` / `LATER_EDITS` 既有手法），
      这一单摘掉 `shell` 与它自己覆盖到的那部分；清单条目数写进读数。
- [ ] **守卫四条腿**（全部加进既有的 `tests/js/css-tokens.test.mjs`，**不另起文件**）：
      ① 检测页段裸 px = 0（既有）；② 检测页段裸令牌间距 = 0（既有）；
      ③ **已完工页面段**裸 px = 0（新增，按分区表逐页，未完工页由 `SITEWIDE_BACKLOG` 放行）；
      ④ 全站取值集合 ⊆ `FROZEN_FONT_SIZES`（既有）。
- [ ] **合成红证**：四条腿各注入一次判红、复原转绿；锚点取自真实源码并**断言锚点还在**

- [ ] **一屏一层描边**：本单范围内层完整描边清干净（`.card` 那一条是保留的"唯一那层"）；

## 备注

- **读数每轮改动后都要重跑**：上一轮的两条假账（"裸 px = 0" 与那个 22px）都源于此。
- 只改样式与新增类名；**不动任何 id、DOM 顺序、既有类名语义**，不改任何 JS 行为。
