# 01 — 地基 A：字号角色表 + 守卫分区骨架 + 全局文本基类

**要做什么：** 让「其余页面还没做、哪一页退化了」变成**机器能判**的一件事，并把**每一页都吃到的那层字**
（正文 / 标题 / 说明 / 表单 / 表格）先落到检测页那套台阶上。做完之后：守卫能逐页判红，
进度清单能逐单下降；任何一个页面的正文、标题、说明不再各写各的 px。

**被谁阻塞：** 无——可立即开始。

**状态：** resolved（2026-09-28；读数、逐层清单、门禁与双轴评审的账见文末「结论」）

## 这一单为什么是第一单

上一轮的账写得很清楚：02 在 `#tab-hwcheck` 里写了个 `font-size: 22px`，
**当场把 01 已勾选的验收打假**，而本该判红的守卫当时还不存在。全站推广面比检测页大一个量级，
**先有尺子再动手**——否则这一轮结束时会得到一堆无法复核的"我觉得改好了"。

## 范围

**算这一单的**（"全局文本基类"，不带任何页面作用域的文本层）：

- `:root` 令牌表（沿用检测页六档；必要时只改注释，不新增档位）
- 标签选择器：`body` / `h1` / `h2` / `h3` / `button` / `input` / `select` / `textarea` / `table` / `th` / `td` / `code` / `pre` / `label`
- 全局文本类：`.card`（`h2` / `h3` / `.card-details` 等子规则）/ `.muted` / `.error` / `.hint` / `.reason` / `.desc` / `.slug` / `.role` / `.brand` / `.welcome-card`
- 全局状态类里**只影响文本**的那些（`.hidden` / `.ok` / `.active` / `.done` 等若含字号声明）

**不算这一单的**（02 或页面单）：`.btn` / `.badge` / `.chip` / `.item` / `.toast` / 弹层外壳 /
整块 `.empty-state`（含图标）/ 任何带页面前缀的规则。

## 结论（形状、读数、逐层清单、账）

**形状。** 三件事：

1. **守卫升级成「分区表 + 逐页腿」**（全在既有的 `tests/js/css-tokens.test.mjs`，不另起文件）：
   字号角色表 `FONT_ROLES`（六档单源）、有序分区表 `PAGE_SCOPES`（**页面在前、兜底在最后**
   ⇒ 全覆盖不重叠的划分）、页面尺 `SITEWIDE_BACKLOG`、两条逐页腿（字号 / 间距）、
   四条腿的合成红证（三条真注入 + 分区表形状三张坏表）。
2. **全局文本基类与外壳就地替换**：37 条规则字号 + 31 处内联 `style=` 取值 → `var(--fs-*)`；
   42 处等于令牌的间距值 → `var(--space-*)`；6 处内层完整描边去掉（留淡底 / 分隔线）。
   **不做覆盖层**（上一轮 01 的账：叠覆盖层会让同一条规则两处说它多大）。
3. **读数与截图落盘**：`probe-00-after-01.txt` / `probe-01-scope-after-01.txt` /
   `probe-03-contract-01.txt` / `probe-red-shell-{in,out}.txt` / `after-01-{js,browser,pytest}.txt`，
   截图在 `shots/`（暗色全部 12 页 + 改前 4 页对照 + 浅色 2 页 + 1024 窄屏 2 页）。

**账（留给后面的人）。**

1. **兜底会吞东西，而且吞了不报。** 第一版分区表的 `shell` 吞了十余族页面类名——它们的字被
   本单顺手改了、框被本单顺手拆了，而它们本该由 03/04/07 认领。修法：谓词按**渲染方**写 +
   自检「每条谓词至少命中一条规则」。**下一单开工前先看一眼 `probe-01` 的归属表**，别重演。
2. **「内层描边清干净」只在申报过的例外之外成立。** 上面那张逐层清单就是边界。
   特别提醒：**`.card-group`（生成页第 11 步的分组框）仍是完整内层框**——分区修正后它归
   `generate`，**03 单必须处理它**，别当成"地基已经做完了"。
3. **改了一条既有断言的口径**：`tests/js/welcome-responsive.test.mjs` 里窄屏媒体查询的
   `main { padding: 0 12px }` → `0 var(--space-3)`。语义没变，是「等于令牌的必须走令牌」
   这条新纪律的必然结果。
4. **内联 `style=` 的 31 处在 01 就清完了**（原计划留 08 单）：它们分散在生成页与设置页的标记上，
   跟着兜底一起处理最省事。**08 单那条「JS 内联 7 处」仍在**——那在 `static/js/**` 里，与本单无关。
5. **一次性 `#id` 选择器留在了 `shell`**（`#btn-score-export` / `#btn-recent-refresh` 等）：
   它们是单条规则、不是一族，归属不影响复核；哪天成族了，按渲染方加进对应谓词。
6. **拍照/探针脚本都在这轮目录里**（`probe-02-shot.mjs` 可一条命令重出任意页签任意主题，
   `SHOT_WIDTH` 可换视口）；读数一律走 `readings.py`（剥 ANSI、UTF-8、带命令/时间/退出码头）。

## 备注

- **读数每轮改动后都要重跑**：上一轮的两条假账（"裸 px = 0" 与那个 22px）都源于此。
- 只改样式与新增类名；**不动任何 id、DOM 顺序、既有类名语义**，不改任何 JS 行为。
- 纯呈现的效果优先用 CSS（`:target` / `:has()` / 原生锚），**不往 `ui/` 四件的行多重集台账里加页**。
