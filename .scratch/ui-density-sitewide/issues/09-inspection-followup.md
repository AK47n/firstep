## 结论（这一单做了什么、账）

**这一单没碰产品面**（`index.html` 的 `<style>` 块与 `static/js/**` 一个字节没动——
`git status src/contest_generator/static` 是空的）。四件事全在取证面与口径面：

1. **补上两块"任何时候都看不见"的图**（`probe-09-shot-content.mjs`，浅 + 暗共 4 张）：
   · **参考条目详情弹层**（`.ref-files-*` 这一族跨页共用，6 个 `ui/*.js` 在用它）——
     **全真路径**：真表格行 → 真端点 → 真渲染；断言"文件清单非空 / 弹层外壳 1px /
     过滤输入框 1px"（那两条框是 06 单申报保留的例外 ✅）。
   · **提炼进度区**（`.distill-progress`，母版库 `#distill-progress` 与生成页 `#rec-progress`
     两个实例）——**结构真、文字夹具**；断言三件事：**整圈框 = 0px**（07 单去框生效 ✅）、
     **步骤名 = 14px**、**日志 = 13px**（07 单的档位生效 ✅）。
     这三条断言把"07 单说它改好了"从"脚本对账过"升级成"**浏览器里量出来是这样**"。
2. **`probe-03` 扩成"每页一节"**（spec L171 早就要求，08 账第 6 条记着没做）：
   新增第 2b 节——把 `index.html` 按 `<section id="tab-…">` 切成 **12 段**，逐段与基线比
   **id 顺序 / 元素多重集 / 类名多重集**。口径与"只新增、不删既有"的契约一致：
   **新增报成事实、删除才算违约**。
   读数一眼可见本轮各单的正当增量：`hwcheck` 新 18 元素 / 9 类名（02 单的分组带）、
   `settings` 新 10 / 6（05 单的分组带），**十二页删除数全是 0** ✅。
3. **`probe-01` 整支对齐 `scope_lib`**（08 账第 9 条）：三份逐字副本（`load_scopes` /
   `load_backlog` / `scope_of`）换成 import；`apply-09a` **在写盘前后各跑一次探针、逐行 diff**
   ——21 行输出**逐字节相同** ✅（口径没变，只是不再抄）。
4. **跨页前缀的口径写成文**（spec 的「契约与改动面」补一段）：`.pdf-*`（PDF 资料库页 +
   生成页 PDF 上传预览）与 `.lib-*`（模块库 + 五页共用的 `.lib-table` / `.lib-stats`）
   **按第一命名页保持现状**——改谓词只会换一条腿看同一批规则，而两边读数都是 0/0；
   要动的唯一理由是"哪条腿看着它"。**唯一例外 `.rel-tag`**（只由版本记录卡片渲染）已在 08 单改判。

**为什么本单没跑 Spec 轴**：Spec 轴的判据是"改动是否满足工单/spec 的**产品面**要求"，而这一单
**产品面零改动**（`git status src/contest_generator/static` 是空的：不改样式、不改 JS、不改 DOM）。
Spec 面唯一能审的是"取证与口径有没有补齐"，那正是上面这张表在做的；**把这条判断写在这里，
不是"忘了跑"**。（08 单那种改了产品面的单子，两轴都跑。）

1. **`.distill-progress` 那张图是"夹具态"，不是"跑到一半的真提炼"**：产品那几个更新函数是
   模块私有件（没有导出），所以探针只能复现它们写下的 DOM 形态。**要拍"真跑起来"的进度**，
   得给 `ui/master.js` 开一个测试钩子（那是产品面改动，需要单独一单——本单没做，
   因为 09 的边界是"只补取证与口径"）。
2. **`probe-03` 的第 2b 节按"页签切片"比**：切片用的是"从本页签的 `<section>` 到下一个页签
   `<section>` 之前"（这些 section 内部还有嵌套 section，非贪婪匹配会提前截断）。
   **新增页签时要同时更新 `TABS` 列表**（12 个，顺序 = 顶部导航）；漏了会让那一页整段不参与
   对账——脚本对空切片会判红（"切片为空"），不会静默放过 ✅。
3. **`apply-09a` 的自证方式值得抄**：**写盘前后各跑一次被改的脚本、逐行 diff**——
   比"我觉得口径没变"强得多（这一轮 06/07 两单的账里都在讲这件事）。
4. **票面日期按 git 提交时间写**（`git log -1 --format=%ci`）。
