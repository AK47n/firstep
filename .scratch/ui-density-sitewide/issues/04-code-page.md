# 04 — 代码页复用同一套令牌与描边

**要做什么：** 「代码」页（工程树 / 只读编辑器 / 大纲 / 搜索 / 编译面板 / 修复中心 / AI 对话）
与其余页面长成同一套；**编辑器字号仍是用户可缩放的**（缩放是功能，不是样式），
但它的基准值改从字号台阶派生。

**被谁阻塞：** 02（地基两单；页面单彼此独立）。

**状态：** ready-for-agent

## 这一页的家底（改前读数，2026-09-28）

| 项 | 实测 |
|---|---|
| `.code-*` 家族 | **406 条规则**（全站最大一族） |
| 裸 px 字号 | **67 处** |
| 完整描边 | **63 处** |
| 裸令牌间距值 | 84 处 |
| DOM | 158 行（内容多由 JS 渲染） |
| 既有令牌 | `--code-font-size: calc(13px * var(--code-zoom, 1))`——**已经是令牌**，本轮只把它改成从 `--fs-note` 派生 |

## 验收标准

- [ ] 本页作用域裸 px 字号 = 0；`--code-font-size` 从字号台阶派生（13px 那个裸值消失）。
- [ ] **缩放行为不变**：`--code-zoom` 的取值路径、快捷键、缩放档位一字不动
      （改了基准值，不改缩放这条链路）。
- [ ] **行号 / 光标 / 选区的行高与字号单源**：gutter 与 `pre` 用同一 font / line-height
      （既有不变量，别在拆框时拆散）。
- [ ] 本页作用域"等于令牌却裸写"的 padding / margin / gap = 0。
- [ ] **一屏一层描边**：本页是描边最多的一页（树 / 编辑器 / 大纲 / 底部面板 / 修复行 / 对话区），
      给出改前 / 改后逐层清单；如实列出保留的例外（编辑器自身的框 = 控件形状）。
- [ ] **面板分层可读**：编辑区 / 底部面板 / 侧栏三段靠留白 + 一条分隔线分组，
      不再靠每个面板各画一圈框。
- [ ] 契约：id 集合 / 既有元素顺序 / 既有类名计数不变；中文文案零删除。
- [ ] `SITEWIDE_BACKLOG` 摘掉 `code` 那一条；守卫四条腿全绿。
- [ ] 读数与截图落盘：`probe-00` / `probe-01` / `probe-03` 重跑；
      **本页暗色整页图**入库（含"打开了一个工程"那一态）。
- [ ] 门禁：前端门禁零回归（基线 1836 / 0）；浏览器门禁零回归
      （`tests/browser/code-tree-click.spec.mjs` 是这一页交互的主证据）；**不与全量 pytest 并跑**。
