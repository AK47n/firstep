## 结论（形状、读数、四级、逐层清单、账）

**形状。** 五件事，四件在 `src/contest_generator/static/index.html` 的 `<style>` 块里
（**`static/js/**` 一个字节没动**），一件在守卫：

1. **字号按角色就地上令牌**（`apply-04a-fonts.py`，66 处 + 2 处派生）：取值给基准档、角色定档。
   这一页多两条本页口径（写在脚本 docstring 里，评审按它核）：
   ① **代码 / 路径 / mono 内容走 `--fs-note`(13)**，与编辑器正文 `--code-font-size` **同源**
   （树里的文件名与打开后的代码不一样大，是 IDE 的一致性 bug；样板页的代码块 `pre.result`
   也正是 `--fs-note`）；② **散文（说明 / 状态 / 空态 / 元信息）也走 13**，
   **用户要读的非 mono 条目主字走 `--fs-body`(14)**，**徽章 / 键帽 / 小按钮走 `--fs-tag`(12)**，
   **给一整块命名的标题走 `--fs-block`(16)**。页签（编辑器文件标签 / 底部面板页签 / 侧栏 tab）
   统一 13——它们是 mono 文件名与面板名，属口径①那一档。
2. **间距令牌化**（`apply-04b-spaces.py`，64 条声明 / 84 处取值）：保值变换，只动
   `padding` / `margin` / `gap`；含 `calc()` 的**逐条点名**（只一条：行号列右侧那 12px 内边距，
   换成 `var(--space-3)` 值不变），没点名的一律跳过**并打印出来**——"跳过了几条"是看得见的。
3. **内层整圈框换语言**（`apply-04c-borders.py`，5 条）：代码块 → 去框留淡底（照样板 `pre.result`）；
   冲突对比列标题 + pre → 去框（两列靠 10px 间隙 + 各自 `--code-bg` 底分界）；
   效果 diff hunk → 左条 3px + 淡底（照 `.res-block`）。保留 19 条逐条写理由。
4. **两处派生 + 一处 em 例外**：`--code-font-size` 从 `--fs-note` 派生、md 预览根字号从
   `--fs-body` 派生、编译错误行的 ● 色点 `8px → .62em`（装饰字形随行号缩放，
   **spec 的 em 例外第二例**，spec 与守卫文件头两处已同步写明）。
5. **守卫**（`tests/js/css-tokens.test.mjs`）：摘掉页面尺的 `code`、**摘掉取值尺的 `8`**
   （全站最后一处 8px 就是上面那个色点），并给合成红证补一条"`code` 作用域也要判得红"。
