# 12 — 浅色主题人眼复核（这一轮改动的"最后一道人眼闸"）

**要做什么：** 08 单入库了 12 个页签 × 浅色/暗色整页图，09 / 10 两单又补了内容态；
但**没有人系统地看过浅色那一版**（只抽查过指南页、进度区、详情弹层三张）。
这一轮改的是"档位与描边"，最容易在浅色下露馅的是三类：

1. **"去框留淡底"的块**在浅色下与页面底分不分得开：`.recent-wf-summary`（05）、
   `.update-result` / `.materials-progress`（05）、`.mi-reason` / `.mi-plat` / `.edit-old`（06）、
   `.add-section` 的左条（06）、`.distill-progress`（07）、`.md-preview-body`（06）、
   `.topic-detail-problem`（06）。
2. **语义色与硬编码灰**：`.badge.ref-none`、`.mc-plat.un` / `.mc-deps` 用的
   `rgba(139, 148, 158, .12/.15)`，`.master-health-ok` 的 `rgba(63, 185, 80, .3)`，
   以及五种语义色对（`--danger-dim/-danger` …）在浅色下的对比度。
3. **弹层与文档面**：`code-bg` / `--bg` 底 + 已经去框之后，浅色下与页面底是否还分得开
   （`.ref-files-modal` 外壳、`.ref-files-viewer pre`、`.md-preview-body`、
   `.master-file-pre`、`.topic-detail-problem`）。

**账（留给后面的人）。**

1. **"批次胶囊折 2–3 行"是取舍，不是缺陷**：`fx/pdf.js` / `fx/md.js` 把批次名放进
   `<span class="lib-chip">` 再塞进 110px 的固定列里 ✅。**别给它加 `white-space: nowrap`**——
   那会让长批次名**溢出到邻列底下**（比折行更糟，参考库那类表就是这个形状）。
   真要好看得上"列宽 + 省略号 + title 全文"，那是一次设计改动。
2. **源码里的 `<br>` 会被当成"折行缺陷"**：模块库"平台版本"列的两行徽章是
   `moduleBadges()` **故意**写的 `<br>`（`fx/module.js:16`）✅。**看图怀疑之前先 `grep` 渲染方**
   （本轮 05/06 两单的账里都写着这条；这一单我自己先踩了一次，靠 grep 纠正）。
3. **`--accent` 当小字用，浅色下低于 AA（3.39:1）**——这是**调色板级**性质，不是本轮引入：
   `.badge.ref-topic`、文件名链接（`.ref-title-cell` / md 列表）、`.guide-note strong` 都是它。
   **交办下一轮**：要么接受它是"品牌色"（那就把"小字不用 accent"写进规范），
   要么引入一个 `--accent-text`（浅色下压暗一档）——**改它要过颜色守卫**（`tok-*` 那套）。
4. **"去框留淡底"在浅色下很淡（×1.06）**：`.recent-wf-summary` / `.update-result` /
   `.materials-progress` / `.distill-progress` / `.release-body` 这几处**没有左条**，
   浅色下属于"盯着看才分得出"。要加深就是动 `--panel-2`（**全局**，会牵动所有面板）——
   属于调色板级决定，不在本单动。**带左条的那几处（`.guide-note` / `.settings-band` /
   `.add-section`）反而一眼可辨** ✅：这是"左条比淡底更抗浅色"的一条经验。
5. **量具的口径坑（我自己踩的）**：`td.scrollWidth - clientWidth` 判"文本溢出"在
   `table-layout: fixed` 的表上**不可靠**（实测 40/40 行全报，而视觉上没事）；
   可信判据是**"前一列右边界 vs 后一列左边界"的重叠像素**（实测 0）。
   下一轮判"压没压到邻列"，用后者。量具里连"等真行渲染出来再量"都写进去了
   （第一版没等，light 那次只看到 1 行 → 量出"0 行溢出"的假绿）。
6. **覆盖缺口（本单补上两处）**：① 代码页的浅色图**原来只有空态**（编辑器/差异/文档面
   从没在浅色下拍过）→ 补拍打开态；② settings 的内容态（三档体检行、更新与进度块）
   **原来只有暗色** → 补拍浅色。**这两处加起来**才是"这一轮的浅色巡检"。
7. **本单没改一行 CSS**：三类里 ① 淡底可辨（数字见上）、② 三档语义色成立（唯一越线的是
   调色板级的 accent 小字，交办）、③ 弹层与文档面正常。**"有人真的看过"这件事本身就是交付物**，
   下一轮若要动 `--accent` / `--panel-2`，先把这张表拿出来当基线。
8. **票面日期按 git 提交时间写**（`git log -1 --format=%ci`）。
