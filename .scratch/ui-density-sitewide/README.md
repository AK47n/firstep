## 07 单又添的四条（下一单直接用）

28. **一步脚本里"会插行的编辑"要排在"按行号对账的复扫"之后。** `apply-07c` 同时干两件事：
    去框（按行号双向对账）与术语表口径（插入 5 行）——第一版把插入放在对账前，复扫当场报出
    **一串"+5 行"的假不符**（脚本停手、没写坏）。→ 两支脚本共用行号时，**先把行号敏感的核完，
    再做会插行的编辑**；或干脆按 `(作用域, 选择器片段, 取值)` 认人。
29. **探针是从守卫源码里读那两张尺的——注释里的引号会变成"待做作用域"。** 07 单把
    `SITEWIDE_BACKLOG` 清空时，注释里写了 `空集合不是"关掉这条腿"`，`probe-01` / `probe-04`
    当场报"页面尺 1 条：关掉这条腿"。→ 注释里写作用域名一律用 `「」`；**清空那张尺之后要重跑
    一次探针确认它读成 0 条**。
30. **最后三页的"共用件"换了个花样：这次是"同一段 CSS 服务两个页面"。**
    `.distill-progress` 在母版库与生成页（`#rec-progress`）各有一个实例；`.glossary-*` 的
    **唯一渲染方是生成页侧栏**（`#glossary-card` 在 `.gen-sidebar` 里，**指南页并不渲染它**——
    07 单评审抓到我把注释写反了）。→ **"按分区表归谁"与"谁在渲染"是两件事**，
    写注释/记账之前先 `grep` 一遍渲染方；08 巡检在浅色主题下重点看这两处。
31. **票尾要能当"这个作用域的交接单"读**：07 单之后全站裸字号归零，但**整圈完整框还有 116 处**
    （`probe-04` 一跑就知道：`code` 19 / `generate` 33 / `shell` 22 …）——那些是**逐条申报过的例外**
    （spec ①–⑥），不是漏网。**别把"字号 0"误读成"这一轮什么都做完了"**：描边那条靠每单的
    逐层清单 + 人眼看图，守卫明文不判它。
