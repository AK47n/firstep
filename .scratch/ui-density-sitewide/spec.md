# spec：界面「呼吸感」全站推广（其余页面复用检测页那套令牌与描边规矩）

> 状态：待用户确认（clarify 已拍六条，见「补充说明 · 拍板记录」）
> 立项日期：2026-09-28
> 上一轮：`.scratch/ui-density/`（检测页样板，01–05 全 resolved，`1db62b01`）

## 问题陈述

检测页样板已经定稿、用户认可（原话「我现在觉得不错」），但**其余页面一点没变**——
于是现在是"一页新、十页旧"，同一张卡片在两个页面长得不一样。

盘上量出来的硬指标（改前读数，2026-09-28 实测，`probe-00-before.txt`）：

- **全站 387 处裸 px 字号 / 13 种取值**（= `FROZEN_FONT_SIZES` 那 13 条，一条没少）。
  其中 356 处落在样式块的规则里（31 处是标记上的内联 `style=`）：
  **221 处在"不带页面前缀"的全局/组件规则里**（`.btn` 69 处、`.code-*` 82、`.card` 9、
  `.toast` 7、`.muted` 5……），135 处挂在各页自己的类上。**检测页那 30 处是唯一做完的**。
- **完整描边 268 处，其中 209 处是 1px 全框**（`.code-*` 75、`.hwcheck-*` 23、
  `.task-*` 13、`.res-*` 12、`.sugg-*` 11……）——框套框在这些页面照旧。
- **相邻页面的层级是断的**：`.card h2` 全站 16px，而检测页的卡片标题已经是 20px；
  `.card h3` 全站 13px + 灰字，检测页是 16px 正文色。
- **没有任何东西看着其余页面**：防回退守卫只有检测页那一条腿（`#tab-hwcheck|.hwcheck-|.my-device-`），
  别处再写一个 `font-size: 22px` 也不会红——上一轮 02 就是这么把 01 的验收打假的。

## 方案

把检测页定稿的三件事原样推给其余页面（生成 / 模块库 / 参考文件库 / PDF 资料库 /
Markdown 资料 / 赛题库 / 母版库 / 设置 / 代码页 / 版本更新记录，**外加使用指南页**——
它也有 10 处裸字号，不清它冻结清单清不空）：

1. **一条 6 档字号角色表**：页标题 20 / 小节标题 16 / 正文 14 / 说明 13 / 标签 12 / 图标 22
   （就是检测页那六个 `--fs-*` 令牌）。落地口径是**按角色判、就地替换**，不是按现有数值换算——
   13 种裸取值随之全部消失，`FROZEN_FONT_SIZES` 逐条摘空。
2. **一屏一层完整描边**：内层完整矩形描边一律改留白 / 单条分隔线 / 淡底；
   保留两个例外（语义告警块、可点控件），弹层各算自己的一屏。
3. **守卫升级成"分区表 + 每页一条腿"**：机器能判"这一页还没做 / 这一页退化了"；
   未做完的页面挂一张进度清单，每单一页从清单里摘；冻结清单继续只许减不许增。

## 用户故事

1. 作为用户，我想要打开生成页 / 模块库 / 设置 / 代码页时看到的是**与检测页同一套呼吸感**，
   而不是"这一页像是另一个软件"。
2. 作为长时间对着这些页面的用户，我想要正文与说明都读得下去（字号地板抬到 12px 起，
   说明不再是 11px 灰字），以便脖子不往前伸。
3. 作为用户，我想要任何页面**一屏内只有一层完整描边**，而不是卡片里套面板、面板里套表单。
4. 作为用户，我想要"页标题 > 小节标题 > 正文 > 说明"四级在**每一页**都分得出来，
   以便滚动时能靠标题定位。
5. 作为用户，我想要深色与浅色两套主题是同一套层级，以便按环境切主题。
6. 作为用户，我想要"重点会跳"（选中态、危险操作、主操作）在其余页面也成立，
   而不是只有检测页有。
7. 作为维护者，我想要**"这一页还没做 / 这一页退化了"是机器可判的**，
   而不是靠人翻 470 KB 的样式块。
8. 作为维护者，我想要冻结清单的条目数是**单调下降**的进度尺，任何一次改动后能立刻重跑。
9. 作为维护者，我想要这次改造**不改变任何 id、DOM 顺序与既有类名语义**，
   以便 6 个真浏览器 spec、1800+ 条前端用例与结构钉继续有效（视觉改、契约不变）。
10. 作为维护者，我想要"纯呈现"的效果**只用 CSS 拿到**（原生锚点 / `:target` / `:has()`），
    不往 `ui/` 那四件的**行多重集台账**里加页——上一轮 04 在这里返工过一次。
11. 作为下一轮的人，我想要每页一条可复跑的读数与一张对照图，以便"改好了"有人眼可查的证据，
    而不是只靠"门禁全绿"。
12. 作为下一轮的人，我想要**三条踩过的坑写在明面上**（读数过期、门禁并行、spec 文件混用
    goto 与路由桩），以便不重走一遍。

## 实现决策

### 一、字号角色表（本 spec 的核心契约，落地为守卫文件头的单源表）

| 令牌 | 值 | 角色 | 改前实际取值 |
|---|---|---|---|
| `--fs-page` | 20px | 页面 / 卡片标题、弹层大标题 | 16（`.card h2`）、18、20、16.5 |
| `--fs-block` | 16px | 小节标题、按钮主字、欢迎语标题 | 13（`h3`）、15、16 |
| `--fs-body` | 14px | 正文 / 表单 / 表格单元格 / 行内主字 | 12、12.5、13、14 |
| `--fs-note` | 13px | 次要说明、`.muted`、时间戳、表头 | 11.5、12、12.5、13 |
| `--fs-tag` | 12px | 徽章 / 标签 / 极小字 | 11、11.5、12 |
| `--fs-icon` | 22px | 装饰性图标（空态 emoji、关闭 ✕） | 18、22、30 |

- **按角色判，不按数值换算**：同是 12px，做"正文"的进 `--fs-body`、做"徽章"的进 `--fs-tag`。
  这是本轮唯一需要逐条读语义的地方，也是"抬高地板"（用户拍板）的具体含义。
- **唯一的相对单位例外**：8px 那个上标星号（`.badge` 邻域的 `*`）写 `em`（随父级缩放），
  不进令牌表——上标的正确写法就是相对的。守卫按 px 取值判，em 天然不在它射程内，
  这条边界写进守卫文件头（**不是**绕过守卫，是守卫本来就只管 px 取值）。
- 代码页的 `--code-font-size: calc(13px * var(--code-zoom, 1))` 已经是令牌，
  本轮把它改成从 `--fs-note` 派生（字号台阶整体调整时它跟着走）。

### 二、描边规矩（照检测页 02/05 定稿）

- **一层**：一次可见的视图（一个页面页签 / 一个弹层）内，完整矩形描边只有最外层容器那一条。
- **内层替代**：留白（优先）/ 单条分隔线 / 淡底（`--panel-2`、`--input-bg`）/ 左条（3px 色条 + 淡底）。
- **保留的例外（如实列出，别误读成"页面里只剩一个框"）**：① 语义告警块（"未上板""本平台没这条目"
  这类必须显眼的警示，全页少量）；② 可点控件（平台卡、输入框、按钮、上传区）——那是控件的形状；
  ③ 弹层外壳（弹层自己是一屏，它那一条要留）。
- **分组不搬 DOM**：需要分段时靠新增类名 + 大间距（照 02 的 `.hwcheck-band` 先例）。
- 每页出一份「改前逐层 / 改后逐层」清单（照 02 那张表）。

### 三、守卫与进度尺

- 判据仍住在既有的 `tests/js/css-tokens.test.mjs`（**不另起文件**——上一轮 02 的账记着这条）。
- 新增**分区表**：每页一条作用域谓词（页面 `#tab-*` + 该页组件类前缀 + 该页 JS 渲染的类名）。
  谓词表是本轮"哪一页归哪一单"的单源，也是守卫每条腿的输入。
- **两条进度尺，各自单调**：
  1. **页面尺**（前段下降）：`SITEWIDE_BACKLOG` —— 还没做的页面清单，每 resole 一单摘一条；
     做过的页面由守卫判红（裸字号 ≠ 0 / 冻结清单外的新取值）。
  2. **取值尺**（后段下降）：`FROZEN_FONT_SIZES` —— 某个取值**在全站彻底消失**才摘得掉，
     所以它主要在收尾单清零；清零后 13 条全空 = 本轮完工。
- 守卫判据三条腿照旧扩成四条：① 检测页段裸 px = 0（既有）；② 检测页段裸令牌间距 = 0（既有）；
  ③ **已完工页面段**裸 px = 0（新增，按分区表逐页）；④ 全站取值集合 ⊆ 冻结清单（既有，
  收尾后冻结清单为空 ⇒ 全站零裸 px）。
- **合成红证**：四条腿各注入一次判红、复原转绿，锚点取自真实源码并断言锚点还在。

### 四、契约与改动面

- **不动**：任何 `id`、任何 DOM 顺序、既有类名的语义、任何 JS 行为、宽屏 `max-width`。
- **只新增**：类名（分组带 / 语义标记）、令牌、CSS 规则。
- **JS 面唯一允许的改动**：`static/js/**` 里 7 处**内联样式字符串里的取值**
  （5 个文件，11px / 12px）。契约对账里那条"前端 JS 零改动"随之改成更准的一句——
  **剥掉内联 `style=` 串之后逐字节相同**（机械可判，不是"人看一眼"）。

### 五、切片（详见工单）

**地基 2 单**（01 角色表 + 守卫分区 + 全局文本基类 / 02 全局组件与外壳）+
**厚页 3 单**（03 生成 / 04 代码 / 05 设置）+ **薄页并 2 单**
（06 素材与库五页 / 07 母版库 + 使用指南 + 版本记录）+ **收尾 1 单** = **8 单**。

> 口径修正（2026-09-28，用户拍板）：原计划地基 1 单，实测那一单要改 ~134 条规则、
> 65 处裸字号、77 处描边还要重写守卫——**拆成两单**，拆点在"文本基类"与"全局组件"之间
> （两单各自都能红 → 绿跑完，且第一单就把尺子立起来）。

依赖：01 → 02 → {03…07} → 08；**五张页面单彼此独立**（家族几乎不重叠），
blocked-by 只写 02（地基两单）。每单都是一条**纵向切片**：
改样式 → 跑该页读数与截图 → 摘掉该页在 `SITEWIDE_BACKLOG` 里的那一条 → 门禁全绿。

**验收粒度**（用户拍板）：**按页验收**——每单交付 = 该页裸字号 0 + 一屏一层描边 +
该页暗色整页图 + 该页读数；全量 pytest 只在 08 跑（浏览器门禁另起一次，两者不并跑）。

## 测试决策

- **吃最高既有缝，不新造缝**（本 spec 唯一的新缝就是上面那条分区表守卫，加进既有守卫文件）：
  ① `tests/js/css-tokens.test.mjs` —— 判据纯函数 + 守卫用例 + 合成红证；
  ② **前端门禁** `node --test "tests/js/*.test.mjs"` —— 改静态标记与 CSS 时的主要证据
  （id 契约 / 结构钉 / 令牌纪律都在这一套里）；
  ③ **浏览器门禁** `node --test --test-concurrency=1 "tests/browser/*.spec.mjs"` ——
  `ui-contract.spec.mjs`（向导与折叠态）、`code-tree-click.spec.mjs`（代码页交互）；
  **每单跑一次，且不与全量 pytest 并跑**（本机负载下会抖）。
- **读数量具**（改前 / 改后同一把尺子，每轮改动后重跑——上一轮两条假账都源于"读数过期"）：
  `probe-00`（家底普查，按页面作用域分组）、`probe-01`（字号 / 间距分布，扩成按页分组）、
  `probe-03`（契约机械对账，扩成每页一节：id 集合 / 既有元素顺序 / 类名计数 / 中文文案零删除）。
- **人眼验收 = 每单该页一张暗色整页图**，收尾再出一次浅色全站巡检（用户拍板的口径）。
  截图脚本沿用检测页那支（真浏览器 + 真后端夹具，端口内核分配、跑完自收）。
- **判据边界**（写进守卫文件头）：守卫只判"取值越界 / 该走令牌的走了没有"，
  **不判好不好看**；好不好看只有用户对着截图拍板作数。
- **红证先行**：先把"其余页面碎片化"钉成红（`SITEWIDE_BACKLOG` 非空 + 冻结清单 13 条）→
  逐单转绿；每单的收尾读数与该页截图一起落盘。

## 范围外

- **检测页本身**：已定稿，本轮只跑读数复核（它的读数不许退化，退化了就是本轮引入的回归）。
- **交互与行为**：不新增功能、不改任何 JS 行为；纯呈现的折叠这类若引入，必须有既有用例覆盖的等价行为。
- **宽屏铺太满（`main` 的 `max-width` 与两侧留白）**：上一轮就在范围外，本轮仍不动。
- **文案事实与判据**：不改"说什么"，只改"怎么说、放在哪一级"；中文文案零删除（机械对账）。
- **图标体系 / 字体更换 / 动效体系**：不引入外部资源（本地应用、离线可用是硬约束）。
- **库数据 / 发布包 / `sources/`**：不碰。
- **`ui/` 四件的形状台账**：不加页（见用户故事 10）。

### 三条踩过的坑（上一轮的账，本轮当纪律）

1. **读数每轮改动后都要重跑**：上一轮的两条假账（01 说"裸 px = 0"，02 又写了个 22px）
   都是"读数过期"造成的——**读数不是结论，是那一刻的照片**。
2. **浏览器门禁别和全量 pytest 同时跑**（本机负载下会抖）；
   **同一个 spec 文件里别混用整页 `goto` 与路由桩**（会让文件级抛 `unhandledRejection`，
   而每条用例自己全绿——最难查的一类红）。
3. **`ui/` 那四件有形状钉**（入口只有接线 + 两个导出，且按行多重集对账）：
   纯呈现的效果优先用 CSS（`:target` / `:has()` / 原生锚），别往那份台账里加页。

### 与上一轮的关系

- 上一轮定的令牌与规矩**不改**，本轮只**推广**；若推广中发现某条规矩不成立（比如某页必须两层描边），
  回来改这条 spec 并写清为什么——不改检测页那一版。
- 上一轮的 `probe-01` / `probe-03` 基线钉死在 `bd478720`；本轮沿用同一基线，
  因此读数里同时含"检测页那一轮 + 本轮"的累计差异（对账脚本按页分段，能分开看）。
