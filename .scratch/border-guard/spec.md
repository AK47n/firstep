# spec：描边那条线的机器守卫（把「哪些框算例外」变成可对账的数据）

> 状态：待用户确认工单切分（clarify 已拍三条，见「补充说明 · 拍板记录」）
> 立项日期：2026-09-29
> 上一轮：`.scratch/ui-density-sitewide/`（全站密度轮，01–12 全 resolved，已随 v1.4.0 上线）

## 问题陈述

`ui-density-sitewide` 轮把「一屏一层完整描边」推给了全部十四页，收尾读数落在
**整圈完整框 115 处**——那是逐条申报过的例外（spec ①–⑥）。但这条线**没有机器守卫**：

- 守卫 `tests/js/css-tokens.test.mjs` 有五条腿看着字号与间距，**一条都没看描边**（文件头明文写着不判）；
- 「哪些框算例外」只活在**上一轮七张工单的散文清单**里——机器读不出来，也算不出来
  （08 账第 1 条的原话是"先解决'哪些框算例外'的判据问题"）；
- 于是今天任何人往样式块里写一条 `border: 1px solid var(--border)`，**没有任何东西会红**：
  115 会安静地变成 116、120，只能靠"下一轮的人记得去数"。

**第二处缺口**：`static/js/**` 里还有 **10 处内联的整圈框**（`fx/flash.js` 的指引卡、
`fx/task.js` 的"下一步要做"块、`ui/codeeditor.js` 的诊断浮标（裸色 `#888`）、
`ui/generate-recommend.js` 的题面图片框与警示块、`ui/generate-pins.js` 的图例点与角色标记）。
它们**完全不在 115 的口径里**——08 单给「内联字号」补了第五条腿，描边这一面对称地空着。

**第三处是口径混读**（08 账第 1 条与 `local-environment` 都点过名）：115 这个数里
**21 处在默认态根本画不出框**（12 处 `1px solid transparent` 占位 + 9 处用 border 画的
圆点 / 字形 / 滚动条）。把它们与"真框"混成一个数，是"115 到底多不多"一直说不清的原因。

## 方案

一句话：**不判"这条框该不该留"（机器判不了），改判"这条框是不是被登记过的"**——
把逐条申报的散文清单升级成一份**可对账的数据**，再让守卫双向对账。

1. **描边登记簿**（`BORDER_REGISTER`，**115 条**）：每条 = `[作用域, 选择器, 类别]`。
   选择器取**剥掉前导块注释、空白归一**后的形态（与守卫 `scopeOf` 同一口径）——
   这才是稳定的认人键；原始选择器前面挂着大段块注释，拿它当键等于把注释一起冻进表里。
2. **类别表**（`BORDER_KINDS`，**10 类**）：每类一句判据，回答"这一类为什么可以留框"；
   每个类别在表里都要有成员（空类别 = 判据退化成摆设，当场判红）。
3. **守卫加两条腿 + 合成红证**（住在既有的 `tests/js/css-tokens.test.mjs`，**不另起文件**）：
   - **腿⑥（样式块面）**：盘上每个整圈完整框都能在登记簿里认到人（⊆）；
     登记簿里每条都能在盘上认到（⊇，**防腐烂**）；`placeholder` ⟺ 取值含 `transparent`
     （**抓"透明占位偷偷变成真框"**）；类别表形状自检。
   - **腿⑦（渲染方面）**：`static/js/**` 里内联的整圈完整框同样逐条登记、双向对账。
4. **读数是可复算的照片**：登记簿由探针**从守卫源码解析**（单源，照 `load_scopes` /
   `load_backlog` 先例），报"登记簿 ↔ 盘上"的双向差、每类条数，以及**口径分列**
   （115 总声明 / **94** 可见框 / **21** 非框）与一条"悬停态框"的脚注读数。

## 用户故事

1. 作为维护者，我想要**往样式块里新写一条整圈框会当场判红**，以便"一屏一层"这句话不是只靠自觉。
2. 作为维护者，我想要判红的文案直接告诉我**该往登记簿里加哪一行**（作用域 + 选择器 + 类别），
   以便被拦下的时候不用去翻上一轮的七张工单。
3. 作为维护者，我想要**改了选择器名 / 删了规则时登记簿会过期判红**（反向对账），
   以便这份数据不会烂成"表里 115 条、盘上 108 条"的假账。
4. 作为维护者，我想要**去掉一条框时也必须同步摘掉登记项**，以便登记簿的每一条都对应盘上真有的东西。
5. 作为维护者，我想要**"透明占位变成可见框"这一条路也堵上**，因为那是往页面里加框最常见的一条路。
6. 作为维护者，我想要每条登记项都**带一个类别**（而不是一个光秃秃的选择器名单），
   以便"为什么它可以留"和"它是什么"一起被冻住，评审能逐条追问。
7. 作为维护者，我想要**类别表本身也有形状判据**（每类至少一条、类别值必须已登记），
   以便"新造一个类别把框塞进去"这条后门也有关卡。
8. 作为维护者，我想要**渲染方（`static/js/**`）那一面也被看着**，以便内联写出来的框不会绕过守卫
   （08 单给内联字号补腿的先例）。
9. 作为下一轮的人，我想要**115 这个数里"可见框 / 非框"分列**（94 / 21），
   以便不再把"透明占位"读成"页面里还有 115 个框"。
10. 作为下一轮的人，我想要**悬停 / 选中态出现的框有一条明写的口径边界**（不在射程内，为什么），
    以便不把"占位变高亮"误判成漏网。
11. 作为下一轮的人，我想要这两条腿各自带**合成红证**（注入 → 判红 → 复原转绿，锚点取自真实源码），
    以便"永远绿"的摆设腿进不来（守卫的既有先例）。
12. 作为下一轮的人，我想要**读数能一条命令复算**（登记簿 ↔ 盘上双向差 + 每类条数），
    以便"绿得可疑"时能自己验一遍，而不是相信票面。
13. 作为用户，我想要这一轮**不改任何观感**（产品面零改动），以便升级只是"多了一道闸"，
    不是"界面又变了"。
14. 作为维护者，我想要**上一轮的散文账本被回改标记**（sitewide README 的「判断边界」① 与
    08 账第 1 条），以便下一个人读到的不是"这条还没做"的过期措辞。

## 实现决策

### 一、登记簿与类别表（本轮的核心契约，落地为守卫文件里的两张单源表）

**登记项形状**：`[作用域, 选择器, 类别]`，选择器已剥注释、空白已归一；按作用域分组书写
（读起来就是"哪一页留了哪些框"），组内保持盘上出现顺序。

**类别表（10 类，条数即分布）**：

| 类别 | 条数 | 判据（人判，机器不重推） |
|---|---|---|
| `block` | 3 | **顶层块**：一屏里自成一块的容器（`.card` / 就绪总览条 / 最近生成汇总条）——"一屏一层"说的就是它们 |
| `control` | 38 | **可点控件**：按钮 / 输入 / 下拉 / 勾选框 / 可点卡片 / 可点 chip / 标签页 |
| `tag` | 15 | **徽章与标签**：不可点的身份 / 计数 / 图例胶囊（平台徽章、序号圈、图例件、KBD） |
| `alert` | 19 | **语义告示块**：带警示 / 状态语义的告示（编译条、未选功能组、未上板、"服务已停止"、保存失败、步骤提示） |
| `modal` | 8 | **弹层外壳**：弹层 / 菜单 / toast——它自己是一屏 |
| `float` | 3 | **浮在内容之上的自己的面**：悬浮保存条、只读标注、缩放浮标 |
| `doc` | 6 | **文档与表格语法**：表格网格线、md 预览的表格与图片框、指南表 |
| `editor` | 2 | **编辑器形状**：代码编辑器本体与它的悬浮工具条 |
| `nonbox` | 9 | **不是框**：用 border 画的圆点 / 对勾字形 / 转圈环 / 滚动条 thumb |
| `placeholder` | 12 | **透明占位**（★ 唯一带机器不变量）：取值含 `transparent`，默认态画不出框，给悬停 / 选中态留位置 |

**`placeholder` 的不变量**：`类别 == "placeholder"` **当且仅当** 取值含 `transparent`。
两个方向都判——这是"透明占位偷偷变成真框"唯一的机器抓手。

**类别可判性的边界（明写）**：机器只判"这条框有没有被登记、类别值在不在表里"，
**不重推类别**。"这是语义告示还是内层框"是人判的，写在登记项里；
守卫只保证它被显式判过一次、且不会静默变化。

### 二、守卫的两条腿

- **腿⑥（样式块面，判据纯函数）**：
  1. 盘上完整框集合（按 `(作用域, 选择器)`）**⊆** 登记簿；
  2. 登记簿 **⊆** 盘上（反向，防死条）；
  3. `placeholder` ⟺ 取值含 `transparent`；
  4. 类别表形状：每条登记项的类别必须在 `BORDER_KINDS` 里；每个类别至少一条。
  - 认人对齐：两侧都取**剥注释 + 空白归一**后的选择器（守卫 `stripLeadComments` /
    探针 `scope_lib` 同一口径，`probe-02` 已实测两侧在描边这一面**逐条相同**——整文件解析
    与 `<style>` 块解析的规则数差 14 条，但**都不含完整 `border:` 声明**，故不引入分歧）。
- **腿⑦（渲染方面）**：`static/js/**` 里内联的整圈完整框（`border:` 简写、值非 none/0）
  逐条登记为 `[文件, 锚点片段, 类别]`，同样双向对账。锚点取**该声明所在行的可认片段**
  （类名 / id / 变量名），不取行号——行号会随插行漂，锚点不会。
- **合成红证**（两条腿各自）：注入新框 → 判红；改一个已登记的选择器 → 判红；
  删一条已登记的规则 → 判红；把一条 `placeholder` 的取值改成可见 → 判红；
  塞一个未知类别 / 掏空一个类别 → 判红；**复原后逐条转绿**。锚点取自真实源码并断言锚点还在
  （04 账第 11 条：锚点别带令牌值）。

### 三、读数与口径

- **口径不动**：`full_borders`（完整 `border:` 声明、值非 none/0）就是锚，115 这个数保持可比。
  新函数**站在它上面**（只加"剥注释 + 归类别人"这一步），不改它的判据。
- **口径分列**：115 = **94 可见框** + **21 非框**（12 `placeholder` + 9 `nonbox`）。
  写进读数与守卫注释时**连"这是哪个口径"一起写**（那轮纪律 3：两个口径混着读是第二常见的误判）。
- **脚注读数**：21 处非框里有几处在 `:hover` / `.active` / `[aria-*]` 状态下会拿到框
  （`border-color` 单声明不是"完整框"，**本来就不在口径内**）——量出来写清楚，
  免得下一个人把它读成漏网。
- **读数每轮重跑**：提交前落盘读数的时间戳必须晚于最后一次改产品面（本轮产品面零改动，
  但仍按纪律重跑）。

### 四、契约与改动面

- **产品面零改动**：不改 `index.html` 一个字节、不改 `static/js/**`；
  两条腿是"加闸"，不是"改观感"。唯一的例外是评审在登记过程中发现某条框本就不该留
  （那时按 spec 记账、单独说清，不允许顺手改）。
- **只新增**：守卫文件里的两张表 + 两条腿 + 红证；`.scratch/border-guard/` 下的探针与读数。
- **`scope_lib.py` 是扩展不是重写**：加"读登记簿 / 读类别表"与"带作用域与归类的完整框"两个入口
  （照 08 单给 `scope_lib` 加 `load_backlog()` 的先例）；既有函数判据一字不动。

## 测试决策

- **吃最高既有缝，不新造缝**：
  1. `tests/js/css-tokens.test.mjs` —— 判据纯函数 + 守卫用例 + 合成红证（本 spec 唯一的新缝就在这里，
     与 FROZEN_FONT_SIZES / PAGE_SCOPES / SITEWIDE_BACKLOG 同一处）；
  2. **前端门禁** `node --test "tests/js/*.test.mjs"` —— 改守卫文件时的主要证据；
  3. **全量 pytest** `python -m pytest -n auto -q` —— 收口一次（改 `tests/js/**` 时 pytest 面看不见它，
     但仓语言/编码等结构用例仍要过）；
  4. **浏览器门禁** `node --test --test-concurrency=1 "tests/browser/*.spec.mjs"` ——
     本轮产品面零改动，跑它是**"没退化"的独立读数**；**不与全量 pytest 并行**（那轮纪律 2）。
- **读数量具**：`.scratch/border-guard/` 下的探针（一条命令复算登记簿 ↔ 盘上双向差 + 每类条数 +
  口径分列）。探针的认人键必须与守卫**同源**：登记簿从守卫源码解析，不另抄一份。
- **判据边界（写进守卫文件头）**：守卫只判"这条框登记过没有 / 类别值合不合法"，
  **不判"该不该留"**、不判好不好看；`border-color` 单声明与悬停态边框不在射程内。
- **红证先行**：先让"盘上某条框不在登记簿里"钉成红（拿一条不登记的框注入），再转绿。

## 范围外

- **不改任何观感**：不删框、不加框、不调描边颜色；这一轮只立数据与判据。
- **不改 `scope_lib.full_borders` 的既有判据**（115 必须保持可比）；新入口站在它上面。
- **悬停 / 选中态出现的框不纳入射程**（`border-color` 不是完整框声明）——如实量、如实记边界。
- **`--accent` 小字在浅色下 3.39:1 与"去框留淡底"×1.06**（`backlog.md` §27 另一条账）：
  调色板级决定，本轮不碰。
- **`.pdf-*` / `.lib-*` 两处跨页前缀的谓词归属**：sitewide 08 账第 8 条判过"按第一命名页保留现状"，
  本轮不改（要动的唯一理由是"哪条腿看着它"，属另一轮的口径讨论）。
- **不改 `static/js/**`**：腿⑦ 只**读**渲染方，不顺手动那些内联框（发现该去框的另开单）。
- **库数据 / 发布包 / `sources/`**：不碰。

| 115 条登记数据放哪 | **守卫源码内**（照 `FROZEN_FONT_SIZES` / `PAGE_SCOPES` / `SITEWIDE_BACKLOG` 先例，第四张表同一处）；探针从守卫源码解析，格式变化大声失败 |

### 三种被否掉的方案（记下来，免得下一轮重走）

1. **只认选择器**（不判透明）：最省事，但"透明占位改成可见框"抓不到——那正是往页面里加框
   最常见的一条路（`.code-tab` 这类占位一改就是一条真框）。
2. **`(作用域, 选择器, 完整取值)` 全等**：最严，连描边换色 / 换令牌都要改 115 行的表；
   与那轮"守卫不判好不好看"的边界相冲，且表容易因噪音被削弱。
3. **类别谓词现算**（守卫按正则判类别，不逐条登记）：数据小，但谓词必然写宽
   （`button` 一条就能吞掉一切未来按钮），宽谓词就是后门；而且"这是语义告示还是内层框"
   本来就判不了，硬判出来的绿是假的。

### 与上一轮的关系

- 上一轮定的观感**一个字不改**；本 spec 只把它"逐条申报过的例外"从散文升级成数据 + 闸。
- 上一轮的散文档（`spec.md` 的 ①–⑥、七张工单的逐层清单）**仍是类别的出处**——
  本轮的类别表就是它们的机械化，登记项的类别判定照那些清单复核。
- `probe-00` / `probe-01` / `probe-04` 的读数**不许退化**：115 这个数在本轮前后必须逐字相同
  （产品面零改动的机器证明）。
