# 代码查看器：.md 文件渲染预览

## 问题陈述

「代码」tab 的代码查看器（IDE 式只读工程浏览）里打开 `.md` 文件时，只能看到纯文本（`languageOf` 判定只有 c/xml/plain，.md 走 plain → 白底等宽 pre）。用户实际要看的 .md（生成工程的 README.md、技术方案.md、赛题原文.md 等）包含标题、表格、代码块、任务清单、引用、加粗、本地图片——纯文本下全部失效，没有 VSCode 打开 .md 时那种排版效果。

## 方案

代码查看器对 .md 文件默认渲染预览（对齐 VSCode Ctrl+Shift+V 体验）：标题层级、段落、围栏代码块（fence 语言复用既有高亮）、引用、有序/无序/任务清单、管道表、水平线、行内粗体/斜体/行内码/删除线/链接、本地相对路径图片。预览无行号 gutter、无行高亮。

检出两个既有的相关线索：① `sources/contest/2026C/规格书.md` 等文档用 `![图片](images/*.png)` 引本地图片，预览必须能把图片显示出来 → 需要新增后端图片二进制端点；② 预览与「行号」语义冲突（搜索结果跳行 / Ctrl+F 过滤依赖行号）→ 采用「默认预览 + 临时源码态」两态：点搜索结果或 Ctrl+F 时自动临时切到该文件原始文本（带行号）定位/过滤，界面提供「返回预览」，重新点树内文件也回预览。

## 用户故事

1. 作为用户，我在代码查看器打开目录后点击 .md 文件，想看到渲染排版（标题/表格/代码块/清单/引用/加粗），以便像 VSCode 预览一样快速阅读文档。
2. 作为用户，我想 .md 里以相对路径引用的本地图片能显示（如规格书 images/*.png），以便预览完整还原文档。
3. 作为用户，我想 .md 的右侧大纲显示文档标题，点击可在预览内滚动定位，以便长文档快速导航。
4. 作为用户，我想点跨文件搜索结果（命中 .md）时自动切到该文件原始文本并定位到命中行，以便知道命中上下文。
5. 作为用户，我想在 .md 预览里按 Ctrl+F 时自动切到原始文本过滤，以便在行语义下查找定位。
6. 作为用户，我想临时源码视图下能一键「返回预览」，重新点树内文件也回预览，以便不会困在无排版视图。
7. 作为用户，我想非 .md 文件（c/h/xml/txt…）行为完全不变，以便既有浏览零回归。
8. 作为用户，我想 .md 里的 HTML 标签 / 脚本 / 危险 URL 不被执行或注入，只按文本显示，以便预览安全。
9. 作为用户，我想 Ctrl+滚轮缩放在 .md 预览里同样生效，以便排版尺寸可调（与代码视图一致）。
10. 作为用户，我想上级目录（../）或绝对/协议图片路径不被请求、渲染为可读占位，以便坏引用不炸界面。

## 实现决策

- **渲染器自研**：仓库前端零 npm 依赖、零构建（static ESM 直供），既有先例全是自研轻量纯函数（cHighlight / highlightXml），故新增纯函数模块（fx/markdown.js）：字符串进、HTML 出，所有原文先 esc（杜绝注入）。语法覆盖 = 仓库实际语料 + CommonMark 常用子集：ATX 标题（#~######，可带闭井号）、段落（软换行 = 空格）、围栏代码块（``` 带可选语言，语言经既有 highlightText 单源再高亮；未闭合围栏兜底到文末）、引用（> 连续行）、有序/无序列表（含嵌套缩进）、任务清单（- [ ] / - [x] → 禁用 checkbox）、管道表（表头 + --- 分隔行 + 数据行，单元格再过行内解析）、水平线（---/***/___，与表格/列表歧义消解：表上下文按表、独立成段按 hr）、行内 `code`/粗体/斜体/删除线/链接/图片。
- **安全立场**：不透传原始 HTML（`<b>` 等原样转义显示）；URL 协议白名单（http/https/mailto/#/相对路径；javascript:/data:/vbscript:/file: → 文本兜底）；图片 alt 转义。
- **图片寻址**：纯函数不感知目录与后端端点——渲染器接受注入的 imageUrl(src) 回调产出 `<img src>`；相对路径以**所引用 .md 文件所在目录**为基准（VSCode 语义），胶水层拼 dirname(path) + src 后再归一（`../` 跨出打开根、绝对路径、协议路径 → 拒绝并渲染占位文本）。
- **单遍块扫描**：解析层产出带 1 基行号的块列表（parseMarkdownBlocks），预览 HTML 与 .md 大纲标题清单（markdownOutline）都从它投影——两份投影不重复解析、行号不漂移；标题等块级元素带 data-md-line 供预览内滚动定位。
- **语言路由单源**：languageOf 增 .md/.markdown → "md"；highlightText 对 md 仍回退 plain（临时源码视图 = 纯文本行号视图，不另做 md 源码高亮——预览才是重点）；前端以 lang==="md" 判定预览/源码两态，不引入第二份扩展名清单。文件 tab 徽标补「MD」。
- **两态视图**：打开 .md 默认预览（无行号 gutter、无行高亮、无当前行点击）；进入临时源码态的入口 = 跨文件搜索结果跳行 / Ctrl+F 文件内过滤（行语义需要行号）；源码态渲染既有行号 gutter 视图（plain），顶栏文件标签旁出现「返回预览」小按钮；重新点击文件树内该文件也回预览。其余交互（搜索面板、Ctrl+F 过滤、跳行 flash）在源码态与原行为一致。
- **大纲**：.md 右侧栏显示标题清单（kind=heading，徽标 H），点击 = 预览内 scrollIntoView + flash（复用 data-md-line）；源码态 = 既有按行跳转。现有「大纲仅 .c/.h 提供」的空态文案随 .md 支持同步更新。
- **图片后端端点**：新增 GET /api/code/raw?dir=&path=（域函数：read_code_file_bytes）。安全判定与 read_code_file 同一组（is_unsafe_path 单源 + resolve 在根内 + 文件存在）；扩展名白名单 png/jpg/jpeg/gif/webp/bmp/ico/svg；上限 8MB（超限 400 中文）；media_type 手写映射（不依赖 mimetypes 的平台差异）；返回图片字节 + Cache-Control private max-age=3600（打开目录只读、生成物不变，减少重复读盘）。错误一律 400 中文（复用 CodeViewError）。
- **CSS**：.code-md-preview 排版体系（标题梯度字号与边距、表格边框合并 + th 底色、代码块底色/等宽字体、引用左线、列表/任务勾选、hr、img max-width:100%、链接颜色 hover）；根字号 = calc(15px * var(--code-zoom,1))——复用 Ctrl+滚轮缩放（标题等用 em 相对联动）。表头 sticky 不做（范围外）。
- **零写侧 / 零新依赖**：后端只增只读端点；不加 npm 依赖、不加构建步骤；c/xml/txt 文件路径行为不变。

## 测试决策

- **纯函数单测（node:test + assert/strict，无 DOM）**：新增 tests/js/markdown.test.mjs——块解析与行号（标题各层级/闭井号/段落/围栏含未闭合兜底/表格/列表嵌套/任务清单/引用/hr）、行内解析、转义与 XSS（`<script>`、javascript: URL、属性注入断言不产生执行形态）、URL 白名单、imageUrl 回调映射（相对/./、../ 拒绝、http(s) 直通）、markdownOutline 投影一致性；highlight.test.mjs 补 languageOf("x.md")→"md"（及 .markdown）；codeview.test.mjs 补 MD 徽标。
- **后端 pytest**：tests/test_codeview.py 补 read_code_file_bytes（白名单命中 / 非图片拒绝 / 路径穿越 / 大小超限 / 文件缺失 / NUL 与二进制防护语义沿用）；tests/test_webapp.py 补 /api/code/raw 端点（200 + media_type 断言 + 400 中文 + 参数缺失）。
- **回归**：全量 pytest 与 node --test tests/js/*.test.mjs 全绿；胶水层（两态切换/返回预览/大纲滚动）无 DOM 测试基建，按仓库惯例走既有 CDP 冒烟脚本补 .md 预览/临时源码/返回预览/图片步骤 + 手动验收。

## 范围外

- 参考文件行内预览（reference.js 的 ref-files-viewer）的 .md 渲染——用户点名「代码查看器」，参考文件文本预览保持现状。
- .md 源码态的语法高亮（临时源码视图 = 纯文本行号视图）。
- 缩进代码块 / 脚注 / GFM 对齐 / HTML 透传 / mermaid / KaTeX / 自动目录 / 预览内搜索定位。
- 任意二进制文件预览（raw 端点仅服务图片白名单）。
- 编辑/写侧改动、缓存层、新依赖、构建步骤。

## 补充说明

- 图片通常来自 docx 转换（如 image_rId7.png），md 与 images/ 同根直接可用；md 在子目录时相对路径含子目录前缀，按「md 所在目录」基准天然正确。
- 预览为纯展示；行号相关交互（搜索结果跳行、Ctrl+F）统一走临时源码态，避免渲染 HTML 与行号错位的复杂映射。
- 该功能与既有「代码字号缩放」「树宽拖拽」等互不干扰：预览容器挂同一 #code-viewer，缩放变量写容器 inline，innerHTML 重渲染不影响设置。
