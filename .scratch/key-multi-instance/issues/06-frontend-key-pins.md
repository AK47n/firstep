# 06 — 前端：实例选脚候选按模块首 pin 类型（gpio_in）

**要做什么：** key 实例在板图上能正确选脚：实例选脚模式（点板图 IO 脚直接绑
目标实例）的候选与提示文案从硬编码「gpio_out 能力」改为按模块首 pin 角色类型
（key = gpio_in，led = gpio_out 不变）；key 多实例卡自动出现并可增删改、改名、
回填，实例随 expanded 全集出入。

**被谁阻塞：** 02（manifest 生效即前端自动识别多实例）。

**状态：** resolved

`<input list>` 组合框——自由文本（工单验收原字）+ 建议（策略表投影），消除
「工单自由文本 vs 下拉」矛盾与回退路径双空选项缺陷；② 选脚能力改消费后端
expand 端点透传的 `multi_instance.pin_capability`（策略表权威投影），前端不再
按引脚角色重推导（消除 Divergent Change、单源弱化）；③ 后端透传 variants +
