**要做什么：** 实例展开对 key 生效：策略表加 key 行（内置变体 start/stop/mode/set →
KEY_START/KEY_STOP/KEY_MODE/KEY_SET、同名第 2 次起 _2 后缀、词表外/空 → KEY_1..N；
首实例 = 平台默认键脚 stm32 PB3 / mspm0 PA2；其余 board 顺序首个可用 gpio_in 脚，
同模块去重）；AI 没猜实例时 key 实例卡预填 1 个默认实例（显示名「按键」、变体
start），实例上限守卫与解析校验自动覆盖 key。
