# 01 — 装载清单只留在用的名字，并由守卫钉住

**要做什么：** 页面打开后行为一字不变，但 HTML 里那张模块装载清单不再包含宿主用不到的名字
（337 → 78 个具名 + 5 条纯装载），靠加载接线的 ui 模块改成裸装载把"加载即接线"写成代码，
并新增一条结构守卫让"导入了却没用"当场变红。

**被谁阻塞：** 无——可立即开始

**状态：** resolved

## 判据（本次单源）

`tests/js/import-usage.mjs` 的 `unusedImports`：`import` 语句里具名的符号，必须在宿主脚本
**正文**里出现；正文 = 宿主脚本块（`<script type="module">` … `</script>`）去掉 import 语句与
整行注释。方向保守：判为未使用的名字在正文里**零出现**，不存在"其实在用却被删"。
（标识符边界不能用 `\b`——`$` 非 word 字符会恒假，实测踩到。）
