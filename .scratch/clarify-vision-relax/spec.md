# Spec：AI 推荐少问能从题面/图里找到答案的问题（判定放宽 + 澄清提示词补强）

## 问题陈述

用户真机取题面 2021F 点 AI 推荐，被问 3 个问题，全部能从已有素材找到答案。
用户原话：「这三个问题都是应该AI从之前的图片中就能找到答案的所以说还是在
对于图片识别这一方面我不是很满意」。逐条验证（对照真实 2021F 题面与现状
判定逻辑）：

- Q1（走廊尺寸/门口区域坐标/图1的5cm 指什么）：点名「图1」∩ 题面引用图1
  ∩ 关键词命中 → **现状已可视觉消化**（真机被问是当时版本旧，无图注/无
  视觉问答）。
- Q2（数字标号纸张放置位置/距交叉口多远/能否识别数字判方向）：未点名
  「图N」→ 现状漏判直接问用户；答案藏在渲染页里（正文规定纸张放置 +
  图1 布局）。
- Q3（取药流程/红灯含义/要不要返回/总时间到哪为止）：未点名「图N」且
  关键词不命中 → 现状问用户；答案全在题面正文（发挥部分（2）流程与计时
  起止明文）。

## 方案

1. **判定放宽**：「可视觉消化」的合取条件从「问题点名图N ∩ 题面引用图N
   ∩ 图内信息关键词」放宽为「**题面引用过图** ∩（**问题点名题面引用过的图N**
   ∨ **命中图内信息关键词**）」——未点名图但问的是图内信息（走廊/门口/位置/尺寸
   等），也交给视觉通道从原题渲染页找答案。安全网不变：视觉答不上（否定
   词/空答案）→ 照旧转问用户；视觉描述已缓存，每问题最多一次调用。
2. **澄清提示词补强**：题面已写明的流程/时序/指示灯含义/计时起止规则绝不
   重复问（Q3 类问题从源头不生成）。

## 用户故事

1. 作为参赛学生，AI 推荐环节被问的图内信息问题（如数字纸张放置位置、
   走廊距离），只要题面引用了图，AI 应自己从原题 PDF 页里找答案，而不是
   问我。
2. 作为参赛学生，题面正文已写明的流程（谁先谁后、指示灯含义、总时间
   起止）不应再被 AI 当作缺失信息问我。
3. 作为参赛学生，AI 从图中确实找不到答案时（如规则性判断），仍然问我，
   不瞎猜。

## 实现决策

- 判定函数放宽为两条件合取：题面引用过图 ∧（问题点名**题面引用过的**图N ∨
  命中关键词）；图号按编号求交（防「图1/图10」子串误命中，保守方向不变）；
  关键词表保持单源（既有表不变）。
- 澄清系统提示词增加「流程/时序/指示灯含义/计时起止」禁止重复问条款。
- 视觉消化失败路径、推荐事件流、澄清历史结构零改动。

## 测试决策

- 判定函数用例组：点名图（保持可消化）、未点名但关键词命中且题面有图
  （新可消化）、未点名且关键词不命中（不可消化）、题面无图引用（不可
  消化）。
- 真实问题回归：2021F 题面 + 用户提供的真机 3 问原文，断言判定结果
  （Q1/Q2 → 可消化、Q3 → 不可消化走澄清）。
- 提示词契约测试：澄清系统提示词含流程条款。
- 全量 pytest 绿 + mypy 干净。

## 范围外

- 不改视觉问答的实现（渲染/描述/否定词过滤/缓存）。
- 不改澄清问题的生成流程、数量上限与收敛循环。
- 不换模型、不改关键词表内容。

## 补充说明

- 验证素材 = 用户提供的真机 3 问原文 + 2021F 条目题面（正文含 Q3 全部
  答案；`[图1 标注：…]` 图注在文末）。
- 成本：放宽后每个命中问题多一次缓存视觉调用（描述键已按图片字节+提示词
  缓存）。
