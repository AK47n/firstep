工单 ci-gate-fixes/02+03 评审整改：夹具种子配置补死端口 base_url、断言锚点收紧、两单收口

双轴评审的整改一次落。三件**改行为**的：

- `tests/browser/server.mjs`：种子配置补 `base_url = http://127.0.0.1:9/v1`（死端口）。
  评审抓到的问题是真的——原种子配置漏写 base_url ⇒ 落到 `DEFAULT_BASE_URL =
  https://api.deepseek.com`，于是**一条没被 spec 的 `page.route` 拦住的 LLM 路径会真出网**
  （假 key 换回 401）。并纠正一处失准注释：**拦截不在夹具里**，那是各 spec 自己的
  `page.route`（module-intro / code-tree-click）；夹具没有"拦端点"这个职责。
- 同文件：两个种子目录先 `existsSync` 校验——布局改名时当场报"种子库不存在"，
  而不是后端起得来、库端点 400、哨兵误报「端口上是旧后端」。
- 同文件：清理钩子加 `SIGINT`/`SIGTERM`（Ctrl-C / 被强杀；排查时正是在反复 Ctrl-C）；
  **`SIGKILL` 覆盖不到**，在工单里如实记下这条限度，不假称已覆盖。
- 两处 CRLF 断言锚点从 `[^\n]*\n\s*` 收紧成 `[^\n]*\r?\n[ \t]*`：`\s*` 能跨空行，
  等于把"两处相邻"放宽成"隔多远都行"（工单 03「断言强度不缩水」那条）。
