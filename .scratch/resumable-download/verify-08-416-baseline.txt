载荷：307200 字节

## 用例一：服务器**恒**回 416（本地半成品坏死在这一卷上）
   铺 102400 字节半成品；带 Range 的请求恒 416，不带 Range 正常
   实测 error='HTTPError: HTTP Error 416: Range Not Satisfiable'
   实测 请求数=1 / 最终 sha_ok=False / 半成品在盘=102400 / 边车在=True
   → 「删掉半成品、从 0 重下并成功」**不成立（现状：卡死）**

## 用例二：服务器**第一次**带 Range 回 416，之后正常
   （= 服务器上的文件曾经变小过；客户端半成品偏大）
   实测 error='HTTPError: HTTP Error 416: Range Not Satisfiable'
   实测 请求数=1 / 最终 sha_ok=False
   → 「清掉重来一次就好」**不成立（现状：一次 416 就判死）**

## 用例三：本地半成品比清单还大（不经过网络就能判）
   实测 error='DownloadLocalCorruptError: 本地文件比远端还大（本地 311296 / 清单 307200 字节）'
   实测 请求数=0 / 最终 sha_ok=False
   → 「删掉坏的、从 0 重下并成功」**不成立（现状：判死）**

## 用例四：分类函数对 416 的判定
   is_retryable(416) = False
   describe_network_error(416) = '服务器说请求的字节范围不合法（本地记录与远端对不上）'
   → 「416 不当可重试的网络错误」成立
   （口径：416 的本地补救在 _attempt 里只做一次；再做还是 416，当可重试就变成每 60 秒撞一次墙的安静死循环）
