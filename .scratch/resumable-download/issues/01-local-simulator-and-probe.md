# 01 — 真网络判据：本地可控 HTTP 服务器 + 探针骨架（先红后绿）

**要做什么：** 让「断点续传在真 socket 上确实成立」这条判据**可重复、可复现、可反证**——
不必靠拔网线，也不必靠运气撞上真实的网络抖动。

本单只交付**判据本身**（模拟服务器 + 探针 + 预登记的红基线），**不实现续传**：
探针在这一单结束时**是红的**，红在哪、为什么红，逐条写进证据文件。
这样下一单（02）做完时，绿是**被同一套判据判出来的绿**，而不是自己新写一套判据自己通过。

**被谁阻塞：** 无——可立即开始。

**状态：** resolved

- [x] `.scratch/resumable-download/sim-server.py`：本地 HTTP 服务器，支持 `Range`（`206` + `Content-Range`）
      与 `416`，按开关切换六种行为：`stable` / `ignore-range`（恒返回 `200` 整份）/ `cut`（发 N 字节后断流）/
      `stall`（发 N 字节后不再发也不关连接）/ `deadline`（先睡 N 秒再发）/ `slow`（限速）；
      载荷用确定性伪随机字节，**每次启动打印载荷 SHA256**
- [x] `.scratch/resumable-download/probe-01-resume.py`：五个用例依次跑
      （①稳定 ②连断 ③卡死 ④服务器忽略 Range ⑤慢后恢复），每个断言三件事：
      **续传起始偏移**（取自服务器请求台账的 `Range`）、**重试次数如实**、**最终 SHA256 == 期望**；
      输出 `verify-01-baseline.txt` + `verify-01-baseline.json`
- [x] 预登记红基线如实记下（`verify-01-baseline.txt`）：**总判 FAIL**，且红在两处——
      `cut` / `stall` 两例**被截断却自称成功**
- [x] **反证**（`probe-01-negative.py` → `verify-01-negative.txt`）：
      对照实现 = 「每次尝试前丢弃半成品」，probe 判据一行未改；结果 cut/stall 转红、
      请求起始偏移序列**全为 0**（证明「续传」判据真的在工作），退出码 1
- [x] 服务器用完即停、端口释放（默认 8031，`--port 0` 由内核分配），临时目录 `%TEMP%` 自动清理

## 验收记录（2026-09-13）

**判据交付了，且在交付的那一刻就是红的**——这正是本单的目的（先证明判据会红，再用它判绿）。

**探针抓到一件比预期更硬的事（本单最大产出）**：

| 现象 | 证据 |
|---|---|
| 断流后 `download_part` **返回成功**，没有任何异常 | `verify-01-baseline.txt`：`cut 尝试 1 次 → ok，落盘 838860/2097152` |
| 根因 | 它以「每次读 256 KB、读到空为止」收工，**从不校验 `Content-Length`** |
| 用户视角后果 | 进度条 100% → 判「校验失败」→ 半成品被删 → 从头再来；**「断」这件事根本没被识别** |

这条已回写进 spec（问题陈述第 4 条 + 断点契约表两行）与工单 02 的验收标准
（截断必须失败；清单 size 与对端总长矛盾则不可重试）。

**反证的两条命题**（`verify-01-negative.txt`）：

- 命题 A「从断点接着下」**判得到**：对照实现的请求起始偏移序列全是 0，判据转红。
- 命题 B「被截断却自称成功」**判得到**：红的理由写的正是这句。

**本单没做的事**（留给 02）：`deadline` 模式已实现但未列入五用例——它的判据（长时间零字节）
与 `stall` 重复，等 02 有了「数据不动了」的看门狗再补一例更划算。

## 备注

- 不进 `tests/`：真 socket + sleep 会让 CI 变脆；行为判据由 `tests/test_download_resume.py`（工单 02）覆盖，
  本单只回答「真 socket 上确实如此」。
- 反证的写法遵本项目惯例（`.scratch/tracker-audit` 记过多次「判据本身失效导致的假绿」）：
  **先证明判据会红，再用它判绿。**
- `stall` 模式的服务器兜底等待定在 8 秒（不是两分钟）：卡死用例要的是「对端零字节」，
  探针不必真等两分钟——第一版写 120 秒，实测把探针拖慢了 15 倍。
