# 立创wiki 资料抓取（工作记录）

## 做了什么

从 [立创开发板技术文档中心](https://wiki.lckfb.com/zh-hans/dmx/) 抓取**地猛星 MSPM0G3507 模块移植手册**全部 70 页（VuePress 站点）：

- 分类：screen 12 / sensor 41 / rf 7 / control 10
- 每页转成 Markdown：正文（模块来源/规格参数/移植过程/移植验证）+ 完整 C 代码块（3-4 个）+ 百度网盘链接与提取码
- 产出：`sources/materials/lckfb-地猛星移植手册/`（资料库批次，gitignore 不入库）
  - `<分类>--<slug>.md` × 70
  - `模块索引.md`（70 页清单：原页/代码数/网盘数）
  - `网盘索引.md`（126 个百度网盘链接，含 `?pwd=` 提取码）
  - 总量 17 MB

## 工具

- `fetch_wiki.py`：抓取脚本（可重跑 `--force` 全量 / `--only` 单页 / `--limit` 调试）
  - 幂等：已存在的 `.md` 跳过；UTF-8 输出强制（Windows GBK 控制台会崩）；
  - url 列表：`module-urls.txt`（BOM 已兼容，读时 `utf-8-sig` + lstrip）
- `module-urls.txt`：70 个页面 URL（已去重，来自主入口 + 0.96 彩屏页并集）

## 已知限制

- **正文图片为 0**：VuePress SSR 不在服务端 HTML 中渲染正文 `<img>`（浏览器端补全），
  脚本只能抓文本与代码；图片需浏览器打开原页查看（模块索引有原页链接）。
- 网盘文件（完整工程/DEMO/驱动包）无法自动下载（百度网盘反爬+登录），
  只能靠 `网盘索引.md` 人工下载。
- 页面更新时间：多数 2024 年，地址可能过期；重抓前先看 `模块索引.md` 计数。
