    [flash] 应看到: 烧录工具最后报成功（Keil 的 Programming Done / Verify OK，或 DSLite 的 Success）
           不对先查: ① 探针 / 下载线有没有插好、板子有没有单独供电；② 下载口被别的程序占用（串口助手、另一个 IDE）会写不进去；③ 目标芯片型号要与板子一致（stm32 选 STM32F103C8，mspm0 选 MSPM0G3507）
    [heartbeat] 应看到: 板载 LED 按约 200 毫秒的节奏规律闪烁（一亮一灭，不是常亮也不是全灭）
           不对先查: ① 先按一次复位，看是不是根本没跑起来；② stm32 板载三色 LED 在 PC13/PC14/PC15（本程序用红灯通道 LED_RED），地猛星用户 LED 是 PA15；③ 灯常亮或常灭不动 = 程序卡住了（多半卡在外设初始化）
    [serial] 应看到: 串口助手（115200 / 8 / 无校验 / 1 停止位）出现一行「上电：板子活着，检测程序开始跑」
           不对先查: ① 串口号选错（拔插一次，看哪个口消失）；② TX/RX 要交叉接、GND 必须与板子共地；③ 波特率不对就是乱码——固定 115200；④ 板子没复位 / 没烧进去
    [oled] 应看到: OLED 屏上出现同一行「上电：板子活着…」（屏是亮的，不是全黑也不是全白）
           不对先查: ① SCL/SDA 接反或没接（本工程的默认脚见工程 README 的接线表）；② 屏供电 3.3V；③ 0.96 寸 SSD1306 与 1.3 寸屏初始化序列不同，换屏要改驱动
    [reset] 应看到: 按一下复位键，现象从头再来一遍（灯继续闪、输出通道再打一次那一行）
           不对先查: ① 复位键没接 / 按下没反应 → 直接断电重新上电；② 只打印一次就停 = 程序进了死循环或硬件异常（HardFault）

    [flash] 应看到: 烧录工具最后报成功（Keil 的 Programming Done / Verify OK，或 DSLite 的 Success）
           不对先查: ① 探针 / 下载线有没有插好、板子有没有单独供电；② 下载口被别的程序占用（串口助手、另一个 IDE）会写不进去；③ 目标芯片型号要与板子一致（stm32 选 STM32F103C8，mspm0 选 MSPM0G3507）
    [heartbeat] 应看到: 板载 LED 按约 200 毫秒的节奏规律闪烁（一亮一灭，不是常亮也不是全灭）
           不对先查: ① 先按一次复位，看是不是根本没跑起来；② stm32 板载三色 LED 在 PC13/PC14/PC15（本程序用红灯通道 LED_RED），地猛星用户 LED 是 PA15；③ 灯常亮或常灭不动 = 程序卡住了（多半卡在外设初始化）
    [serial] 应看到: 串口助手（115200 / 8 / 无校验 / 1 停止位）出现一行「上电：板子活着，检测程序开始跑」
           不对先查: ① 串口号选错（拔插一次，看哪个口消失）；② TX/RX 要交叉接、GND 必须与板子共地；③ 波特率不对就是乱码——固定 115200；④ 板子没复位 / 没烧进去
    [oled] 应看到: OLED 屏上出现同一行「上电：板子活着…」（屏是亮的，不是全黑也不是全白）
           不对先查: ① SCL/SDA 接反或没接（本工程的默认脚见工程 README 的接线表）；② 屏供电 3.3V；③ 0.96 寸 SSD1306 与 1.3 寸屏初始化序列不同，换屏要改驱动
    [reset] 应看到: 按一下复位键，现象从头再来一遍（灯继续闪、输出通道再打一次那一行）
           不对先查: ① 复位键没接 / 按下没反应 → 直接断电重新上电；② 只打印一次就停 = 程序进了死循环或硬件异常（HardFault）

-- 上板确认清单 --
    [flash] 应看到: 烧录工具最后报成功（Keil 的 Programming Done / Verify OK，或 DSLite 的 Success）
           不对先查: ① 探针 / 下载线有没有插好、板子有没有单独供电；② 下载口被别的程序占用（串口助手、另一个 IDE）会写不进去；③ 目标芯片型号要与板子一致（stm32 选 STM32F103C8，mspm0 选 MSPM0G3507）
    [heartbeat] 应看到: 板载 LED 按约 200 毫秒的节奏规律闪烁（一亮一灭，不是常亮也不是全灭）
           不对先查: ① 先按一次复位，看是不是根本没跑起来；② stm32 板载三色 LED 在 PC13/PC14/PC15（本程序用红灯通道 LED_RED），地猛星用户 LED 是 PA15；③ 灯常亮或常灭不动 = 程序卡住了（多半卡在外设初始化）
    [serial] 应看到: 串口助手（115200 / 8 / 无校验 / 1 停止位）出现一行「上电：板子活着，检测程序开始跑」
           不对先查: ① 串口号选错（拔插一次，看哪个口消失）；② TX/RX 要交叉接、GND 必须与板子共地；③ 波特率不对就是乱码——固定 115200；④ 板子没复位 / 没烧进去
    [reset] 应看到: 按一下复位键，现象从头再来一遍（灯继续闪、输出通道再打一次那一行）
           不对先查: ① 复位键没接 / 按下没反应 → 直接断电重新上电；② 只打印一次就停 = 程序进了死循环或硬件异常（HardFault）
