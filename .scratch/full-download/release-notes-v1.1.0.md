# firstep 电赛工程生成器 · v1.1.0

**这一版的主题：三段式更新——从此不用再重下 6 GB 完整包。**

| 资产 | 大小 | 给谁用 |
| --- | --- | --- |
| `firstep-update-v1.1.0.zip`（4 件套） | 约 296 MB | **老用户推荐**。工具内「设置 → 软件更新 → 检查更新 → 一键更新」自动完成下载 / 校验 / 替换 / 重启；也可手动下载后用更新器 |
| `firstep-full-v1.1.0.zip`（4 件套） | 约 783 MB | 修损坏、换机器、本地还没有资料库基线（检查资料库更新时提示「版本未知」）：工具内「设置 → 完整包下载」一键全量，**不用手动下分卷、不用装 7-Zip** |

> 完整包**不含**那批「装一次就完事」的第三方安装包与视觉 SDK（CCS 安装包 1.28 GB、视觉 SDK 1.4 GB、VSCode / LCEDA / 嘉立创 EDA 安装程序、K230 固件镜像等，合计 5.4 GB，本机原有的原地保留）。所以它从 6.2 GB 降到 783 MB；需要那批文件的用户仍走 v1.0.0 的 7z 完整包。

## 这一版更新了什么

- **新增：一键下载完整 firstep（约 783 MB）**——「设置 → 完整包下载」→ 检查完整包 → 下载完整 firstep：自动下载、替换并重启。中途取消、断网或关掉页面后重试，**只补没下完的卷**（卷级断点续传）。
- **新增：应用内一键更新**——「设置 → 软件更新」检查更新 → 一键更新，自动完成停服、备份、替换、依赖安装与重启；DeepSeek key、任务状态、对话记录与电赛资料库原样保留。
- **新增：资料库增量更新**——「设置 → 资料库更新」按批次（芯片手册 / K230 视觉 / 真题…）勾选下载，只传变化的部分；真实进度与速度、断点续传、下载完自动解压落位并备份旧文件。**全量下载一次后会自动记下基线，之后只收增量。**
- **新增：硬件模块扩充**——红外对射、Zigbee 无线链路、磁力计（HMC5883L / QMC5883L）等入库，双平台驱动 + 编译矩阵验证。
- **改进：模块「说明」入口**——推荐区模块名旁直接看简介与用法；参考库文件按类型分流打开（视频 / 音频 / 图片新标签内联预览）；引脚冲突诊断给出「至少去掉几个」的明确结论。
- **修复：启动器失败原因可机读**（更新中 / 上次更新未完成 / 端口被占用分别提示）；自动编译与推荐链路的若干误判收口。

## 怎么更新

**已经在用工具（任意旧版本）**

1. 打开工具 →「设置」→「软件更新」→「检查更新」→「一键更新」（约 296 MB，几分钟）。
2. 更新完成后工具自动重启；配置、任务状态、对话记录与电赛资料库都在工具目录之外，不受影响。

**换机器 / 修损坏 / 想拿一份干净的**

1. 打开工具 →「设置」→「完整包下载」→「检查完整包」→「下载完整 firstep」（约 783 MB）。
2. 下载完自动替换并重启。若本地还没有资料库基线，这一步会连带写回基线，之后检查资料库更新就只提示变化的部分。

**手动下载的话**

- 小发版：把 `firstep-update-v1.1.0.zip` 与三个配套文件放在同一目录，用 `tools/update-app.py` 应用（见仓库 `docs/agents/releasing.md`）。
- 完整包：`firstep-full-v1.1.0.zip` 解压后直接覆盖到工具目录（zip 标准格式，系统自带解压即可），再双击 `install.bat` → `start-app.vbs`。

## 校验

- `firstep-update-v1.1.0.sha256.txt`、`firstep-full-v1.1.0.sha256.txt`：对应 zip 的 SHA256。
- `firstep-full-v1.1.0.manifest.json`：包内全部 8774 个文件的清单 + 资料库基线（12 批次 / 5087 文件）+ 删除清单；用户侧下载与更新器都按它校验。
- 只想跑生成器、不需要资料库？直接 `git clone https://github.com/AK47n/firstep.git`（约 270 MB）。
