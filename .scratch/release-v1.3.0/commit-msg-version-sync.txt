顺手修掉一处**既有**缺陷（与本次改动无关，但会把发版闸门拖红）：
`tests/test_js_gate.py::test_full_mode_runs_js_gate_and_pytest` 的 docstring 与断言停在
「--full 两支都跑」，而 `tools/prepush.py` 自工单 ui-dom-contract-gate/03 起已经有**第三支**
`run_browser_tests`；`--full` 会置 `selection.browser=True`，那条用例没 stub 它 ⇒ 真跑整支
真浏览器套件。本机实测该套件 **42 条 / 183.7 秒**，比 `pyproject.toml` 的全局
`timeout = 180`（thread，超时中止整场）还长 ⇒ 这条用例必红（`-n auto` 下表现为 worker 崩）。
改法：把第三支也 stub 掉并断言调用顺序 `js → browser → pytest`；「浏览器门禁真被执行 /
dry-run 不执行」的判据仍在 `tests/test_prepush.py`，覆盖不减。
修前：`tests/test_js_gate.py` 单跑超时（180s）；修后 **29 passed / 0.43s**。
