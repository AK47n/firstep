# 代码页快捷键帮助 — 规格说明（code-editor-shortcut-help）

## 背景与问题

代码页（「代码」tab）经多轮迭代绑定了一批键盘快捷键与鼠标手势（保存、缩进、括号自动闭合、查找替换、折叠、缩放、标签页中键关闭/拖拽排序等），但界面上没有任何地方说明它们——用户只能靠猜或源码。本次为这些快捷键提供一个可发现的、集中的说明入口。

## 目标（本次交付）

1. 状态栏最右侧新增「快捷键」按钮（与既有状态栏按钮同视觉）。
2. 点击弹出居中模态浮层「键盘快捷键」，按分组列出代码页全部常用快捷键与鼠标手势：
   - **编辑**：`Ctrl+S` 保存当前文件；`Tab` 缩进（4 空格）；`Enter` 换行自动缩进；输入开括号 `( [ {` 自动补闭合括号（C/XML/Markdown）；`Backspace` 删除配对的空括号；鼠标中键点击标签关闭；拖拽标签排序。
   - **查找**：`Ctrl+F` 当前文件查找；`Ctrl+H` 查找并替换；`Enter` / `Shift+Enter` 下一个 / 上一个匹配；`Esc` 清除查找。
   - **视图**：`Ctrl+Shift+[` 折叠光标所在代码块；`Ctrl+Shift+]` 展开；`Ctrl+滚轮` 缩放代码字号。
3. 关闭方式：× 按钮 / 点击遮罩 / `Esc`；关闭后焦点还给「快捷键」按钮；弹窗内 `Tab` 焦点循环（与既有冲突弹窗同一交互纪律）。
4. 键位以键帽样式（kbd）呈现，组合键 `+` 连接；说明数据单一来源（纯函数模块），界面不散落裸串。

## 明确不做

- 不做「可自定义快捷键 / 按键录制」。
- 不改任何快捷键绑定本身（本任务只做说明入口）。
- 不新增第三方依赖；不触碰代码页既有布局与交互。

## 验收要点

- [ ] 状态栏出现「快捷键」按钮，样式与两侧按钮一致（统一圆角/边框/悬停，复用既有 token）。
- [ ] 点击弹窗出现：标题「键盘快捷键」、三组（编辑/查找/视图）全部条目、键位为键帽样式。
- [ ] `Esc`、× 、点击遮罩均可关闭；关闭后焦点回到按钮。
- [ ] `/` 分隔的替代键位（如 `Enter / Shift+Enter`）拆成两个键帽。
- [ ] 弹窗内容全部转义；窄视口内容可滚动（max-height + overflow）。
- [ ] 新样式类名 `.code-*` 前缀、只使用既有 token；通过 CSS token 守卫测试。
- [ ] 纯函数单测 + CDP 冒烟（打开/关闭/内容）通过；全量 JS 测试回归通过。
