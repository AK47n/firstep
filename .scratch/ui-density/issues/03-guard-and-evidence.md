## 为什么要有这单

本轮改造的价值一半在"改对"，另一半在"**不被下一个人改回去**"。仓库既有先例都是这个形状：
`tests/js/ui-dom-contract.mjs`（id 契约）、`tests/js/import-usage.mjs`（未使用导入）、
`tests/js/boot-contract.mjs`（装载契约）——判据纯函数 + 守卫用例 + 合成红证。
本单照这个形状补一条**排版契约**。

## 结论（本单迟到了一轮，账记在这里）

**迟到的事实**：02 一 resolved，本单就是 frontier，我却先做了 04（Standards 轴评审判为硬性违规，
且**代价当场发生**：02 写的 `font-size: 22px` 把 01 已勾选的「检测页样式段不再出现一次性字号」

三条腿各一条 + 一条合成红证。判据纯函数写在同文件内（`cssRules` / `bareFontSizesInHwcheck` /
`bareTokenSpacesInHwcheck` / `bareFontSizesSitewide`）。

**读数**：`node --test tests/js/css-tokens.test.mjs` → **12 passed / 0 fail**（原 8 条 + 本单 4 条）；
前端门禁整套 **1836 passed / 0 fail**；`probe-01-after.txt` 重跑：检测页段裸 px 字号 **0**、
间距档位 4/8/12/16/20/24 齐全；全站 387 处 / 13 种（只减不增）。

**它挡住的坏法（都是真发生过的）**：02 的 `font-size: 22px`（越界字号）、
04 的 `padding: 20px 24px` 与 `padding: 5px 12px`（等于令牌却裸写）。
两条在加守卫之前都"门禁全绿"——正是"门禁全绿只证明没搬坏，证明不了没退化"。

## 备注

- 守卫**不判"好不好看"**（那是人眼验收），只判"取值有没有越界"——这条边界写在守卫文件头，
  免得后人以为它能替代审美判断。**也不判**"只许用令牌"：这一页本来就有 9 / 10 / 14px
  这类细内边距（既有习惯），守卫只管"等于令牌的必须走令牌"。
- 冻结清单不是"免死金牌"：全站推广完成后，清单应收敛到新集合、条目数写进读数
  （体量本身就是"改造推进到哪了"的尺子）。
