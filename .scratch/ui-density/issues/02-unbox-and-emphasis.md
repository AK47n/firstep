# 02 — 拆「框套框」+ 让重点会跳

**要做什么：** 硬件检测页**一屏内只剩一层完整描边**——内层容器改成留白 / 单条分隔线 / 浅底
（同类信息靠"挨得近"分组，不靠画框）；当前选中与正在编辑的那一件**一眼看得出是哪件**；
「删除」与「生成」两个动作视觉重量分明；未生成时那几张空卡片**安静下来**，并让整页读起来分成
「配置 / 结果 / 上板」三段（用分组标题 + 大间距表达，**不搬 DOM**）。

**被谁阻塞：** 01（地基不在，重点就没法"跳"——层级是靠对比出来的）。

**状态：** resolved（2026-09-27；逐层清单、读数与账见文末「结论」）

## 现状（截图与代码实读）

用户原话：「好挤啊……小家子气」。一屏内可达**四层描边**：

1. 页面卡 `.card`（1px `--border`）
2. 「我的器件」外壳 `.hwcheck-my-devices`（1px `--border` + 左 3px `--accent`）
3. 每件一行 `.hwcheck-my-device`（`border-bottom` 分隔）
4. 表单 `.hwcheck-my-device-form`（1px `--border-strong`）+ 字段行
   圆角还全是同一个 `--radius-md`（76 处在用）⇒ 边界很吵、层级很平。

另外两条：

- **选中态太弱**：`.hwcheck-my-device.picked` 只加一道 3px 绿左条；候选器件 chip 的选中态与之
  不是同一种"重量"，用户得逐字读名字才知道改的是哪一件。
- **空态占满首屏**：接线表 / 冲突 / 顺序 / 检测计划 / 命令台 / 检测工程 / 清单 / 最近检测
  在未生成时都是"一张空卡 + 一句空态文案"，与有内容时同样重。

## 验收标准

- [x] **一层描边**：检测页任一屏内，完整矩形描边**只有一层**；内层改用留白、单条分隔线或浅底。
      给出"改前四层 / 改后一层"的逐层清单（哪一层被什么替代）→ 见「结论 · 逐层清单」。
- [x] **同形之物同形**：「我的器件」/ 自建件计划 / 带入生成页三块原本共用外壳形状，
      拆框后仍必须**看起来是一类东西**（形状单源不破）→ 形状单源那条共用规则只改一次
      （`border` → `background`），三块仍共用它。
- [x] **重点会跳**：当前选中 / 正在编辑的那一件，与"未选中"的差别**不依赖读文字**即可分辨
      （尺寸、底色、左条、边框至少两项同时变化）；页面里"选中态"只有一种表达，不与其它状态混淆。
      → 统一成**淡绿底**（`--ok-dim`）：自建件行 `.picked` 与候选 chip `.chip.rec` 同一种表达；
      撞脚组 `--warn-dim` 底 + 琥珀左条、可共享组 `--ok-dim` 底 + 绿左条。
- [x] **动作重量**：「生成检测工程」（主）/「删除」（不可逆）/ 其余（次要）三级分明，
      且删除在任何情况下都不会与主操作混淆 → `.danger` 由"只有红字"升为"红描边 + 淡红底"
      （悬停实心红），与实心 accent 的主操作不撞色。
- [x] **空态安静**：未生成时那几张卡明显弱于有内容时；每张空态仍说清"生成后这里会出现什么"
      （**不删文案**，只降一级呈现）→ 空态组件（图标 22px / 半透明、标题与说明退到 muted）
      + 六张结果卡在"只有一个空态孩子"时整卡降级（去顶光与阴影、标题退成 muted、记号码变灰）。
- [x] **三段可读**：整页能读出「配置 → 结果 → 上板」三段（分组标题 + 间距），
      且 **DOM 顺序与 id 集合零变化**（分组只靠新增类名与标题表达）→ 三段落成
      「① 配置这次要测什么 / ② 这一趟的接线、冲突与顺序 / ③ 上板跑起来与收尾」；口径修正见「账」第 1 条。
- [x] **契约机械对账**：同 01 的三项对账（id 集合 / DOM 顺序 / 既有类名出现次数）+ 文案零删除
      → `probe-03-contract-02.txt`：id **569=569**、检测页既有元素 **38 个 id 顺序逐项相等**、
      新增标签**恰好 3 个 band（div+span ×3）**、删除标签 **0**、文案删除 **0 行**。
- [x] **门禁读数**：前端门禁 + 浏览器门禁（`hwcheck.spec.mjs` 361 处选择器引用是本单的主要风险面）

      全量 **5656 passed + 11 skipped**（121s）。

## 结论（逐层清单、读数、账）

**逐层清单（「一层描边」到底留了哪一层）。** 改前那一屏实际有七处完整矩形描边，改后只剩第一层：

| 层 | 改前 | 改后 |
|---|---|---|
| 页面卡 `.card` | 1px `--border` | **保留**（这就是"唯一那一层"） |
| 「我的器件」/ 带入生成页 / 自建件计划 外壳 | 1px `--border` + 左 3px accent | 去整圈描边 → **`--panel-2` 淡底 + 左条** |
| 表单 `.hwcheck-my-device-form` | 1px `--border-strong` | 去描边 → **`--input-bg` 凹陷底** |
| 面板内提示 `.hwcheck-hint`（嵌套时） | 自带 1px 框 | 去描边 → **凹陷底**（只负责分行） |
| 撞脚组 `.hwcheck-group` | 1px 框（红 / 绿 / 中性） | 左 3px 色条 + 同色淡底（**比原来更跳**） |
| 专精 / 通用小节 `.hwcheck-section` / `.hwcheck-generic` | 1px 框（实线 / 虚线） | 左条（实线 / **虚线**）+ 淡底 |
| 上板清单行 / 最近检测行 | 每行一个 1px 框 | `border: transparent` → **指到 / 选中 / 正在看才出框**（照 `.sp-item` 先例） |
| 排障建议 `.hwcheck-advice` | 1px 框 + 左条 | 左条 + 淡底 |

**保留的完整描边（如实列出，别误读成"页面里只剩一个框"）**：① 卡片那一层；
② **语义告警块** `.hwcheck-warn`（"未上板""本平台没有这条目"这类必须显眼的警示，全页少量）；
③ **可点控件**（平台卡、输入框、按钮）——那是控件的形状，不是分组用的框。

**账（留给后面的人）：**

1. **对账口径改了一条**（`probe-03-contract.py` §2）：01 判的是"检测页标签序列逐项相等"，
   而 02 要**插入**分组标题带——那是"新增元素"，不是"重排既有元素"。新口径 = **既有元素的
   id 出现顺序逐项相等** + 新增 / 删除标签如实报数。旧口径真正想守的东西没丢，假红没了。
2. **`:has()` 的浏览器前提**：空卡降级那两条规则用了 `:has()`（Chromium 105+ / Safari 15.4+ /
   Firefox 121+）。不支持时**整条忽略**——卡片照旧可用，只是不"安静"。故它是纯增强，
   不是可达性依赖；退化路径就是现在这版的样子。
3. **撞上既有守卫一次（好事）**：`#tab-hwcheck .card h2::before` 第一版写了裸 `border-radius: 2px`，
   被 `tests/js/css-tokens.test.mjs` 当场判红（"圆角一律走令牌"）。已改 `var(--radius-full)`。
   **这条对工单 03 有直接影响**：防回退守卫**不该另起一个文件**——字号那条腿加进这个既有守卫
   家族即可（工单 03 已按此更新）。
4. **`h2::before` 的竖条是"第二条维度"的补法**（01 的账第 3 条）：中文没有 600/700 字重差，
   于是给"卡片"这一级加了形状 / 颜色记号，与"步骤标题（无记号）"一眼分开。
   若用户觉得它多余，删掉只是一条 CSS 规则，不动任何结构。
5. **【2026-09-28 补记·05 复查又拆了两处 + 一处口径】** 本单的"逐层清单"当时漏了两处
   四边描边：**4 个 `.hwcheck-hint`**（这页的说明块）与 **`.my-device-draft`**（整圈虚线）——
   05 复查时用 `probe-06` 数出来，都改成"左条 + 淡底"（草稿面板用虚线左条保住"还没确认"的意思）。
   另：`#hwcheck-conflicts` / `#hwcheck-order` 空时渲染的是**空串**（`hwcheck-core.js:426/436`），
   本单的空卡判据漏了这两张 → 05 补 `:empty` 两支，空卡 **8/8** 全降级。
   **口径**：三个 `.hwcheck-band` 是带文案的标题元素，比 spec 那句"分组标记（加类名）"宽一点——
   **以本票票面为准**（票面与用户拍板写的都是"分组标题 + 大间距，不搬 DOM"）。
