# 02 — 「我的器件」：定义形状 + 数据目录 + 端点 + 检测页表单

**要做什么：** 检测页多出「我的器件」：学生能新增一件库外器件（名称 / 总线 / 7 位地址 / 身份寄存器 / 期望值 / 备注），保存后下次还能选，可改可删。数据落在**工具数据目录**（不进产品库根）。这一张**不生成任何代码**——先把"事实"这条路打通。

**被谁阻塞：** 无——可立即开始

**状态：** ready-for-agent

- [ ] 定义落 `<配置目录>/hwcheck_devices/<id>/device.json`（目录即数据库），资料副本目录 `materials/` 预留；**不进 `library/`**、不进 git、不随发布包分发
- [ ] 字段与校验（全部是事实，没有一项推导）：`id`（`mine_` 前缀 slug 形）、`name`、`bus`（词表 `i2c`/`spi`/`uart`/`onewire`/`analog`/`gpio`/`other`）、`address`（**7 位** 0x08–0x77，`bus=i2c` 必填）、`register`（8 位，可选）、`expect`（8 位，可选；填了 `expect` 就必须有 `register`）、`notes`（可选）、`created_at` / `updated_at`
- [ ] `id` 与库内 slug 冲突 → 400 中文**当场点名要求改名**（不静默加后缀）
- [ ] 页面**双向显示地址**：7 位值 + 派生的 8 位读 / 写形式（手册里 0x68 与 0xD0 两种写法都能对上——填错地址最常见的一处坑）
- [ ] 端点：列出 / 新增（按 id 幂等更新）/ 删除；错误映射沿用既有 400 中文口径
- [ ] 检测页有「+ 我的器件」卡片与表单：能建、能列、能选、能改、能删；件**与平台无关**（切平台不丢）
- [ ] 前端 fx 纯件单测进前端门禁；真实浏览器验收能看见并操作这块卡片
- [ ] 反证：把「id 撞库内 slug」的守卫拿掉后，对应用例必须变红
