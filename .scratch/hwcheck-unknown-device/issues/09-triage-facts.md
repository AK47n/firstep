# 09 — AI 排障带自建件事实

**要做什么：** 现象回填后的 AI 排障会**引用这件自建件的事实**（地址 / 身份寄存器 / 期望值 / 是否与库内件共总线），并且模型提到自建件的名字或地址**不会被事实白名单误拒**。

**被谁阻塞：** 05（页面计划投影）

**状态：** ready-for-agent

- [ ] 排障上下文新增「自建器件事实」段：id / 名称 / 地址（7 位 + 8 位两种写法）/ 身份寄存器 / 期望值 / 备注 / 本次探测形态（判定 · 只回显 · 只 ping）/ 是否与库内件共总线
- [ ] 事实白名单扩容到自建件 id / 名称 / 地址（模型提它们不再被当"上下文里没有的东西"拒收）
- [ ] 反向判据仍成立：模型提一个**不在本次**的自建件名或地址**仍被拒收**（白名单不是照单全收）
- [ ] 提示词写明：`[自建件]` 的结论来自**用户确认的事实**，不是库内验证过的驱动结论（不许把它说成"库内模块有问题"）
- [ ] AI 不可用 → 兜底建议照旧，检测记录照常落盘（不阻断）
- [ ] 既有排障用例全绿（没有自建件时上下文逐字与改动前一致）
