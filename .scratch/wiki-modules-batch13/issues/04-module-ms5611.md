# 04 — ms5611 高精度气压/温度传感器（软 I2C，手册 sensor--ms5611-pressure-sensor.md）

**要做什么：** 模块库新增 `ms5611` 条目（仅 mspm0）：从手册提炼 MS5611-01BA03 气压/高度传感器驱动为纯驱动切片——**软 I2C**（SCL/SDA 两 GPIO、SDA 方向运行时切换，照 sht30/sgp30/bmp180 先例：不占硬件 I2C 外设/TIMER、延时走 delay）：`ms5611_init()`（**页面 main 序列封装**：复位 0x1E（0=成功/1=器件地址错误/2=命令无应答——页面码）→delay_ms(300)（页面「等待初始化完成」）→Read_PROM 8 字（0xA0..0xAE，C1..C6=idx1..6 + CRC=idx7，页面原式；页面 PROM 读的 I2C_WaitAck 无应答检查缺漏——人工复核修正：逐段检查应答并返回 3=PROM 读应答失败，notes 记录）+ `ms5611_read(float *temp_c, float *pressure_pa)`（**页面 2 次转换按原式**：Read_D1_D2(0x48=OSR4096)→delay 10ms→Read_D1_D2(0x58)→delay 10ms→dT=D2−C5×256.0→TEMP=2000+dT×C6/8388608.0→OFF=C2×65536.0+C4×dT/128→SENS=C1×32768.0+C3×dT/256.0→P=(D1×SENS/2097152.0−OFF)/32768.0；温度出参 = **TEMP/100.0（℃）**——页面 Get_TEMP 返回整数℃截断丢小数（dat=(TEMP/1000)*10+(TEMP/100%10)），人工复核修正保留 0.01℃ 分辨率记 notes；气压出参 = **P（Pa）**——P 单位 0.01mbar == 1Pa，页面 /100= hPa，统一出 Pa 记 notes；返回 0=成功/1=D1 段失败/2=D2 段失败/3=数据读失败——页面 NACK printf 改码、段内细分码保留内部）+ `ms5611_read_altitude(float pa)`（**可选**——44330 海拔公式与 bmp180 共用，notes 分工）；页面 MS5611_Reset/Read_PROM/Read_D1_D2 保留为底层；页面 Get_pressure 内部重复调 Get_TEMP() 的二次 D1/D2 重读——本件合并为单次 D1/D2 读取 + 一次全换算（结果等价省 ~40ms），notes 记录；选中后生成工程打开即可编译、可调用，不再"需自备"。

**被谁阻塞：** 无——可立即开始（与 01/02/03 独立；与 bmp180 同软 I2C 先例）。
