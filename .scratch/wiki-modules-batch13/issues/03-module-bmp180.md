# 03 — bmp180 气压/温度/海拔传感器（软 I2C，手册 sensor--bmp180-pressure-sensor.md）

**要做什么：** 模块库新增 `bmp180` 条目（仅 mspm0）：从手册提炼 BMP180 气压传感器驱动为纯驱动切片——**软 I2C**（SCL/SDA 两 GPIO、SDA 方向运行时切换，照 sht30/sgp30 先例：不占硬件 I2C 外设/TIMER、延时走 delay）：`bmp180_init()`（**页面 BMP180_Get_param 序列封装入 init**：0xAA..0xBE 逐项 Read16 读 11 项校准系数（AC1..MD）入模块静态 struct——校准数据是每次读数的必需输入，init 缓存为静态——sgp30_init 先例）+ `bmp180_read(float *temp_c, float *pa)`（页面 Get_Temperature + Get_Pressure **原式合并**：温度 0xF4←0x2E→delay 6ms→读 0xF6 2 字节→X1=(UT−AC6)×AC5/32768.0、X2=MC×2048.0/(X1+MD)、B5=X1+X2 模块静态、T=((B5+8)/16.0)×0.1；气压 0xF4←(0x34+(oss<<6))（oss=0 页面默认）→delay 10ms→读 0xF6 3 字节→B6/B3/B4/B7/p 全套页面原式；返回 0=成功/1=温度段失败/2=气压段失败——sht20 分段先例，段内细分码（写地址/命令/读地址超时 5×1ms）保留内部）+ `bmp180_read_altitude(float pa)`（**页面原式：44330×(1−pow(p/101325.0, 1/5.255))**——math.h/pow，ir_distance 编译先例）；页面 BMP180_Write_Cmd/Read16 保留为底层（读/写应答改状态码返回，去 printf）；器件正确性复核修正记 notes；选中后生成工程打开即可编译、可调用，不再"需自备"。
