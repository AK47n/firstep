# 03 — 2023 控制题拆条（E/G/I 三题入库）

**要做什么：** 从 `library/topics/*/000_2017-2025_全国大学生电子设计竞赛真题汇编.pdf`（34MB，261 页，2023 章节 = p171-205）拆出 **2023E 运动目标控制与自动追踪系统（p183）/ 2023G 空地协同智能消防系统（p189）/ 2023I 气垫悬浮车（p197）** 三条目，复用既有机制、**零 LLM 改写**：

1. **定位页**：fitz 文本定位 2023 章节内三题边界——题目标记（E 题）/（G 题）/（I 题）起始页为准（上述页码为锚点，精确边界执行时核实；相邻题分界 = 下一题标题行）。
2. **小题 PDF**：fitz 提取各题页 → `.scratch/topics-control-2023-2025/pdf/2023E.pdf` 等（几百 KB；**不放 34MB 汇编副本**）。
3. **确定性拆条**：提取小题文本 → 调 `split_topics_document(text)`（`topic_library.py:567`，YEAR_RE 年份 + TITLE_RE 题目标记（X 题）/行首 X 题：）得 TopicDraft（year/number/problem_text）；若输出 ≠ 1 条用「章节切片」兜底（标题行起点到文档末尾的原文段落，照 split_topics_document 分块逻辑）；**不经 LLM／webapp /api/topics/split 的 LLM 分支**（TOPIC_SPLIT_LLM_CHAR_CAP 内会走 LLM 拆条——刻意规避）。
4. **结构补全**：拆出草稿缺年份标题 / `## 参赛注意事项` 时，从全文章节文本确定性拼接（照 2026H 结构：`# 2023年全国大学生电子设计竞赛试题` → `## 参赛注意事项` → `# 题名（X 题）` → `## 一、任务` `## 二、要求` `## 三、说明` `## 四、评分标准`）；不 AI 生成。
5. **视觉核对**：fitz 渲染各题页面 PNG → `.scratch/topics-control-2023-2025/pages/`，read_image 检查：文本层是否漏图/表、评分标准表是否齐全（漏则从渲染页人工补录，记录差异）。
6. **入库**：本地脚本调 `confirm_topics`（或走 `POST /api/topics/confirm`，pdf = 小题 PDF）：entries = [{year: "2023", number: "E", problem_text, category: "control"}, ...]，program_dirs = [] → 条目目录 `2023E`/`2023G`/`2023I` + topic.md + 小题 PDF + manifest（original_pdf = 小题 PDF 文件名；category=control）。
7. **图注**：入库后 GET `/api/topics/2023E` 等（webapp L4783 触发 `enrich_topic_image_notes` 三级降级：渲染视觉 [图N 标注：…] → 文字标注 → 内嵌图视觉；幂等；失败静默）——不手写。
8. **断言**（每题）：topic.md 含「一、任务」「四、评分标准」；manifest 五字段齐全 + category=control；original_pdf 存在且 < 1MB；`resolve_number` 可解析。
