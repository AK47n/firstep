## 这一版有什么变化

- **三条被「变淡」压得看不清的话，恢复成实色**：资源总览里标着「非硬件资源」的那一行、库外建议 chip
  上的「⤵ N 方案」计数、被你点掉的推荐 chip 上那行「为什么推荐它」的理由。以前它们整块变淡，
  浅色下最低只有 **3.52:1**、暗色最低 **3.91:1**（WCAG AA 要求 4.5:1）；现在改成实色灰字——
  浅色 **5.25 / 5.72**、暗色 **5.67 / 4.85**，两种主题都读得清了。
- **浅色主题板图里的「固定/电源」焊盘换色**：以前它沿用了暗色那一支近黑，在一片浅色焊盘里像个小洞；
  现在与「空闲 IO」焊盘用同一套浅灰——浅色下扫一眼就知道哪根脚能点。**暗色主题没有变化。**
- **「看起来不能用」不再靠「看不清」表达**（内部加固，观感无变化）：全站每一条「变淡」的写法现在都
  逐条登记、写了中文理由，门禁盯着——以后要表达"这个不能选"得用形状（虚线描边 / 灰底灰字），
  不能靠把字洗淡；另外补了一条判据，把「写错的颜色名」这类问题挡在发版前（这一版顺手修掉了一处，
  它本来就渲染成正常颜色，所以你看不出差别）。
- 内部还收了两笔**已知但故意不修**的账（选中文字叠上搜索高亮、强调色当非文字描边），写进了守卫注释，
  下一轮不必重新发现。
