# code-editor-vscode-polish — 代码编辑器 UI 对标 VSCode 全面优化

## 问题陈述

「代码」tab 的功能已相当完整（多文件标签、可编辑、保存冲突、编译/AI 修复、磁盘变更感知），
但界面观感与交互手感仍停留在「自研拼装」阶段，与用户日常使用的 VSCode 相比差距明显：

- 底部状态栏只有目录路径与操作按钮，没有 VSCode 式「光标行列 / 语言 / 编码 / 缩进 / 缩放」信息；
- 编辑器本体朴素：无细滚动条、选区/光标行/滚动条观感不精致；
- 标签条交互简陋：不能中键关闭、不能拖拽排序、标签多时不会自动滚到活动标签；
- 输代码时没有括号配对（自动闭合 / 跳过 / 匹配高亮），写 C 手感生硬；
- 文件内查找只列结果列表，编辑器里没有命中高亮，也没有「第 N / 共 M 处」计数；
- 长函数 / 长 .md 无法折叠，浏览效率低；
- 无选中词（光标所在标识符）全文高亮，读代码费眼；
- 文件树 / 侧栏 / 底部面板 / 状态栏各组件风格细节不统一（间距、字体、hover、滚动条、焦点环）。

用户目标：让代码页整体观感与交互对标 VSCode，同时**不引入任何第三方依赖**（沿用自研
textarea 三明治引擎），不破坏既有功能（保存 / 冲突 / 编译 / AI / 磁盘感知）。

## 方案（用户已确认的选择）

范围 = 整套代码页（文件树 + 编辑器 + 侧栏 + 底部面板）。重点 = 视觉观感打磨 + 编辑功能增强
+ 布局与信息密度，三项并重。参考 = 对标 VSCode 观感。具体优化项 8 项全选；**Minimap 不做**
（成本高、收益一般，用户明确不要）。生成页的独立 main.c 编辑器（textarea + 行号 + 高亮 +
缩放工具条那套）与代码页编辑器不同源，属另一个界面，不在本次范围。

### ① 底部状态栏 VS Code 化

- 状态栏分区：左侧 = 目录路径（保留、可收缩省略）；中右 = 动态信息 + 操作按钮。
- 动态信息（随光标 / 文件 / 缩放实时刷新）：`Ln X, Col Y`、语言徽标（C / XML / MD / TXT）、
  编码（UTF-8 / 非 UTF-8 标「非 UTF-8（只读）」）、缩进（空格: 4）、缩放百分比。
- 操作按钮保留既有四个（保存全部 / 编译 / 烧录 / 去生成页），样式统一为状态栏条钮。
- 视觉：沿用 token（--panel-2 底、--border 顶线），信息段 muted 等宽字体、当前值 accent；
  不做 VSCode 蓝色底（跟随主题）。

### ② 编辑器视觉精修

- 细化滚动条（细条、thumb 圆角、hover 加深、暗色下可见），横向 / 纵向一致。
- 当前行高亮微调（淡底 + 左侧竖线保留，行号 accent 加粗保留；行内选区颜色增强）。
- 光标所在行行号与内容行对齐观感、焦点态（textarea 聚焦无 outline 但视觉焦点清晰）；
- 空态文案与图标化（打开文件前的提示更接近 VSCode 欢迎页质感，保持轻量）。
- 代码区 padding / 字距微调，行号列与代码列间距统一；文件尾空行观感修正。
- 只读标注（非 UTF-8 提示）样式与信息条按钮统一。

### ③ 标签条增强

- 中键（鼠标第三键）点击标签关闭：与 VSCode 一致；锁定活动标签不可中键关（VSCode
  行为：活动标签中键不关）。
- 拖拽排序：按住标签拖动，虚线/插入位指示，松手落位；顺序仅会话内有效（不持久化）。
- 激活自动滚入视野：活动标签在溢出被截断时自动 scrollIntoView（inline: nearest）。
- 关闭按钮 hover 区加大；脏点 / 磁盘变更徽章 / 只读标样式与间距统一。

### ④ 括号配对与自动闭合

- 输入 `(` `[` `{` 自动闭合：光标置于括号对中间；若当前有选区 → 选区被括号对包裹
  （VSCode 行为）。
- 输入右括号时，若光标紧邻同款右括号 → 跳过（不重复输入）；若选区被包裹在成对括号外
  则把左右括号一起替换成新括号对（VSCode「typing over pair」）。
- 退格：光标位于空括号对中间时一次退格删除整对。
- 光标停在括号上或紧邻时，高亮配对括号（匹配深度扫描，跳过字符串 / 字符 / 单行注释 /
  块注释内部的假括号；.md 不启用配对高亮，仅 .c/.h 与 XML 启）。
- 上述行为仅在 .c/.h / xml（可编辑源码）启；.md 编辑源码态仅自动闭合不启用配对高亮
  （延续其「文档优先」语义）。

### ⑤ 文件内查找高亮 + 计数

- 侧栏「查找」输入非空时：编辑器内所有命中行内片段加高亮层标记（区分当前命中，更醒目）。
- 计数：输入框旁显示 `第 N / 共 M 处`；Enter / Shift+Enter 循环上/下一个；命中列表中
  点击项联动（已有）；跳转时滚动并保持当前命中高亮。
- 编辑内容后查找高亮即时重算（与既有 fileFindFilter 同步）；小写命中大小写不敏感保持。
- 替换输入行联动态：显示「将替换 N 处」提示（不改「全部替换」行为）。

### ⑥ 代码折叠

- `.c/.h`：按花括号配对计算折叠区（`{` 与配对的 `}`，同行闭合的 `{}` 不生成折叠区；
  跳过字符串 / 注释内的假括号；嵌套正确）。
- `.md`：按标题层级计算折叠区（标题行到同层或更高层标题前；顶层 # 之后到文件尾）。
- 折叠交互：行号列左侧（或行号列与代码之间）显示折叠箭头（▸ 折叠 / ▾ 展开），点击切换；
  折叠占位行显示 `…` 与折叠行数（如 `… 12 行`），点击占位行展开。
- 折叠状态 = 视图态：编辑器可见行 = 模型行去掉被折叠区（占位行替代）；行号列仍显示
  模型真实行号；textarea 内容 = 可见行拼接，**编辑经偏移映射写回模型**（模型是全量
  基线，保存 / 脏判定 / 冲突 / 磁盘感知全部基于模型不变；不支持跨折叠区域的选区编辑，
  遇到即自动展开该折叠区后处理）。
- 跳行（大纲 / 搜索 / 查找命中）落在被折叠行内 → 自动展开该折叠区再定位。
- 折叠状态会话内有效（不持久化）；切目录 / 换文件重算；快捷键 Ctrl+Shift+[ / ] 折叠 /
  展开光标所在区（一轮内先做，若争议大可裁掉）。
- 预览态（.md 渲染预览）：标题旁折叠钮，点击收起至下一标题（details/summary 语义）。

### ⑦ 整套代码页视觉统一

- 文件树 / 侧栏 / 底部面板 / 状态栏 / 标签条统一：字号体系（11–12.5px）、间距节奏、
  hover 底色、焦点环（outline accent 2px offset 2px）、滚动条、分隔线、标题大写间距。
- 面板标题样式统一（小字 muted + panel-2 底 + 底部分隔）。
- 按钮体系统一（信息条钮 / 面板头动作 / 状态栏钮共用边角与 hover 观感）。
- 空态文案与留白统一；图标尺寸 / stroke 风格统一（既有 15px stroke SVG 体系）。

### ⑧ 选中词高亮

- 光标落在标识符上（或双击选中词）时，全文所有相同词（大小写精确）加淡色背景标记，
  与查找命中高亮样式可区分（更淡，无边框）。
- 语言范围：.c/.h / xml / plain / md 编辑源码态均启（标识符 = 词边界字母数字下划线）。
- 与 ⑤ 查找高亮共用「标记层」基础设施，两类标记分层渲染互不覆盖。

## 用户故事

1. 作为用户，打开代码页后状态栏能实时看到光标行列、语言、编码、缩进、缩放，像 VSCode
   一样有「当前位置感」。
2. 作为用户，编辑器的滚动条 / 选区 / 当前行 / 空态观感精致，深浅主题都协调。
3. 作为用户，标签可以用中键关闭、拖拽排序，标签多时自动滚到当前标签。
4. 作为用户，写 C 时输入括号自动闭合、右括号自动跳过、空括号对一次退格删除、光标在
   括号上时能看到配对括号高亮。
5. 作为用户，文件内查找时所有命中在编辑器里高亮，并显示「第 N / 共 M 处」，Enter 循环。
6. 作为用户，长函数 / 长 .md 可以折叠，点击占位行展开，跳行自动展开所在折叠区。
7. 作为用户，整套代码页观感统一，没有「拼装感」。
8. 作为用户，光标停在某个变量名上时，全文同名词有淡色高亮，读代码更省眼。

## 实现决策

- **沿用自研 textarea 三明治引擎**：不引入 CodeMirror / Monaco 等第三方（项目前端零依赖
  硬约定）；所有新能力基于既有「高亮层 + 透明 textarea」架构扩展。
- **标记层基础设施**（⑤ ⑧ ④ 的配对高亮共用）：在 .code-edit 三明治内高亮层之上、
  textarea 之下插入一层「仅背景标记」层（与 textarea 同坐标系统、同字体度量），标记 span
  文本透明不影响下层文字；标记分三类：查找命中（含当前命中）、选中词、括号配对。新增
  纯件模块承载「行文本 → 标记区段」计算（区间按 1 基行号 + 行内偏字符偏移表达，输入经
  esc 后再包 span）。
- **折叠 = 视图态行隐藏 + 偏移映射**：模型（tab.content 全量）+ 折叠区清单 → 可见行
  数组（被折叠区替换为占位行）→ textarea / 高亮层 / 行号列全部按可见行渲染，行号用
  模型真实行号；任何编辑经「可见偏移 ↔ 模型偏移」静态映射写回模型；不引入虚拟滚动。
- **纯件 / 胶水分层不变**：所有新计算（括号配对、折叠区、可见行映射、标记区段、标签
  排序、状态栏信息格式化）进 fx 纯件（可单测）；DOM / 事件 / 状态进 ui 胶水；CSS 全部
  用既有 token（--panel / --panel-2 / --border / --accent / --accent-dim / --muted /
  --code-bg / --code-text / --mono / rgba(var(--accent-rgb), a) / --radius-* / --warn /
  --danger 等），不新造色值；新类名一律 .code-* 前缀。
- **零持久化新增**：标签顺序 / 折叠状态 / 查找状态均会话内有效；仅既有 localStorage
  （目录、缩放、树宽、侧栏收起、磁盘基线）保持不变。
- **键盘快捷键**：Ctrl+Shift+[ / ]（折叠 / 展开）、Enter / Shift+Enter（查找下/上一个）
  挂在既有全局 keydown 路径；与保存 Ctrl+S、查找 Ctrl+F/H、替换 Ctrl+H 同级注册。
- **后端零改动**：全部前端实现，不改任何 API / 载荷 / Python 代码。

## 测试决策

- **主 seam = tests/js 纯函数单测**（既有先例：tests/js/codeeditor.test.mjs /
  codeview.test.mjs，node --test tests/js/ 运行，直接 import + 子串断言防脆）。新增：
  - 状态栏信息格式化（行列 / 语言 / 编码 / 缩进 / 缩放文案、边界（0 行 / 只读 / 越界））；
  - 标签排序 / 中键关闭前置判定（活动标签不关）、激活滚入（纯函数部分）；
  - 括号配对：自动闭合（空光标 / 选区包裹）、跳过右括号、退格删对、配对深度扫描
    （字符串 / 注释内假括号不配对、嵌套、跨行）；
  - 查找命中区段（大小写不敏感、多行、重叠、空针）、标记层 HTML（esc + 当前命中类）；
  - 选中词（词边界、光标在词内 / 词外、大小写精确、中文/数字边界）；
  - 折叠区（花括号嵌套 / 同行闭合不折叠 / 字符串注释内假括号 / .md 标题层级）、
    可见行映射（占位行、模型行号正确）、偏移映射（新增/删除/跨折叠展开、跳行命中
    折叠区自动展开的映射）。
- **交互 seam = CDP 冒烟**（.scratch/code-editor-vscode-polish/smoke-*.mjs，先例：
  .scratch/code-viewer-editor/smoke-*.mjs）：中键关标签、拖拽排序、Ctrl+Shift+[ 折叠 /
  占位行展开、查找 Enter 循环 + 编辑器高亮数、光标行列刷新、选中词高亮数。
- **回归**：pytest 全量 + node --test tests/js/ 全量保持绿；现有 CDP 冒烟脚本不破
  （关键 DOM 键与既有类名不删除，只增不改）。

## 范围外

- Minimap / 代码缩略图（用户明确不要）。
- 第三方编辑器引擎（CodeMirror / Monaco / ace）。
- 生成页的独立 main.c 编辑器（另一套 UI，本次不动）。
- 标签顺序 / 折叠状态持久化；多窗口同步。
- 后端 / API / 载荷变更；磁盘基线（firstep.codeBaseline）逻辑改动。
- 快捷键自定义（设置面板）。

## 补充说明

- 状态栏信息区在窄视口下允许折叠为「仅 Ln/Col + 缩放」（其余隐藏），不挤占按钮。
- 折叠优先级：先交付交互核心（箭头 + 占位行 + 快捷），再打磨样式；若 Ctrl+Shift+[ / ]
  与其冲突（浏览器 DevTools 预设），在 quiz 后实现前实测决定保留与否。
- 标记层与高亮层的层级顺序：高亮层（文字与语法色）→ 标记层（背景色，伪文本透明）→
  textarea（透明文字 + 光标）。标记层必须 `pointer-events:none`。
- 全部新 HTML 产物走既有 esc（fx/core.js 单源）防注入；内容进 mark 层前必须转义。
- 验收观感截图存 .scratch/code-editor-vscode-polish/shot-*.png（深浅两主题）。
