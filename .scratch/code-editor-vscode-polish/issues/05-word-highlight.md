# 05 — 选中词高亮

**要做什么：** 光标落在标识符上（或双击选中词）时，编辑器中全文所有相同词（大小写精确）以淡色背景标记，与查找命中高亮可区分；随光标移动即时更新。

**被谁阻塞：** 04（标记层基础设施与渲染入口）

**状态：** ready-for-agent

- [ ] 标识符识别：词边界 = 字母 / 数字 / 下划线连续段；光标在词内或紧邻词边界时取该词；光标在空白/符号上不高亮
- [ ] 全文同词高亮：大小写精确匹配（与查找的大小写不敏感区分）；仅当前打开文件内
- [ ] 高亮样式与查找命中可区分（更淡、无描边）；与查找命中同时存在时互不覆盖（两类标记分层）
- [ ] 随光标移动即时重算（复用 select/keyup 路径）；输入编辑后重算；折叠态（若先行实现）仅可见行渲染
- [ ] 适用语言：.c/.h / xml / plain / .md 编辑源码态均启用；.md 预览态不启用
- [ ] tests/js：词边界（光标在词内/词外/空格/中文/数字/下划线）、同词匹配大小写精确、空词不高亮单测
- [ ] CDP 冒烟：光标移到 `main` → 高亮数 = 文件中 `main` 出现数；移到空白 → 无高亮

**补充：** 纯件输出「词区段 + 全文同词区段清单」，胶水转成标记层清单；与 04 的查找标记合并渲染（两个清单一次遍历）。
