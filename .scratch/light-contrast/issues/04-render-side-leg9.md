# 04 — 渲染方面：腿⑨（`static/js/**` 19 处内联取色入册 + 双向对账）

**要做什么：** 把 `static/js/**` 里内联写出来的**令牌取色**变成登记在册的数据，并让守卫看着它——
样式块面干净不代表渲染方干净（描边那轮 10 处内联框就是先例）。登记表逐条给出
**前景令牌 / 假定底 / 类别**，守卫用同一套比值判据现算，双向对账；
`fx/task.js` 那处 `--ok-bright` 压卡片底（浅色 ≈3.3 ❌）在 02 单改值后应当自动过线——
**若仍不过线，本单把它修掉**（那是渲染方的消费方，样式块面改不到它）。

**被谁阻塞：** 02（登记表要冻改后的令牌值）。

**状态：** ready-for-agent

## 验收标准

- [ ] **`JS_CONTRAST_REGISTER` 落地**（`tests/js/css-tokens.test.mjs`，与腿⑨ 同一处）：
      `[文件, 锚点, 前景令牌, 假定底, 类别]`，覆盖 `probe-02-js-inline.txt` 里那
      **19 处**内联令牌取色（`--warn` × 8 / `--danger` × 3 / `--ok-bright` × 2 / `--muted` × 2 /
      `--panel-2` × 1 / `--accent` × 1 / `--pin-pad` × 1 / `--pin-fixed-pad` × 1）。
      锚点 = **该声明所在行的可认片段**（令牌名 + 邻近类名/函数名），**不取行号**
      （描边那轮 02 单的纪律：行号会漂，且本机 `Get-Content` 不带 `-Encoding UTF8` 会把行数读错）。
- [ ] **假定底明写**：每条写清"这块钱被插进哪层底"（多为 `--panel`；`fx/task.js:935` 那条是
      `--panel-2`）；假定是**登记内容的一部分**，不是脚注。
- [ ] **腿⑨ 判据（三条）**：① 盘上每处内联令牌取色 ⊆ 登记表（新增未登记 = 红）；
      ② 登记表每条 ⊆ 盘上（防死条）；③ 每条现算比值 ≥ 阈值（**假定底 + 该令牌**，
      阈值按该处字号定；`--pin-pad` / `--pin-fixed-pad` 这类色点按 `nontext` 3.0 判）。
- [ ] **裸值与跨行拼接的边界写明**：`probe-02` 量到的 5 处含裸值/`transparent` 的与
      **0 处**跨行拼接——守卫明文不判裸值那几条（`#111`/`#eee` 那处在暗色下高对比、不构成缺陷），
      但要把"为什么不管"写进守卫文件头；探针每轮盯着跨行拼接有没有变多。
- [ ] **合成红证**（照 01 单的形状，`finally` 复原）：① 新增一处内联取色 → 红；
      ② 摘掉一条登记 → 红；③ 把某条的令牌换成不过线的 → 红；④ 复原后转绿。
- [ ] **读数**：`probe-02` 重跑（改后清单）＋ 腿⑨ 的双向差与逐条比值落盘。
- [ ] **门禁**：前端门禁全绿；**浏览器门禁单独跑**（改了 `static/js/**`，必须真浏览器作证）。
- [ ] **双轴评审**跑过，发现逐条处置并在票尾记账。
