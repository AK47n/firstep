## 备注

- **为什么不登记"达标的对"**：登记得越多越容易烂；达标的现算即可，**只有不达标与不适用
  才需要理由**——这是本单与描边那轮（115 条全登记）最大的差别。
- **例外表的类别怎么分**：`debt` = 明确记账的不达标；`skip` = 静态口径不适用
  （`::selection` 反白块这类）。判不准的一律 `debt` + 写明理由，**不许用 `skip` 兜**。
- 阈值判据的输入 = 该规则自己的 `font-size` / `font-weight`；未声明 = 继承 body 14px = 小字。
- 解析面 = **剥掉 CSS 注释的 `<style>` 块**（注释里含 `{}` 会把朴素切分带偏，注释正文里的
  伪声明也会骗过判据）；描边那条腿**故意不同**（历史口径，115 条登记簿不动）。

### 账（留给下一轮）

1. **"逐条登记"vs"族级最坏格"是个真取舍**：这一轮选了后者（100 行噪音换 2 行 + 读数里的矩阵）。
   代价：**族内某一格单独变坏**要看读数才知道（判据只看最坏格）。下一轮若发现这类漏网，
   把该族拆成两族或升级成逐格。
2. **`skip` 这条后门要有人看着**：`skip` 只该装"静态判不了"（`inherit` / 未定义令牌 /
   已由族面覆盖）。**新增 `skip` 必须同时写理由**，评审时要逐条问"这是判不了，还是不想判"。
3. **`var(--fg)` 是未定义令牌**（`.pin-subtitle` 的笔误，浏览器按 `inherit` 渲染）——
   本轮不动观感，已登记为 `skip` 并在理由里点名。属下一轮的小修。
4. **`.ov-summary .ov-sep`（`--border-strong` 当字形）浅色 1.89、`--accent-dim` 折叠占位 1.15**：
   两条都是"描边色当字形用"的装饰件，已按 `nontext` 记债。要不要修属 03/05 单的观感判断。
