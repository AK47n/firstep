# 02 — 浅色六族落地：`--accent-text` + 五族微调（把 99 处压到只剩真例外）

**要做什么：** 让浅色主题下**每一个『文字色 × 它自己的底』都过 AA**（小字 ≥ 4.5、大字 ≥ 3.0，
余量 ≥ 0.15）。做法：① 给六族各加一个 text 档（`--X-text`，暗色 = 现值、浅色压暗到过线），
把**当文字用**的色迁过去（描边 / 淡底 / 实心块 / 图标仍用主令牌）；② 把"压在实心块上的字"
也令牌化。每摘掉一条债，01 单那张例外表就少一条——**从红转绿的过程就是判据在起作用的证据**。

**被谁阻塞：** 01（例外表与判据先立起来）。

**状态：** resolved（2026-09-30；结论 / 读数 / 双轴评审处置见文末）
