# 02 — 浅色六族落地：`--accent-text` + 五族微调（把 99 处压到只剩真例外）

**要做什么：** 让浅色主题下**每一个『文字色 × 它自己的底』都过 AA**（小字 ≥ 4.5、大字 ≥ 3.0，
余量 ≥ 0.15）。做法：① 新增 `--accent-text`（浅色 `#005f80`、**暗色 = `--accent` 同值**），
把 **85 处 `color: var(--accent)`** 迁过去（描边 / 淡底 / 图标 / 实心底仍用 `--accent`）；
② ok / warn / danger / info / purple 五族的文字令牌或淡底 alpha 微调到位。
每摘掉一条债，01 单那张例外表就少一条——**从红转绿的过程就是判据在起作用的证据**。

**被谁阻塞：** 01（例外表与判据先立起来）。

**状态：** ready-for-agent

## 验收标准

- [ ] **`--accent-text` 落地**：新增令牌（两主题各一处定义，暗色 = `#00d4ff` 与 `--accent` 同值）；
      `rgba(var(--accent-rgb), …)` 那套不动；令牌无自引用（既有守卫那条腿必须仍绿）。
- [ ] **85 处消费方迁移**：`color: var(--accent)` 全部改走 `--accent-text`（**逐处过一遍**，
      不是批量替换：图标 / 装饰 / 悬停变色这些非文字用途要留在 `--accent`，逐条给出判据与计数）。
      迁移清单与"留在 accent 的处数 + 理由"写进票尾。
- [ ] **六族全部过线**：算法见本单末尾的「判据脚本口径」——每族的「文字色 × 自己的淡底」在
      **四种底**（页面底 `--bg` / 卡片 `--panel` / 加深后的 `--panel-2` / dim 合成底）上
      全部 ≥ 4.5 且余量 ≥ 0.15。浅色不达标数 **99 → 0（真例外除外）**，暗色不得新增。
- [ ] **两处白字压 accent 与 hover 实心底**：`#fff` 硬写改走 `--on-accent`（浅色 4.88 ✓）；
      `--on-accent` 压 `--accent-dark` 的 3.59 修掉（hover 底不再比 `--accent` 更深，
      或另选过线的底 + 文字组合——取值由格网现算决定）。
- [ ] **债表同步收缩**：01 单例外表里属于这六族的 `debt` 条目**逐条摘掉**（摘不掉的要写明为什么）；
      摘掉后前端门禁必须绿——**这是本单唯一的"完成"判据**。
- [ ] **读数**：改前 / 改后各一份（静态清单：不达标数、每族最坏格、`--accent-text` 与
      `--panel-2` 的选型格网 §10 重算）；落盘时间戳晚于最后一次改产品面。
- [ ] **不许退化**：字号档位、描边层级、布局、间距一个字不动；
      `fullBoxes` **115** 与描边两表读数逐字相同；`probe-01` 的「85 处 accent-as-text」在改后
      应变成"0 处仍用 `--accent` 当文字色"（或票尾写清剩余处数 + 理由）。
- [ ] **门禁**：前端门禁全绿；改完必须跑**浏览器门禁**（单独跑，不与全量 pytest 并行）——
      颜色改动只由真浏览器作证。
- [ ] **双轴评审**跑过，发现逐条处置并在票尾记账。

## 备注

- **实施前记（选值探针 `probe-04-family-candidates.py` 的结论，2026-09-30）**：
  「改淡底 alpha」这条路**在浅色下几乎走不通**——因为最坏格不只在淡底上：
  同一个令牌还被当纯文字压在**卡片/页面底**上（如 `fx/task.js` 的 `color:var(--ok-bright)`），
  把 alpha 降到 0.02 也救不了（底本身就不够白）。所以：
  - **浅色**：走"**换文字令牌**"——给每族一个 text 档（暗色 = 现值，浅色 = 探针算出的压暗值），
    把不达标那些 `color:` 迁过去。探针给的首批候选（都能满足 ≥4.65）：
    `ok-bright ×0.62 → #1c6630`、`ok ×0.80 → #15662c`、`warn ×0.78 → #785000`、
    `danger ×0.82 → #aa1c26`（info / purple 同法，见读数全文）。
  - **暗色**：只有 `danger` 那一族要动，且**动 alpha**（0.15 → 0.03 即过关）；
    其余族暗色现值已达标，**一个字节不改**。
  - 六族的 text 档命名沿用 `--accent-text` 的形状（`--ok-text` / `--warn-text` / …），
    **暗色档 = 现值**（暗色零变化的机器证明：暗色那些键的字节不变）。
- **判据脚本口径**（本单的值都按它现算，别按记忆写）：
  底 = `rgba` 淡底**叠到祖先不透明底上**后的颜色（合成基色 = `--panel`）；
  比值 = WCAG 相对亮度比；阈值按该规则自己的 `font-size` / `font-weight` 定
  （≥24px 或 ≥18.66px+bold ⇒ 3.0，否则 4.5）。现成实现见 `probe_lib`，
  改值前先用 `probe-04` 跑一遍两族两侧。
- **两个决定互相咬**：`--accent-text` 越浅 / `--panel-2` 越深，dim 合成那一格越难过线。
  本单按 spec 拍的值走（`#005f80`），`--panel-2` 留给 03 单；
  若 03 单要更深，回来重算这一格（spec §「两个决定互相咬」）。
- 五族微调**优先动淡底 alpha**（对观感影响小）还是**优先动文字令牌**（对语义色影响小），
  由格网结果定——票尾要写清每族选了哪一侧、为什么。
