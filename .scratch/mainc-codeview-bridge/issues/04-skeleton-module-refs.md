# 04 — 骨架引用模块锚定

**要做什么：** 骨架生成（或编辑框内容变化）后，步骤 8 编辑框下方出现「骨架引用的模块」chips——从骨架文本静态提取模块风格调用（`<slug>_init` / `<slug>_read` / `<slug>_update` 等）并与已选模块匹配（ident 以模块 slug 为前缀）；点击 chip 打开该模块的详情弹窗（元数据）。无法识别 = 该区隐藏（宁少标不错标，best-effort）。

**被谁阻塞：** 无——可立即开始。

**状态：** ready-for-agent

- [ ] 骨架含 `led_init(...)` / `adc_init()` 且对应模块在已选列表中 → 显示「骨架引用的模块」chips。
- [ ] 同一模块多次调用去重、按骨架出现顺序展示。
- [ ] 点击 chip → 打开与推荐卡同款模块详情弹窗（元数据 + 文件名列表）。
- [ ] 无命中（骨架里没有任何已选模块的调用）→ 该区隐藏。
- [ ] 提取为纯函数并有单测（tests/js/*.test.mjs）：合法调用命中 / 关键字与字符串内不误收 / 无命中返回空。
