## 这一版有什么变化

- **代码页的语法色与高亮强度变了**：十个语法色在两种主题、每一种高亮状态下都达到 WCAG AA（4.5:1）——
  浅色整体压深一档（关键字、注释这类最深），暗色十个里只动了两个；选中文字与查找的「当前命中」
  降了一档（不再那么重），暗色高亮色换成略深的一支。高亮更轻，但每条高亮下的字都读得清。
- **浅色主题整体更清楚**：正文、说明与五个语义色（成功 / 警告 / 危险 / 信息 / 紫）在浅色底上都压到
  WCAG AA 以上，卡片淡底加深一档让分层看得出来；暗色基本没变（只有几处实心块上的字）。
- **键盘焦点看得见了**：焦点环从 1.8:1 提到 3:1 以上，用 Tab 走一遍就能看出来。
- **禁用态不再「整体变淡」**：不可点的按钮与输入框改成灰底灰字，实测对比度从最低 **2.06:1**
  提到 **5.25:1**——「不能点」不再等于「看不清」。
- 内部还有一批加固（对比度契约由守卫现算 + 真像素量具 + 跨语言镜像守卫），用户可见的影响就是上面四条。
