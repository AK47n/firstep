## 问题陈述

线上最新仍是 **v1.3.0（2026-09-25）**，而 main 上积累了 `hwcheck-hygiene` 一整批（`01`–`14`，
最近一笔 `6402839b`）用户可见的改动，任何发布包里都没有。用户在 v1.3.0 上仍会遇到：

- **页面上到处是字面星号**：JS 产品串 5 处写着 `**…**`，库数据那一层更密——配方说明 **2434 处**、
  74 个模块简介与平台备注 **1844 处**成对标记，经 `esc()` 原样进页面（学生看见的是 `**未上板**`）；
- **两处「失败」不说真话**：母版配置读不出来时页面含糊其辞（不是「文件坏了」），
  检测记录读不出来被说成「记录坏了、删掉重填」；
- **板载 LED 脚写死在页面里**（改板定义（数据）页面对不上）；
- **多实例件（LED / 按键）被默默只测第一路**，页面上一个字都不说；
- **键盘与读屏用户走不通**：勾选后焦点跳走、器件卡键盘达不到、编译/烧录状态读屏念不出来。

同批还有两块**用户看不见但维护面很大**的账：两个大文件按职责拆开（`fx` 1380 行 → 六件、
`ui` 1401 行 → 四件）、前端守卫补洞（全局桥 / 字面星号 / 富文本转义三条判据）、
10 条「源码串断言」换成 11 条真浏览器用例。

## 方案

**发 v1.3.1（修订号 +1：修缺陷 + 页面表达纠正 + 文档，无新增功能）。**

用户可观察的结果：打开工具点「设置 → 软件更新 → 检查更新 → 一键更新」，拿到上面这五条；
新用户走完整包拿到同一份内容。**不带新功能、不带资料库变更**（不发资料库增量包）。

## 用户故事

1. 作为学生，我不想在页面上看见 `**未上板**` 这种记号，我想看见的是**加粗的「未上板」**。
2. 作为学生，母版配置读不出来时我想看到一句中文实话（而不是含糊的失败），
   检测记录读不出来时我不想被误导去「删掉重填」。
3. 作为换了板子的用户，我改了板定义之后，检测页上的板载 LED 脚应该跟着变。
4. 作为勾了 LED / 按键多实例的用户，我想知道**检测只验了第一路**，而不是以为全验过了。
5. 作为只用键盘（或用读屏）的用户，我想勾完器件焦点还在原地、器件卡能 Tab 到、
   编译/烧录状态能被念出来。
6. 作为维护者，我想这一版的发布产物可核对（sha256 实算 = 记录、`00-START-HERE.txt` 在场、
   删除清单非空），以便发完就知道发对了。
7. 作为维护者，我想发完当场把账本（`local-environment` 第 0 节、`VERSIONS.md`、CHANGELOG）改对，
   以便下一轮接手不必重新推一遍。

## 实现决策

- **版本号 `v1.3.1`**（`docs/agents/releasing.md` 的 SemVer 表：小修小补 → 修订号 +1）。
  用户已拍板；本 spec 不改版本号决策。
- **两件套都发**：小发版四件套 + 完整包四件套，同一个 Release（完整包是新用户唯一的安装入口，
  README 只指它一个文件，必须在场）。
- **不带新代码**：本版只做「版本号同步 + 打包 + 发布 + 账本」，三张单见本目录 `issues/`。
- **工作树必须干净**：两个打包器都拒绝脏工作树，而「工单标 claimed / resolved」本身就是 tracked
  变更（2026-09-19 踩过）——所以**先打包打 tag，再落账本与工单标记**（账本提交跟在 tag 之后，
  与 v1.2.2 / v1.3.0 两轮同款）。
- **推送必须钉 IP**：本机 hosts + 本地代理会冒充 github 域名（`curl` 200 也不算数），
  按 `docs/agents/local-environment.md` 第 0 节「本机网络事实」用
  `git -c http.https://github.com/.resolve=github.com:443:<IP>` 钉真 IP。
- **不重跑真机 drill**：`drill-01`（起点 v1.1.1 → 走产品端点升到本版）是 v1.2.2 那一轮的验收；
  本版只保证发布产物自洽，如实记账。

## 测试决策

- 发版闸门照旧一套，**不新造工具**：`tools/preflight.ps1`（三处版本号 / 母版编码钉 /
  下载文档一致性 / README 版本行）+ 推 tag 时 `prepush` 走整套（pytest + 前端门禁 + 浏览器门禁）。
- 本批的读数基线（13 号单实跑落盘）：pytest **5604 passed + 11 skipped**、前端门禁 **1830 / 0**、
  浏览器门禁 **60 / 0**、两平台真编译矩阵 **6/6 PASS**——**发版不再重跑这三道**（本版零代码改动，
  只改版本号与文档），读数以 13 号单为准；推 tag 时 pre-push 闸门会真跑一遍作为独立证据。
- 发布产物核对：两个 zip 实算 sha256 对一次 `sha256.txt`、`tar -tf` 找 `00-START-HERE.txt`、
  两个 `removed.txt` 非空、`tools/check-download-docs.py`（联网版）拿线上最新 Release
  校验 README 体积口径与 Release 说明前两行。
- **验收只看 `git ls-remote` / `gh api .../git/refs/...` 与 Release API**——TCP 可达、
  `curl` 200、浏览器能开页面都不算数（本机有中间人加速器）。
