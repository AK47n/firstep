## 一句话结论

这一族的根因**不是颜色选错了，而是取色写法**（模板变量拼内联 `style`）让所有现成判据都看不见它。
所以修法分两步：**先把取色还给样式块**（治本），**再立一条"不许再这么写"的正向判据**（防复发）——
只做前者，下一处又会悄悄长出来。
