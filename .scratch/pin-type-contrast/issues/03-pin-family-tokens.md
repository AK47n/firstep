# 03 — `--pin-*` 两主题成套 + 文字档 + 入腿⑧

**要做什么：** 把引脚这一族的配色补成**两主题各一套三件套**（主色 / 淡化色 / **文字档**），
并把它的真几何**登记进腿⑧**。端到端行为：四个面的真像素全部过线——文字格 ≥ 4.5、
非文字格（色点）≥ 3:1，**浅色下引脚卡片从此看得清**（类型标、状态文字、板图引脚名、色点），
暗色只动 enc / uart 两处。

**被谁阻塞：** 02（取色要先落在样式块里，文字档令牌才有地方生效、才登得进 token 面）。

**状态：** resolved（2026-10-01；读数见文末）

## 一、色值

- [ ] 七个色族各补齐三件套：`--pin-X`（主色，非文字用：色点 / 焊盘描边 / 板上引脚名以外的图形）、
      `--pin-X-dim`（淡化色，自带底的填充）、**`--pin-X-text`（文字档，新令牌）**。
- [ ] 亮色块补齐 **14 个色件**（7 主 + 7 淡）；暗色只抬不达标的两个（enc / uart）。
- [ ] **硬约束：主色 ≠ 文字档**——主色只要非文字 3:1（色点在 `--panel-2` 上），
      文字档要 4.5（类型标压在自带 dim 底上、状态文字压在 `--panel-2` 上、板上引脚名压在
      `--pin-pcb` 上）。**不许拿主色顶替文字档**，也不许把色相调离原色系。
- [ ] 亮色值不许"只改到刚好过线"：留出与机械面 `--panel` 口径的余量（真底是 `--panel-2`，
      两者对同一对色能差 0.8 左右，见 spec）。

## 二、判据面（腿⑧ 的 token 面：用**层配方**写真相）

- [ ] 类型标：`var(--pin-X-text)` × 层 `--panel-2+--pin-X-dim`（8 族 × 2 主题）——4.5。
- [ ] 状态文字（「已绑 / 现绑」，无自带底）：同一批文字档 × 层 `--panel-2` —— 4.5。
- [ ] 板上引脚名：文字档 × 层 `--panel+--pin-pcb` —— 4.5。
- [ ] 色点（非文字）：主色 × 层 `--panel-2` —— **3:1**（`nontext` 档）。
- [ ] 机械面（类型标那条同规则 `color × background`）**自动**多出 8 格 × 2 主题——
      格数变化必须在工单里解释清楚；它的合成基色是 `--panel`，**过线不等于真几何过线**，
      真几何以上面那几条层配方为准。
- [ ] 新令牌出现即被腿⑧ 的令牌面"表外即红"逼着登记（这是设计，不是障碍）。
- [ ] 跨语言镜像：`.scratch/light-contrast/probe_lib.py` 同步新行（`tests/test_contrast_mirror.py` 钉住）。
- [ ] 红证：把某一族文字档的亮色值改回暗色值 → token 面红（留读数）。
