# 04 — 亮色覆盖成套腿（颜色族必须两主题成套）

**要做什么：** 立一条新腿，判「**颜色令牌所属的族必须在亮色块里整族成套定义**」——不许靠继承
暗色值。端到端行为：`--pin-fixed-pad` 那种"只补了一个值、其余靠继承"的漏（`contrast-residue/03`
靠人眼发现的）从此当场变红；今天盘上**唯一判红面就是本轮修完的 `--pin-*`**。

**被谁阻塞：** 03（`--pin-*` 要先成套，腿一立就是绿的；否则要先挂 debt 再摘账）。

**状态：** resolved（2026-10-01；读数见文末）

## 一、判据

- [ ] 新腿三条：① **正向**——含颜色令牌的族，其**每个**成员都必须在亮色块里有自己的定义；
      ② **反向**——亮色块里定义了、`:root` 里没有的令牌 = 畸形（今天 0 处）；
      ③ **豁免登记表** `THEME_INDEPENDENT_FAMILIES`（前缀 + 中文理由）**双向对账**
      （表里每条都要在盘上认到人且确实不一致；盘上不一致的族要么成套、要么登记）。
- [ ] 口径写死：**"颜色令牌"怎么判**（值或 `var()` 链落到颜色字面 / 渐变）+ **"族"怎么切**
      （前缀分组）——两条都写进腿的注释，并给出今天的分族读数。
- [ ] 判据本体是**纯函数 + 可注入**（照腿⑥–⑩ 的既有形状；红证要喂坏表）。
- [ ] 跨语言镜像：Python 口径侧同步（口径向量表至少覆盖：整族缺 / 缺一个 / 只在亮色有 /
      豁免命中）。

## 落地读数（2026-10-01）

**立了什么**（`tests/js/css-tokens.test.mjs` 腿⑪ + `probe_lib` 的 Python 副本）：

- **口径三条**（写死在注释里）：族 = 名字第一段（`--pin-gpio-text` → `--pin`）；
  **颜色令牌** = 取值（沿 `var()` 链解到底）是 hex / `rgb()` / `rgba()`，或原串含 `gradient(`；
  **成套** = 亮色块里有这个令牌**自己的**定义（靠继承 `:root` 不算）。
- **判据四条**：① 正向（颜色族每个色件都要有自己的亮色定义）② 反向（亮色块独有 = 畸形）

- **豁免表 `THEME_INDEPENDENT_FAMILIES` 今天为空**：盘点过全站 **28 个族**，其中
  **颜色族 19 个**、非颜色族 9 个（`--ambient` / `--dur` / `--ease` / `--fs` / `--header` /
