## 批量决策点（实施时新增/记录，回填 spec）

1. **字体副本命名/static 化**（ILI 两件）：跨模块文件引用不可行（生成按模块目录落文件）→ 每模块携带 lcdfont.h 同源副本；**头基名全局唯一门禁**（test_module_independence）→ 副本改名 `<slug>_font.h`；**数组 static 化**（原 lcdfont.h 全局 const——原件+副本双选链接重复定义）——三接口全部落实到测试/sweep。
2. **deps []（B 类三件 vl53l0x/ili9341/ili9488 + max7219）**：stm32 单平台件 delay 走母版内嵌 ml_delay（headfile.h 聚合）——**死依赖门禁**（test_declared_dependencies_have_actual_include：依赖须有跨模块头 include；ml_delay 非模块头）→ deps []（esp01s/ec11 B 类口径）；lcd/tp/oled 按 mspm0 现状 ["delay"]（mspm0 侧文件 include delay.h 满足门禁）。
3. **oled SPI 命名 oled_spi_ 前缀**：母版 ml_oled 占用 OLED_Show*/oled_show_* 且不可改名/重定义（模块规范红线）→ SPI 路径全部 `oled_spi_` 前缀（与 mspm0 决策 B「同 API」的 stm32 落地差异——I2C 路径零改动，notes 记录）；字库 extern 复用母版 ml_oled_font.h OLED_F8x16（include 会重复定义链接错——extern 化）。
4. **lcd 单文件自实现**：mspm0 lcd.c 绘制层纯 C 但 include mspm0 专属 lcd_init.h（ti_msp_dl_config.h stm32 不可用）→ lcd_stm32.c 单文件（绘制层/序列表/模型表逐行移植零魔改 + 总线层 gpio_set）。
5. **vl53l0x 电平口径 OUT_OD/IU**：页面/移植工程 Out_PP（推挽）→ 与 PA6/PA7 共总线件统一换 OPEN_DRAIN（共总线推挽×开漏互斥）+ SCL/SDA 初始化置高（批次 3/01 回修口径）；XSHUT Out_PP 保留页面原式。
6. **ili 初始序列/18bit 打包只能按包内实现**（页面零序列零引脚表——全页外）。
