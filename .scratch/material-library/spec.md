# 素材库（赛题库 + 参考文件库）— ADR 0006 实施

## Scope

- **赛题库**：历年真题长 PDF 导入 → AI 拆条（年份 / 编号 / 题面全文）→ 用户逐条校对 → 确认入库（事务，与提炼确认同风格）。磁盘目录即数据库：一条目一目录，题面落 `.md`，原 PDF 保留在条目目录（AI 拆错可查原文）。提供编号解析（"2026C" → 题面），供生成入口与 AI 理解使用；条目锚定该题附带的完整程序（2026C 钥匙/锁两套的存放/引用方式）与关联模块（复用"XX 题专用"标注自动发现，不新造链接字段）。
- **参考文件库**：上传配套资料（例程工程 / 说明书）→ AI 生成简介 → 用户补锚定（赛题编号 或 套件型号——套件必须从模块库已有 kit 词表选，不新打字）→ 入库（草稿→校验→入库，复用模块录入流程）。提炼报告动作表新增"归档为该题参考文件"：被剔除的业务代码一键复制入库、锚定该题（内容自持，源工程删除不丢）；构建残留 / 二进制仍确定性剔除，不配归档。浏览 / 搜索（按标题 / 类型 / 锚定）。
- **生成接线**：生成入口支持选历史赛题编号（带出题面 + 关联素材 + 该题专用模块）；粘贴题面中出现编号时同样可认。选模块阶段两级注入参考文件：候选清单带"该赛题/套件关联的参考文件（标题 + 一句话简介）" → LLM 判断需要时取全文；长 PDF 题面全文只在选了该赛题时进上下文。
- **拆条分块（工单 04）**：长 PDF 分批拆——flash 模型输出预算小会静默漏题（实测 2017-2025 汇总 163K 字符只回 2-3 题/年）；按年章节 + 标题标记确定性切到单题、分批调 LLM（或纯确定性切分），已验证 69/69 全对（`.scratch/real-run/topic_split_by_year.py`）。
- **赛题库管理 UI（工单 05）**：浏览/搜索/拆条录入（逐条校对）/删除页签；后端补 GET /api/topics 列表与 DELETE /api/topics/{key}。参考文件库 UI 已先行完成（PR #10，样式样板）。

## Out of Scope（本批不实现）

- 骨架生成阶段读参考文件（等真实用例再评估）
- 参考文件问答（聊天式）
- 题库按内容语义检索（只按年份 / 编号 / 标题 / 锚定检索）
- 其余 UI 层（模块库/提炼/设置等已有页面不动；素材库 UI 由工单 05 与 PR #10 覆盖）

## Implementation Decisions

- 磁盘目录即数据库（延续模块库）：赛题条目字段 = 年份 / 编号 / 题面路径 / 附带程序目录 / 原 PDF；参考文件条目字段 = 标题 / 类型 / 简介 / 锚定（赛题编号 或 kit 型号）
- 跨区链接只存字段：赛题 ↔ 模块 复用"XX 题专用"标注；参考文件 ↔ 套件 用 kit 词表（录入时从已有值选、校验拒绝词表外值）
- 两级注入协议：先清单（标题 + 简介）→ LLM 判断 → 按需取全文；选模块 prompt 扩展，骨架生成 prompt 不动
- 归档 = 复制入库（内容自持）；归档动作挂在提炼报告上、随确认事务一起提交
- 编号解析：显式输入或 AI 从文本提取 "年份 + 编号" → 查库得题面；查无此条时明确报错（不猜测编造）

## Testing Decisions

- 假 LLM 注入：拆条、简介生成、归档判定、注入清单的固定返回
- 目录结构断言：条目落盘形状、原 PDF 保留、锚定字段校验（kit 词表外值拒绝、赛题编号查无此条拒绝）
- 事务性：确认入库、归档单动作原子，失败不留半成品
