### 人眼结论（本单要求"觉得过暗/过淡就连值一起调"——**不必调**）

- 浅色：语法色整体比改前深一档（`kw #005673` / `com #135c28` / `str #785000`），
  在白底上读起来是**正常的浅色语法调色板**，没有"糊成一团"或"发黑"的感觉；
- 暗色：只动了 `pre` / `const` 两个（各 +6%），观感与改前基本无差别；
- 高亮：选区/当前命中从 `.32/.38` 降到 `.20/.24`，肉眼**能看出淡了一档**但依然清晰可辨
  （截图里查找命中的一条条淡带都在）；层序（.07 < .12 < .18 < .20 < .24）在人眼下成立。
