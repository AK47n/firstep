# 02 — 落值：高亮降一档 + 二十个令牌（`--tok-*` 的族债还清）

**要做什么：** 让十个 `--tok-*` 在两主题 × 七层上**全部 ≥ 4.5**（留 ≥ 0.15 余量），
并且**暗色语法色基本不变**（十个里只动两个、各 1–4%）。做法是两边各让一步：

- 层侧降一档：`.code-ta::selection` `.32 → .20`、`.code-mark-current` `.38 → .24`（**层序保持**：
  `.07 < .12 < .18 < .20 < .24`）；
- 令牌侧：浅色 8 个压暗（`kw/tag` 最深 ×0.576）、暗色 2 个微调；
- 暗色高亮色略深一档：`--code-hl-rgb: 0, 190, 230`（浅色保持 `0, 150, 199`）。

做完 `--tok-*` 那条族债应从例外表里**消失**（不是改小，是摘掉）。

**被谁阻塞：** 01（口径与几何先到位，否则读数不成立）。

**状态：** ready-for-agent

- [ ] **层 alpha 降档**：`.code-ta::selection` → `.20`、`.code-mark-current` → `.24`；
      守卫层表里这两行的 alpha 同步改（名字不变），镜像守卫跟着一致。
- [ ] **`--code-hl-rgb` 暗色值** → `0, 190, 230`（浅色不动）。取值依据：`probe-00` §10 的扫描
      ——`0,190,230` 与现值 `0,212,255` 的可见度只差 8%（1.66 → 1.53），却把暗色要改的令牌
      从 4 个降到 2 个；再深（`0,120,150` 一线）可见度掉到 1.24 而令牌数不再降。
- [ ] **浅色八个令牌换值**：`--tok-com #135c28`、`--tok-str/--tok-val #785000`、
      `--tok-pre #4b535d`、`--tok-kw/--tok-tag #005673`、`--tok-num/--tok-attr #663eae`；
      `--tok-fn` / `--tok-const` **不动**（现值 5.24 / 4.72 已达标）。
- [ ] **暗色两个令牌换值**：`--tok-pre #909aa4`（×1.038）、`--tok-const #c788c2`（×1.012）；
      其余八个**逐字节不动**。
- [ ] **族债摘干净**：`generate-01-contrast-register.py --write` 重算后，`族：--tok-* …` 那两条
      （dark / light）从 `CONTRAST_EXCEPTIONS` 里消失；守卫的族面判据现算全部 ≥ 4.5。
- [ ] **几何边界的读数落盘**：叠加态（选区叠词命中 / 叠搜索命中 / 叠当前命中）与七层单层的
      两张矩阵都进 `probe-00`/`probe-01` 读数——**边界如实量、不当成达标**。
- [ ] **括号彩虹族**在新令牌下重算（`--code-text` 与彩虹底都不动，读数应逐字节相同）。
- [ ] **合成红证**：令牌改浅（把某个 `--tok-*` 改回现值）→ 红；层 alpha 改回 `.32/.38` → 红；
      `--code-hl-rgb` 改回亮青 → 红（暗色那两格掉线）。
- [ ] **读数**：`probe-00` / `probe-01` 重跑（两主题 × 七层的最坏格、十个令牌的落定值）；
      代码页样例的真像素采样（浅/暗）——**"过线"要有屏幕上量出来的那一份**。
- [ ] **门禁**：前端门禁全绿；全量 pytest 全绿；**浏览器门禁单独跑**。
