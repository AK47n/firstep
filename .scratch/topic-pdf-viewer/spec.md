# Spec：取题面直接展示原题 PDF 页（默认看图，文字可切换）

## 问题陈述

用户用真机输入编号取题面（如 2021F）后，页面把题面全文铺成一大片文字。
用户原话：「我输入编号的，然后我希望直接给我展示pdf就行了，不要想现在
这样给我展示文字」。题面文字又长又密，图（如 2021F 图1 院区示意图）在文字
里只是一段标注文字，读起来不直观——用户想直接看到原题 PDF 页面，像看纸质
卷一样对照图与文字。

## 方案

取题面成功后（输入编号 / 赛题库「用此题生成」两条路径），页面**默认展示原题
PDF 的题面页**：页图从上到下叠放，点击任意页全屏放大查看（移动端友好），
原题文字收起，提供「显示文字版（可编辑）」按钮随时切回编辑。

技术路径（全部复用既有能力，零新增依赖）：

- 条目目录内已保留原 PDF 副本（入库时复制）——取题面入口与页图展示同源。
- 题面页定位：题面独特文本（去空白前 20 字符）逐页匹配文本层 → 命中页起
  2 页范围（图紧跟正文第 1~2 页）。
- 逐页渲染 PNG（PyMuPDF 硬依赖，2 倍缩放既有参数）→ base64 data URL 返回。
- AI 读取的仍是完整题面文字（文字框值不变），下游流程零改动。

纯展示功能：PDF 缺失 / 定位失败 / 渲染失败 → 明确的中文错误提示，文字框
照常可用，不阻塞主流程。粘贴 / 上传路径 UI 不变（无条目、无原 PDF，仍只有
文字框）。

## 用户故事

1. 作为参赛学生，我想要输入编号取题面后直接看到原题 PDF 页面，以便像看
   纸质卷一样直观读题、对照图与文字。
2. 作为参赛学生，我想要点击页面图片放大查看细节，以便看清图内尺寸标注与
   走线走向。
3. 作为参赛学生，我想要一键切回文字版编辑题面，以便修正或补充题面文字。
4. 作为参赛学生，我想要在手机上也正常看页图，以便真机使用。
5. 作为参赛学生，当原 PDF 缺失或页定位失败时，我想要明确的错误提示而不是
   页面卡死，并且文字框仍然可用。
6. 作为参赛学生，我从赛题库卡片点「用此题生成」时，同样直接看到原题 PDF
   页面。

## 实现决策

- 新增「取题面页图」接口：编号 → 条目 → 条目目录内原 PDF 副本 → 题面页
  定位 → 逐页渲染 → 返回页列表（页码 + data URL）。
- 错误语义：查无此条沿用既有明确报错；条目无原 PDF / 文件缺失 / 定位失败 /
  渲染全失败 → 400 中文错误（各自说明原因）。
- 前端：取题面成功 → 拉页图 → 展示区页图叠放 + 点击放大（全屏遮罩，点
  任意处关闭）；文字框默认收起，「显示文字版（可编辑）」按钮切换（再点
  收起）；上传 / 手动输入路径清除旧页图展示。
- 两条取题面路径（输入编号、用此题生成）共用同一页图加载逻辑。
- 页面尺寸：沿用既有渲染缩放产物，不重新调参；页范围最多 2 页，数据量
  可控。
- 不新增依赖。

## 测试决策

- 复用既有 HTTP 测试库接缝（假模块库 + tmp 赛题库根 + 假 LLM + TestClient）：
  - 构造条目（单页可渲染 PDF，题面文本与 PDF 文本层匹配）→ 断言页图数量、
    页码、data URL 前缀与 PNG 魔数。
  - 定位失败（题面文本不在 PDF 中）→ 400 中文错误。
  - 原 PDF 文件缺失 → 400 中文错误。
  - 渲染失败（monkeypatch 渲染函数 → None）→ 400 中文错误。
  - 查无此条 → 既有编号解析错误契约（400）。
- 定位 / 渲染原语已有单测覆盖；本工单聚焦接口契约；前端交互手工 / 真机验证。
- 全量 pytest 绿 + mypy src 干净。

## 范围外

- 不改变 AI 读取题面的方式（仍是文字 + 图注段）。
- 不做 PDF 原件下载 / 整本翻页浏览（只展示定位到的题面页）。
- 不改入库流程（题面页范围暂不写入 manifest）。
- 不动粘贴 / 上传路径的 UI。
- 不调整澄清 / 推荐环节的问题判定（见 clarify-dumb-questions 与后续工单）。

## 补充说明

- 交互已与用户确认：默认展示 PDF、文字可切换。
- 2021F 实测素材：汇总 PDF 文本层可定位题面页；图1 页渲染后尺寸标注与
  红实线可辨——展示层直接用同一渲染产物。
- 真机照片路径（/api/extract）与粘贴路径无条目原 PDF，不展示页图，保持
  现状。
