## 问题陈述

六条是**三类**毛病，共同点是「闸门看不见」——不是算错，是**静默不判**：

1. **令牌定义面只认第一段**。页面里有两处 `:root`（第二处是引脚配色那一族）。守卫与探针的解析面
   都只读第一处 ⇒ **19 个令牌"查无此值"**。后果有三层：① 登记表里那两条只能写 `skip`（"静态判不了"），
   真实理由没人再往下看；② **亮色块漏覆盖**一并看不见——`--pin-fixed-pad` 在浅色下仍沿用暗色值
   （近黑），与浅灰的空闲焊盘**不是一套**，用户看得见；③ 任何"解析不出 → 不判"的缺口都没有账。
2. **`opacity` 只按"像不像"抓**。全站 18 条活规则里只有 4 条在册（三处上一轮已改成灰底灰字），
   其余 14 条靠"类名词法 + `cursor: not-allowed`"两个**代理信号**才够得着——换个名字就没人管。
   那 14 条今天的实际状态是"**没人逐条看过**"，不是"看过、判定合法"。
3. **写错令牌没人拦**。`color: var(--fg)` 这种笔误在浏览器里按 `inherit` 渲染、看上去"没坏"，
   所以它活到今天还挂在登记表里当 `skip`。全站同型笔误只此一处，但下一次不会有任何东西拦。
   （同批量出的 `--code-font-size` ×6 / `--hwcheck-title-mark` ×1 是**类作用域定义**，合法写法——
   这正是"定义面"必须按**任意 CSS 块**算、而不是按令牌块算的理由。）
4. 两处**取证缺口**：引脚菜单里"不兼容"那一行（`.pin-menu-list li.cant`）从没量到过真像素，
   它的可达性只靠"同一对色的静态推算"背书；"选中叠命中"（浅 3.42 / 暗 3.11）与
   "`--accent` 当非文字描边"（2.70）两笔债只写在工单尾巴里，没进任何守卫的注释或台账正账。

## 方案

按**三个面**收口，全部落在既有缝上（**不新造第五套做法**）：

- **令牌定义面**：解析面从"第一个 `:root`"扩到"**全部 `:root` 块合并**（后者覆盖前者）"，
  两侧（JS 守卫 / Python 口径）同源，并用**行为向量表**钉住"扩了之后的行为"；
  另加一条腿：**无兜底的 `var(--x)` 必须在盘上某个块里有定义**（任意块都算：`:root` / 亮色块 /
  类作用域规则；带兜底的写法天然合法）。
- **不可选形态登记面**：把登记表从"嫌疑面驱动"改成"**全量 `opacity<1` 驱动**"——每条活规则都要在册、
  挑一个档位（`disabled` / `dim`）并写中文理由；判成 `disabled` 的按 §33 先例改成灰底灰字 + 形状信号。
  词法嫌疑面（词表 + 光标信号 + 行为向量表）**整条退役**——全量登记之后它不再有判据用途。
- **真像素面**：给 `.pin-menu-list li.cant` 补一条可复现的操作配方与真像素读数（量具扩口径，
  不是重写量具）。

用户可见的变化**只有两处**：① 三条原先被 `opacity` 压到 AA 以下的文字变清楚
（`.res-soft` / `.sugg-count` / `.chip.rec.unsel .reason`，浅色 3.19–4.12 → 5.25 一档）；
② 浅色主题下板图里"固定/电源"焊盘的颜色（从近黑改成与浅灰空闲焊盘一套）。

## 实现决策

- **模块**：前端守卫（腿⑥–⑨ 那个文件）新增/改写两条腿；Python 口径模块同步；跨语言镜像守卫
  增删对应腿；真像素量具只扩口径（加一条流程与一处"要量的元素"），不重写。
- **接口**：解析面（令牌表构造）与登记表（不可选形态）是仅有的两处**被改的接口**；
  两者都保持"纯函数 + 可注入参数"的既有形状（红证要喂坏表）。
- **技术澄清**：
  - 合并 `:root` 的语义 = **后者覆盖前者**（与 CSS 同特异性下的源序一致）；
  - "定义面"= **任意规则体**里的 `--x:`，不是只有令牌块——否则 `--code-font-size` 这类
    类作用域定义会被误判成笔误（实测 2 处假阳性）；
  - `var(--x, 兜底)` 且 `--x` 无定义 = **合法**（兜底即基值），不进判据；
  - 真像素那条例外：既无兜底、又无定义、又不是运行时注入的，只有 `--fg` 一处。
- **架构决策**：不新增缝。三个面各自复用既有先例：合成红证（内存注入坏表）+ 真文件反证
  （改盘上文件 → 红 → 复原）+ 跨语言行为向量表 + 探针读数每轮重跑。
- **模式变更**：登记表多 14 条、少 2 条 `skip`；档位表少一个 `skip`；令牌面多一张向量表。
  所有冻结形状数（机械面对数 / 族面格数 / 例外表条数 / 渲染方登记条数）**每轮现跑**，
  变了必须解释成"改对了"还是"抽取面坏了"。
- **具体交互**：无 UI 交互变化（除浅色焊盘配色）。

## 测试决策

- **什么构成好测试**：判**外部行为**——"盘上有没有未定义的令牌用法"、"每条 `opacity<1` 有没有在册"、
  "两个色点在不在册"，不判实现细节（正则怎么写、函数怎么拆）。
- **测试哪些模块**：既有三处（前端守卫面 / 跨语言镜像面 / 真像素量具面），一处都不新增。
- **既有先例**：`disabled-forms` 轮的四条判据 + 合成红证、`light-contrast` 轮的"合成红证 14 类 +
  真文件反证"、`ui-density-sitewide` 的三条纪律（读数每轮重跑 / 浏览器门禁单独跑 / 注释里的数按脚本复算）。
- **判据强度**：每条新腿都要有"**stub 掉就变红**"的自检；真文件反证至少覆盖
  "把 `--fg` 放回去""把某条 `opacity` 从登记表里摘掉""把第二个 `:root` 挪走"三类注入。
- **每张单的读数**：探针输出落盘到本目录；读数的时间戳必须晚于最后一次改产品面。

## 范围外

- **叠加态的定价**（选中叠命中：浅 3.42 / 暗 3.11）——本轮明确**记债不收**：要收它得让所有高亮
  淡到几乎看不见（选区 α ≈ .12 量级），属设计决定。
- **`--accent` 控件普通描边 / 语义左条的非文字 3:1**（现算 2.70）——记债不动（装饰性强于信息性）。
- **系统性"非文字 3:1"判据**（描边、图形、色点）——本轮只给两个图例色点**定归属**，
  不给全站立非文字档（那会牵出整片板图与描边配色，是另一轮）。
- **两个色点的填充比值**——归 `surface-bordered` 就是"填充不判、描边承担分层"，本轮不改配色。
- **发版**：本轮不发版。
- 库层（`library/**`）与 `tools/**` 的一切改动。

## 补充说明

- **本轮实测的三条新读数**（探针在本目录，可复跑）：
  1. 页面有 **2 个 `:root` 块**；旧解析面只读第一个 ⇒ **19 个令牌看不见**，其中 **17 个连亮色块
     都没覆盖**（含 `--pin-fixed-pad`）；

     `--hwcheck-title-mark` ×1 是类作用域定义，合法）；
  3. `opacity<1` 活规则 **18 条**：在册 4 条、未在册 **14 条**（另有 `@keyframes` 帧 5 条，判据排除）。
- **两条判读纪律**（免得下一轮读错）：① `--code-zoom` / `--code-tree-w` 是**运行时注入**的令牌
  （JS `setProperty`），带兜底写法，永远不进"未定义"判据；② `--pin-pad` **亮色有覆盖、暗色没有**——
  这是"解析面看不见第二个 `:root`"的直接后果，别读成"亮色写错了"。
- **命名（防串号，工单里一律写全名）**：`backlog.md` 说的「腿⑩」= **全量登记**（把不可选形态登记表
  从嫌疑面驱动改成全量驱动）——它落在守卫文件**腿⑧ 的判据②** 上，**不是**文件里的第十条腿。
  本 spec 新加的那条腿（无兜底 `var()` 必须有定义）才是守卫文件里顺号的 **腿⑩**，本轮一律称
  **「令牌定义面」**。两处都用全名，**不写裸编号**。
