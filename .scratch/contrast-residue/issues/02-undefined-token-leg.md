# 02 — `--fg` 笔误修掉 + 立「令牌定义面」腿（无兜底的 `var()` 必须有定义）

**要做什么：** 页面上唯一一处真笔误 `color: var(--fg)`（令牌从没定义过，浏览器按 `inherit` 渲染，
所以看上去"没坏"）改成真令牌；同时把「**无兜底的 `var(--x)` 必须在盘上某个块里有定义**」立成守卫腿
——全站现在只有这一处违规，改完 0 处，**下一次同型笔误当场红**（而不是靠评审的眼睛）。

**用户可见变化：无**（改前它渲染的就是继承来的 `--text`；改后是显式 `--text`——**同一对色**，
真像素/计算样式取证"改前 = 改后"）。

**被谁阻塞：** 01（令牌定义面扩到全部块 + "任意块算定义"的底座）。

**状态：** ready-for-agent

## 一、产品面

- [ ] `.pin-subtitle` 的 `color: var(--fg)` → **`var(--text)`**；注释里写明"原 `--fg` 是笔误、
      渲染上一直等于继承色"（免得下一个人以为改观感了）。
- [ ] **零观感取证**（两类证据都要）：① 计算样式——两主题下该元素改前 / 改后的 computed `color`
      逐字节相同；② 真像素——同一元素两主题各一张改前 / 改后对照（照 `disabled-forms/02` 的
      `--tag` / `--dir` 口径跑量具）。

## 二、判据（新腿「令牌定义面」）

- [ ] **定义面 = 任意规则体**里的 `--x:`（`:root` / 亮色块 / 类作用域规则都算）。
      ⚠ **不许按令牌块算**——实测会出 2 处假阳性：`--code-font-size`（×6）与
      `--hwcheck-title-mark`（×1）都是**类作用域定义**，是合法写法。
- [ ] **扫描面** = 页面 `<style>` 块 **+** `static/js/**`（渲染方里也有 `var(--x)` 用法，
      照腿⑨ 的既有扫描面）。
- [ ] **带兜底的写法天然合法**：`var(--x, 兜底)` 即使 `--x` 没定义也不判（兜底即基值）。
      实测这一类有 `--code-zoom`（×5，**运行时注入** + 带兜底）、`--code-tree-w`、
      `--code-side-w`、`--warn-fg`。
- [ ] **边界写进注释**：运行时注入的令牌（JS `setProperty`）永远不进判据；类作用域定义合法；
      带兜底合法；"解不出"不等于"不存在"。
- [ ] **摘掉令牌面那条 `skip`**（`var(--fg)`）：改完盘上不再有这个字面，留在表里就是死条。
      两侧（JS 守卫 / Python 口径）同批摘，镜像守卫跟着改。

## 三、红证

- [ ] **真文件反证**：把 `var(--fg)` 放回去 → 前端门禁红（点名文件与用法）→ 复原（sha256 核对）。
- [ ] **合成注入**：① 把一个真令牌改名（盘上定义改成 `--text-x`）→ 红（原用法失去定义）；
      ② 给某个未定义令牌补上兜底 → **不**红（边界用例）；③ 在 `static/js/**` 里插一处无兜底未定义
      `var(--nope)` → 红（证明扫描面覆盖渲染方）。
- [ ] **判据强度**：把定义面退回"只认令牌块" → 红证 ② 反过来红（假阳性复现），证明这条腿
      真的按"任意块"判。
