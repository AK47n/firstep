# 01 — 令牌解析面扩到全部定义块（两侧同源 + 行为向量表）

**要做什么：** 守卫与探针的"令牌表"从此能看见页面里**全部** `:root` 块（页面作用域那一段也算），
并且"哪些块算定义、值怎么取"这件事有一张**两侧共用的行为向量表**。做完之后，此前"查无此值"的
**19 个令牌**解得出来（`--pin-*` 一族），登记表里那两条 `skip`（"静态判不了"）才有资格重新归类；
同时给"**任意块里的 `--x:` 都算定义**"这个更宽的面留下底座（02 单要用）。

**这一单不改任何产品面**（零用户可见变化），只改解析面与它的守卫。

**被谁阻塞：** 无——可立即开始。

**状态：** resolved（2026-10-01；读数与红证见文末）

      与 CSS 同特异性下的源序一致）；亮色表同理处理所有 `html[data-theme="light"]` 块。

      **两侧共用同一张表**（JS 侧断言 JS 实现，Python 侧断言 Python 实现）。
      照 `CONTRAST_HINT_VECTORS` 的既有形状写（那张表本轮退役，但形状先例留着）。
- [x] 向量表至少覆盖四条边界：① 后者覆盖前者；② 亮色覆盖只在亮色生效；
      ③ 类作用域定义**不进令牌表**（那是 02 单的"定义面"，两者不是同一件事——写清）；
