## 1. 回源码核过的事实（与 recon / 工单的对照）

| 结论 | 源码出处 | 与工单/recon 是否一致 |
|---|---|---|

| **mspm0 的 HX711 引脚 = PA28(SCK) / PA31(DT)** | `mspm0.syscfg:334,338` + `hx711` manifest notes | 工单一致；⚠ **模块头注释 `hx711.h:14-16` 写的 PB24/PB8 是过期读数**（历史默认）——本单不改库，记账进 backlog |
| `JOYSTICK_ADC_MAX` / `_SAMPLES` 在 mspm0 侧只在 **.c** 里 | `joystick.c:16-18`（头 `joystick.h` 只有函数声明）；stm32 侧在 `joystick_stm32.h:31,35` | 一致 |
| mspm0 忙等超时用**自旋圈数**（50，≈几微秒）而一次转换 ≈1ms | `joystick.c:25-30` | 一致（D2 推断，未上板） |
| `servo_init(servo_id, channel)` **双参**、`servo_set_angle` 双参、形参被 `(void)` 丢弃 | `servo.h:37-38`；`servo_mspm0.c:21-24` / `servo_stm32.c:20-23` | 一致（D5/D6） |

| `relay` 接口只有 `relay_init()` / `relay_set(0\|1)`、`RELAY_ON_LEVEL = 0u` | `relay.h:40,44,50`；`relay.c:23-27` / `relay_stm32.c:32-37` | 一致（D7） |

| mspm0 RELAY 初值 = **断开**（`initialValue = "SET"`，低电平吸合） | `mspm0.syscfg:748-749` | 一致 ⇒ 该平台**没有**上电咔哒 |
| 引脚（stm32）：JOYSTICK X=PA1/Y=PA0/SW=PA10；SERVO PB6；RELAY PB4 | `pin_config.h:205-208` / `:29-30` / `:128-129` | 一致 |
