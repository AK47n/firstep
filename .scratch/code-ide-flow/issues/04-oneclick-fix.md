# 04 — 一键修复直达：IDE 编译失败 → 跳生成页自动开始修复循环

**要做什么：** IDE 编译失败时「去生成页一键编译修复」按钮：点击后跳转生成页
修复中心并**自动开始** AI 修复循环（不再要求用户二次点击「一键编译修复」）；
自动开始前照旧过写盘守卫（代码栏有未保存编辑 → 先确认保存全部，取消则中止）；
守卫取消 / 无工具链等前置不满足时行为与手动点击一致（按钮置灰文案不变）。

**被谁阻塞：** 无——可立即开始（与 01/02/03 并行）。

**状态：** ready-for-agent

- [ ] 验收 1：IDE 编译失败（目录 = 生成上下文）→ 点按钮 → 切到生成页修复
  中心 → 自动进入修复循环（AI 行动横幅出现、编译/修复事件照常流转）。
- [ ] 验收 2：代码栏有未保存编辑 → 跳转后先弹写盘守卫「保存全部并继续 /
  取消」；取消 → 不开始循环。
- [ ] 验收 3：无工具链 / 平台未选 → 按钮不可用或跳过自动开始（与手动入口
  同判据，不引入新状态）。
- [ ] 验收 4：修复循环完成后 IDE 侧（若已打开同目录）可经 02/03 感知到写盘
  变更（集成不回归）。
- [ ] 验收 5：CDP 冒烟覆盖主路径；全量回归绿。

**结论：** （实现后补）
