## st7789_para 实施要点

- **库内首个 8 位并口（8080 接口）显示件**：14 脚 GPIO 位操作（DB0-7 + RD/WR/CS/DC/RES/BLK），不占 FSMC/TIMER/硬件外设；包内 LCD_Writ_Bus 原式（CS 低→WR 低→8 位并行置数→WR 高→CS 高；RD 仅读向不参与）。
- 初始化序列 = 立创包 lcd_init.c LCD_Init 原式直提；USE_HORIZONTAL 宏方向化 = 运行时 dir 表（MADCTL 0x00/0xC0/0x70/0xA0 + 地址偏移 52/53/40/40 × 40/40/53/52；dir 0/1 竖屏 135×240、2/3 横屏 240×135，默认横屏=包 USE_HORIZONTAL=2）。
- API 照 mspm0 lcd.h 风格（ili 两件同款 15 函数，含 show_chinese16x16；不照 lcdwiki 旧壳）。
- 字库 = 库内 lcdfont.h 同源副本 st7789_para_font.h（字符集比对结论：包内 lcdfont.h 与库内同源——ascii_1608 逐字节一致、tfont16 五字同形同阵仅 GBK 索引写法不同；**API 口径 12/16 字号需要 ascii_1206——包内无此套** → 库内副本；static 化 + 头基名唯一门禁）。
- 默认 14 脚 = 工单重拍（包默认 14 脚全弃用——全撞既有占用）：DB0-7=PB4/5/6/7/PB0/1/PB3/PA8、RD=PA5/WR=PA4、CS=PC13/DC=PC14/RES=PC15/BLK=PA15；数据线叠采集/运动/输入类、控制线叠板载灯+蜂鸣（输出指示互替）、与显示族互替（一次一块屏）。
- pic.h 演示位图不入库（mspm0 先例）；wordlist 显示模块组补录（1.14 寸 ST7789 并口屏方案 + models ST7789 并口屏）。
