# Spec：塔克 R3 资料合规下架 + 自写知识总结（tark-removal）

## 问题陈述

用户确认：本项目与烟台塔克电子科技有限公司**无任何授权/合作关系**。塔克资料包
（`C:\Users\luoji\Desktop\塔克 l R3系列两驱小车底盘资料_20241015` 及仓库内镜像）包含
`O 版权声明.pdf`，其声明核心：

> 未经本公司书面许可，任何单位及个人不得以任何方式或理由对本手册内的产品、服务、
> 信息、材料的任何部分进行复制、修改、抄录、传播、翻译成其他语言、或与其它产品
> 捆绑使用、销售。

与立创 wiki（注明来源+链接即可）不同，塔克声明要求**书面许可**——仅标注来源不构成合规。
我们的使用面（均缺许可）：

- **对外传播**：`sources/materials/塔克R3两驱小车底盘资料/`（含手册 PDF、源码 zip、
  软件安装包、MP4 视频）随 6GB 完整包 / materials 增量包分发 = 复制 + 传播。
- **生成链**：`library/references/塔克R3-*` 6 个条目（约 964KB 解包源码，
  DB20 五例 + 整车控制源码 = 塔克原代码）支持手动准入全文直读注入 LLM =
  修改 + 捆绑使用。
- **模块库**：✅ 已核实零塔克引用（manifest / kit / 代码注释均无）——模块均
  自写 / 立创 / 逐飞来源，无塔克衍生代码，模块库不动。

用户决策：**全部下架**（不传播、不进生成链）；塔克资料中有价值的知识
（PID 闭环 / 编码器测速 / 运动学模型）**由我们自己重新总结编写**，不含塔克原文，
作为本工具自己的知识沉淀（学习 = 人吸收原理，代码 = 自己写）。

## 方案

1. **生成链断源（优先）**：删除 `library/references/` 下 6 个 `塔克R3-*` 条目
   （`delete_reference` 走 store 删除 + 自动 git 提交），LLM 生成不再可能读到塔克源码。
2. **分发下架**：删除 `sources/materials/塔克R3两驱小车底盘资料/` 目录——
   下一次 materials 增量包（diff 基线机制）自动产生该批次的 removed 清单 / 整批消失，
   已安装用户侧自动删除；完整包 next 版自然不含。
3. **知识沉淀（自写）**：新增 `docs/third-party-summaries/塔克R3底盘控制知识总结.md`
   或仓库根文档——由我们自己撰写：PID 速度/位置环原理、正交编码器测速原理、
   常见底盘运动学模型（两轮差速/四轮差速/麦轮/阿克曼）的通用数学表述。
   **不得复制塔克原文段落**（只写普适原理与自推表述；算法/公式本身不受版权保护，
   保护的是表达）。该文档不进参考库（不注入 LLM——学习主体是人，不是机器抄）。
4. **声明补全**：仓库 README「第三方素材来源与知识产权说明」加塔克段——
   版权归烟台塔克电子科技有限公司、官网 www.xtark.cn、本工具已下架其文件、
   学习资料请用户自行前往官网获取。
5. **测试兜底**：真库不变量测试翻转——参考库不得出现 `塔克R3-*` / `xtark` 条目
   （防回潮：以后再录入即红）；`test_materials_pack` 的 `slug_for_dir("塔克R3两驱小车底盘资料")`
   保留（纯函数，与库状态无关）。

## 用户故事

1. 作为参赛学生，我想要生成工程完全不含塔克源码/代码，以便合规使用与传播。
2. 作为工具维护者，我想要参考库/打包清单的测试自动拦截塔克条目回潮，
   以便未来不再重蹈覆辙。
3. 作为学习者，我想要一份我们自写的底盘控制知识总结（PID/编码器/运动学），
   作为「塔克资料里真正有用的东西」的沉淀，将来写代码时有原理可依。
4. 作为发布者，我想要 README 说明塔克版权归属与下架决定，以便公开分发时如实告知。

## 实现决策

- **删除走既有 API**：`reference_library.delete_reference`（entry_store.delete_entry，
  autocommit 默认开 → 自动 git 提交，符合库 CRUD 惯例）。
- **sources/materials 删除**：直接删目录（不在 git 内）；打包机制自动处理 removed。
- **知识总结**：仓库根 `docs/`？——按现有仓库结构，仓库根无 docs 总结惯例；
  新建 `docs/third-party-summaries/` 目录，放自写总结（中文、含公式）。
  总结内容撰写依据 = 塔克资料目录结构（素材清单）+ 通用知识；**不回读塔克 PDF
  原文句子**（写普适原理）。
- **README**：第三方素材段补塔克条目（版权归属 + 官网 + 下架说明）。
- **测试**：`tests/test_reference_library.py` 真库塔克不变量测试段：
  从「6 条目必须存在」翻转为「库内不得存在 塔克R3* 条目（防回潮）」；
  保留纯函数测试（slug_for_dir / 假库夹具不动——假库测试本就用假数据）。

## 测试决策
