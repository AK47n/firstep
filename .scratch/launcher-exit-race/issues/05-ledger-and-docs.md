#### ④ 本特性四处「如实记账的代价」（给下一轮读的人）

1. **宽限仍是时限判据**：极端负载下（浏览器或服务端被饿 > 1.5 秒）F5 仍可能命中自杀路径——
   比修复前（任何模块图 > 1.5 秒，那是常态）窄两个数量级，但**不是零**。见工单 04 Comments ④。
2. **"关浏览器 = 停服务"只有一半有机器证据**：夹具用"真导航离开"验同一条 `pagehide` +
   `sendBeacon` 路径；真关窗口那一跳由浏览器保证，夹具证不了（`page.close()` 实测不发信标）。
3. **结构判据钉的是"位置与形状"**：判据⑥ 保证"最早的登记在模块图之前 + 两侧键同源 + 两处
   payload 带令牌"；**语义**（迟到的告别不许注销新登记、退出幂等）由 pytest 与浏览器 spec 钉。
4. **`.scratch/launcher-exit-race/` 里有两份现场读数**（`probe-00-order-before.txt` /
   `-after.txt`）：红侧那份**别让复跑覆盖**——第一版就是这么丢的（评审当场抓出"引的读数与
   盘上证据相反"）。
