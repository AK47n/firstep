# 03 — 在途退出显式化：布防 / 撤防 / 到点取走

**要做什么：** 把"睡 1.5 秒再查一次空集"换成**显式状态**：注销后空 → `arm_exit()` 布防；
`register` 撤防；宽限到点仍布防且仍空 → `exit_due()` **取走布防（清零）并退出**。三件事同锁，
"查空 → 退出"之间不再有缝。修完这一张：① 宽限内 register 到达**必然**取消在途退出
（不再有"回了 200 然后服务没了"的 TOCTOU）；② 重复 / 迟到的 `bye` **不叠加**第二个退出线程；
③ 上面两条都能用**不睡觉**的确定性用例钉住。

**被谁阻塞：** 无——可立即开始（与 02 同一个类，但契约不同：02 管"谁的告别"，03 管"退出调度
本身的幂等与原子性"）。

**状态：** resolved

## Comments

### 2026-09-21～22 实现记录

#### ① 状态机的三个动作与多标签语义

| 触发 | 动作 | 结果 |
|---|---|---|
| 注销后**还有**标签 | —— | 路由根本不调 `_schedule_exit_if_idle`（`unregister` 返回 False） |
| 注销后变空 | `arm_exit()` | 布防一次 + 起一个 daemon 线程 |
| 同一时刻第二次 bye（重复 / 迟到信标） | `arm_exit()` | 返回 False ⇒ **不叠第二个线程** |
| 宽限内 `register`（含 F5 回来的同一个 tab_id） | `register()` 顺带撤防，返回 True | 到点时 `exit_due()` 为 False ⇒ **不退** |
| 撤防之后再关 | `arm_exit()` | 重新布防（新的一轮，不是"一次布防永久有效"） |
| 宽限到点 | `exit_due()` | 仍布防且仍空 ⇒ 取走布防 ⇒ `_EXIT(0)` |

**取走（清零）而不是留着**是关键细节：注入 `_EXIT` 的测试里"退出"不会真发生，留着布防会让
下一轮关闭永远布不了防——功能会**静默**坏掉（用例 ⑥ 正是钉这个）。

**没新增 `cancel_exit()`**：撤防的唯一来源就是 `register`，多一个没人用的公开动作只是多一处
可以漂的面（与仓库"没人用的导出删掉"同一条纪律）。
