## ⚠ 第一次「判过」是假过关，必须记下来（本轮实测踩到）

第一次是 F7（**Build**，非 Rebuild），日志只有两行：

    Rebuild 前那次：
    Build target 'Target 1'
    ".\Objects\Project.axf" - 0 Error(s), 0 Warning(s).
    Build Time Elapsed:  00:00:00        ← 0 秒，且一条 compiling 都没有

原因：**我（助手）在交给用户做 GUI 验收之前，先用 CLI（UV4）把这棵树编过一遍**，
`user/Objects/` 里 25 个 `.o` 与 `Project.axf` 都已是最新 → uVision 判定「无需重编」，
**空转后翻出上一版结果报了 0/0**。那次只证到「uVision 能打开并解析 .uvprojx」，
**没证到「uVision 能把这份代码从头编过」**。

**教训（对以后任何 GUI 侧验收都适用）**：
① 交给 GUI 验收的产物树**必须清掉旧构建产物**（Keil：`user/Objects/*` + `user/Listings/*`；
   CCS：工程下 `Debug/`），否则 GUI 构建会空转、给出**假绿**。
② 判据里必须带**「这次真的编了」的旁证**：`Build Time Elapsed` 非 0 / 日志里出现
   `compiling …` 行 / 产物 mtime 是本次。
   只读 `0 Error(s), 0 Warning(s)` 这一行**不足以**判过。
③ 本轮 A5/A7 之所以没踩到，是因为拷入 CCS workspace 前已删掉 `Debug/`；A4 漏了这一步。
   反过来说，**A4 这次用 Rebuild 才拿到真读数**。
