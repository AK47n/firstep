### 2. 静态预测 vs 实测：**两套模型都报**，差在哪也如实说

`.scratch/code-contrast/probe-08-disabled-state-read.py` 现在逐格打印 `预测A` 与 `预测B` 两列
（外加各自的差）：

| 口径 | 浅色 `.module-card.off`（slug / 说明） | 浅色 `.param-stale`（标签 / 提示） |
|---|---|---|
| **模型 A**（整块连底一起压到祖先底上，= probe-08 的几何） | 3.22 / 2.16 | 4.32 / 2.59 |
| **模型 B**（字往元素自己声明的底上拉平、底不动） | 3.40 / 2.24 | 4.53 / 2.65 |
| **真像素实测**（before） | **3.22 / 2.16** | **4.58 / 2.67** |

**结论**：`.module-card.off` 实测**逐格等于模型 A**（它自己有 `--panel-2` 底、整块被 opacity 压到
`--panel` 上）；`.param-stale` 的**提示行**实测 2.67 更接近模型 B（2.65），而**标签**实测 4.58
比两套模型都高（`--text` 在卡上、旧值 4.32/4.53）——因为它的"底"在**卡面**、`opacity` 在**卡**上，
字与底一起被拉，取样盒里还掺着输入框与描边。**两套模型都不是通用解**，所以票面定的
"判据以真像素为准"是对的；**没有为了让数字好看去改口径**。

⚠ 一条更值钱的观察：**改前那一发，形态格的"预测 vs 实测"差普遍是 114–435**，
而改后是 0–3。原因不是探针坏了：`opacity` 写在**卡**上，读数半的预测读的是**元素自己**的
`getComputedStyle(el).opacity`（子元素 = 1）⇒ **A、B 两套都按"没变淡"算**。
**这正说明"静态面看不见 `opacity` 形态"**（判据⑥当初够不着这三处的机制），
也正是这一单要真像素的原因。

### 4. "没量到"逐条记账（**不许拿"扫描看不见"当达标**）

**4.1 `.pin-menu-list li.cant`（引脚菜单的「不兼容」行）——初始态造不出来。**
最少操作路径已经走到：生成页 → 选 STM32 → 选模块 → 引脚图 32 根 `circle[data-pin]` **逐根点开**
（32 次菜单都开成、行数正常），**一条 `li.cant` 都没有**；又试了 6 个模块（含成对角色
`oled.OLED_SCL` 先绑一条 `can` 行再扫）、并换 MSPM0 板再试——都没有。
根因：这一行只在**跨角色/成对约束真的挡住**时出现（原因文案「该脚此刻不可绑（同组/成对角色约束）」），
STM32 板模型在本机的这些组合下把列出来的角色都判 `selectable`。
**替代依据** = **静态族面同一对色**：`--muted` × `--panel-2`（与 `button:disabled` **同一格**，
`code-contrast/03` 已真像素实测过 **浅 5.25 / 暗 5.67**），而这一单的静态读数（`probe-00` §2）
给出同格的 5.25 / 5.67——三处形态里另外两处的实测分别落在 **5.25/5.67** 与 **6.06/6.59**，
与它同源同底。**这一处保留为"没量到"，不许拿它当达标证据。**

**4.2 取样盒不纯的格**：两处形态的**整块**行（差 177–547，盒子里掺着徽章底与描边）、
以及 `.param-stale` 里那个 `800` 输入框（1.10 → 1.16 ❌；细长控件的"离主色最远的像素"
是它的**边框**，不是字形）。**这些格只作参考**，判据用同形态的**文字子元素**那几行（差 0–3）。
判据⑥ 的"文字子元素"这一扩口径正是为它加的。
（⚠ 评审逮到过一处**假证据**：修文件名之前，`.param-stale` 的 slug 那格读到的其实是
同名覆盖掉的输入框 PNG，读数 1.16；修好并重跑后是 **2.88 → 5.53**——见 §7 第 1 条。）

**4.3 截图失败的 3 格**：`#params-input-PROBE_THRESHOLD`（116×40 的 `<input>`，disabled）、
`.btn-params-reset`（79×23，disabled）——Playwright 对 `disabled` 控件截图会超时；
它们**不写进 JSON**（盘上没 PNG 就不留格子）。
**4.4 其他页签**：`settings` / `guide` / `changelog` / `library` / `reference` / `pdf` / `md` / `topic`
命中的不可选形态 = 0（这些页签本轮没有靶子）；`code` 页签 4 个命中全是**隐藏**控件
（零尺寸，`disabled 属性` 那半），按分类记进 `skipped`。
