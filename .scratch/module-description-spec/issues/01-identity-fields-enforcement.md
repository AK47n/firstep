# 01 — 硬件身份字段 + 新录入强制

**What to build:** 模块库的每个平台条目都能携带硬件身份——套件型号（kit）与购买链接（source_url）。新录入模块、或给已有模块新增平台版本时，身份字段必填且链接格式合法，不满足则拒绝入库且不留任何半成品；存量没有身份字段的模块照常读取，不破坏现有库。录入/浏览的 API 透传新字段。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 录入新模块不带 kit / source_url → 拒绝入库，给出明确中文错误说明
- [ ] source_url 格式非法（无 scheme、无主机等）→ 拒绝入库
- [ ] 身份字段合法 → 正常入库，manifest 落盘包含新字段
- [ ] 给已有模块新增平台版本时同样强制（缺身份 → 拒绝）
- [ ] 存量无身份字段的 manifest 仍能正常加载、浏览、编辑（迁移不打断现有库）
- [ ] 模块列表 API 返回新字段
- [ ] 校验拒绝后磁盘无残留（沿用"任何校验失败都在落盘前"不变量）
