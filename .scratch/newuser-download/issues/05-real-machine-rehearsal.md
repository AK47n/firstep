### 诚实的局限

- **本机不是干净机器**：有 Python 3.14.6、git、`tar.exe`、已有全局依赖；没有验证「全新 Windows
  没有 Python」那条分支（`need_python`），只验证了它的文案。
- **依赖安装未真正从零走过**：演练用 `--system-site-packages` 的 `.venv` 让 pip 就地满足依赖
  （为的是不污染全局 user-site），因此「全新机器上 pip 下载几分钟」这段**没有实测耗时数据**。
- **未验 macOS / Linux**（本工具本就只支持 Windows）。
