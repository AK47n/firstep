## 1. 演练纪律

1. **只用文档明说的入口。** 允许看 README 与 `START-HERE.txt`；不允许凭对仓库的了解「抄近路」。
   任何需要猜的地方 → 记进卡点清单，不自行绕过。
2. **不碰真身 8000。** 演练前后各查一次 8000/8020 监听状态；若 8000 被意外停掉，记进证据并说明恢复方式。
3. **不写真 key。** 走到「配 key」即停。
4. **原始输出优先。** 证据文件里贴命令 + 原始 stdout/stderr，不写「已确认可用」这类结论句。
5. **诚实标注环境。** 本机不是干净机器（有 Python、有 git、有 7-Zip 能力），结论不得外推为「全新环境已验证」。
