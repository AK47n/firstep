- 类别条目而非逐器件条目：59 个模块若逐个建条目会让参考库膨胀（148 → 200+），改为一类一条（17 条：14 条首轮 + 3 条整改补），标题承载类别词项 + 英文 slug 词，条目内按器件分文件。
