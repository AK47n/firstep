# 03 — 骨架映射判据与显式豁免（契约 + 机制）

**要做什么：** 把骨架「模块 → 参考例程」映射的两条验收线做成可机械检查的契约，并让「不映射」成为库内显式声明（带理由）：

1. **映射不是死的**：每个有映射的模块，至少有一个词项（含同义词组）命中至少一条参考条目标题——关联是按模块算的，只要有一条例程可关联，这条映射就算有效。现状测试要求「每个词项都命中」，过严（`step_motor` 的 `step` 0 命中、`motor` 2 命中，模块本身并不死）。
2. **不留沉默缺口**：全库每个模块要么有映射、要么在**库内数据**里显式豁免并写明理由，不再靠测试文件里的常量名单兜底。

本张只交付**契约与机制**：豁免表落到 `reference_library` 的映射表旁（与 `MODULE_PERIPHERAL_TERMS` 同居一处、同属库内数据），未映射且无手册可补的模块（协议/板载件，见工单 04 的分类）先入豁免表；其余未映射模块保持现状——「全库每个模块有映射或豁免」那条在工单 04 补完映射后才转绿（缺口不隐藏、不靠删断言过关）。
