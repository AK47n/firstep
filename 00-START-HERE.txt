========================================
 firstep 电赛工程生成器 —— 请先读我（从这里开始）
========================================

你手上这一份已经解压好了，按下面三步走就行（一共约 10 分钟）。

【第 1 步】双击本文件夹里的  install.bat
  · 它会自动建好运行环境、装依赖，需要联网，大概几分钟（没有进度条是正常的）。
  · 它会顺便在桌面放一个 firstep 快捷方式。
  · 这个文件可以重复双击，重复运行不会出错。
  · 看到“安装完成”就说明好了，按任意键关掉这个黑窗口。

【第 2 步】双击桌面上的  firstep  快捷方式
  · 浏览器会自动打开 http://127.0.0.1:8000 —— 那就是本工具。
  · 以后再启动都只双击它，不用再跑 install.bat。
  · 关掉浏览器最后一个标签页 = 停止服务。

【第 3 步】配一次 AI 钥匙（只需一次）
  · 网页右上角「设置」→ 粘贴 DeepSeek API key → 点「检查环境」。
  · key 去 https://platform.deepseek.com 注册后创建；只存在你自己电脑上。

----------------------------------------
几个常见误解，先说明白
----------------------------------------
· 这个文件夹里没有 .venv —— 正常的，第 1 步会自己建。
· 「模块库 / 母版库没就绪」—— 第一次运行 install.bat 时会自动指向本文件夹里的
  library，正常不用手动填。
· 完整包里没有 CCS / Keil 这类 IDE 安装包 —— 它们太大，请去各自官网下载。
· 只有「生成 / 修改工程」要联网调用 AI，其余操作都在你本机完成。

----------------------------------------
出问题了看哪里
----------------------------------------
· 启动日志：%USERPROFILE%\.contest_generator\webapp.log
· 想停掉服务：双击  stop-firstep.bat
· 详细教程：本文件夹的  README.md （「三步装好」「常见问题」两节）
· 网页里也有：「指南 / 新手指引」页签，从准备到编译上板四章。

本工具只支持 Windows 10/11，且需要 Python 3.13 或更新版本（没装的话
第 1 步会提示下载地址）。
